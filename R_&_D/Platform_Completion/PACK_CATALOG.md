# Pack catalog

> Generated by `tools/build_master_tasks.py` from `tools/packs_data.py`. Reconciles `R_&_D/specs/pack-framework/03-04`, `docs/PACK_REGISTRY.md`, the PRD's blueprints and stack-aware packs, and packs added on 2026-09-26. Every pack is also a row (`HP-*`, `VP-*`) in the master list.

**108 horizontal packs in 10 categories; 213 vertical packs in 30 industries.**

Stack-aware: every pack has an implementation per stack — Next.js (web, admin), React Native (app), Kotlin/Compose and Swift/SwiftUI (native app, Phase 5), Python/Go/Node (API).

**Surfaces rule for vertical packs:** Each vertical pack ships: API + database (entities, endpoints, state machines, permissions); Web (Next.js pages for each role that uses it); App (React Native screens, or Kotlin/Swift when native is asked); Admin panel (management, moderation, reports for the operator). Mobile apps also get the PWA + QR.
