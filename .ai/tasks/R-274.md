# R-274 — Form Screen Post-Submit Contextual CTAs, Record Navigation & Cancel Actions

**Status:** done  
**Phase:** BASIC/MVP — Founder Stage 0  
**Branch:** `main`  
**Complexity:** L2  

## Objective

Deliver post-submission contextual navigation and form cancellation actions in generated Next.js form screens (`apps/web/app/<screen>/page.tsx`):
1. Capture newly created or updated record ID (`lastSavedId`) upon form submission in React state.
2. Upgrade the success banner into an interactive action panel:
   - Preserve exact success message (`{isEdit ? "{name} updated successfully!" : "{name} saved successfully!"}`).
   - Render "View {name} &rarr;" link button navigating to `/{detail_screen.id}?id=${lastSavedId || editId}` when a detail screen exists for the entity.
   - Render "&larr; Back to {plural}" link button navigating to `/{list_screen.id}` when a collection screen exists for the entity.
   - Render "+ Create another {name}" action button in create mode resetting form state and success banner for rapid data entry.
   - Render "&times;" dismiss button allowing manual closure of the success alert.
3. Add a styled "Cancel" link button in the form card footer next to "Reset", navigating to `/{list_screen.id}` (or `/` if no list screen exists).
4. Maintain strict diff invariance across `ir.description` modifications; 100% offline, zero npm dependencies.

## Acceptance criteria

1. Form screen declares `lastSavedId` state (`useState<string | null>(null)`).
2. Form submission captures created record ID (`res.id`) into `setLastSavedId` in create mode.
3. Form submission sets `setLastSavedId(editId)` in edit mode.
4. Success banner preserves exact text `{isEdit ? "{name} updated successfully!" : "{name} saved successfully!"}` (or `{name} saved successfully!`).
5. Success banner renders "View {name}" link navigating to `/{detail_screen.id}?id=${lastSavedId || editId}` when a detail screen exists.
6. Success banner renders "&larr; Back to {plural}" link navigating to `/{list_screen.id}` when a collection screen exists.
7. Success banner renders "+ Create another {name}" action button in create mode.
8. Success banner renders dismiss button calling `setSuccess(false)`.
9. Form footer renders "Cancel" link button navigating to `/{list_screen.id}` (or `/`).
10. Reset button resets `lastSavedId` (`setLastSavedId(null)`).
11. Strict diff invariance across `ir.description` changes.
12. Stage 0 verification (`task verify`), `task lint`, `task security:quick`, `task doctor`, and builder demos pass.
