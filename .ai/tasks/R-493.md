# R-493: Console — Studio core (chat rail + workspace shell on shadcn/Lucide)

**Phase:** MVP
**Status:** COMPLETED
**Started:** 2026-09-19
**Completed:** 2026-09-19

## Objective

Third task of the Console UI overhaul (R-491..R-496). The Studio is the product; today it is
still the R-477/R-481 hand-rolled layout — a right-hand chat panel with plain bubbles, a
"Loading history…" string, a stats card and a raw `<textarea>` — sitting inside R-492's new
shell. This task rebuilds the **Studio core** the way Lovable / Dyad / Emergent lay it out: a
full-width workspace with the chat rail on the left, a premium chat thread with a real
streaming/working state, a composer that feels like one, a designed "getting started" empty
state with example prompts that actually work, a designed empty workspace, a compact project
header, and one icon family (Lucide) across the whole Studio. **Every piece of behavior stays
byte-for-byte**: turns hydration from `?build=`, the SSE build stream parser (three frame
shapes), edit + 404 recovery, credit updates, `previewVersion` bumps, `router.replace`. The tabs
(Preview / Files / Code / Problems) are R-494's job and are not touched here.

## Design (verified against the real code and `scripts/test.sh` before writing any code)

- **Contract constraints that shape the structure** (read from `scripts/test.sh`): R-475 requires
  `app/studio/studio-icons.tsx` to exist; R-477 requires `studio-workspace.tsx` and `.studio-grid`
  in `globals.css`; R-479/R-481/R-485 require `studio-chat.tsx` to reference `StudioPreview`,
  `StudioTabs` and `sendBuildStream`. And R-494's files (`studio-tabs.tsx`, `studio-preview.tsx`)
  import `FileIcon`/`WarningIcon`/`RefreshIcon`/`StopIcon` from `studio-icons.tsx`. So:
  `studio-icons.tsx` becomes a **thin Lucide-backed shim** exporting the same names with the same
  18px default and `aria-hidden` (one stroke family everywhere immediately; untouched files keep
  working; R-494 can then drop the shim and retire the R-475 assertion deliberately);
  `.studio-grid` keeps its name with a new definition; `studio-chat.tsx` keeps composing
  `<StudioTabs>` (which renders `<StudioPreview>`) and keeps `sendBuildStream()` verbatim.
- **Full-width Studio.** `AppShell` gains `layout?: "contained" | "full"`; the Studio layout
  passes `full` so `<main>` drops the 1180px container and becomes a flex column. R-492 kept the
  legacy geometry "until R-493 rebuilds the grid" — this is that rebuild.
- **Grid.** `.studio-grid`: chat rail `minmax(340px, 400px)` on the **left**, workspace
  `minmax(0, 1fr)` on the right, `height: calc(100dvh - 3.5rem)` (the 56px header), each column
  scrolling internally; stacks to one column below `lg`. Chat-left matches every reference
  platform and keeps the eye on the preview.
- **Chat rail** (`<aside aria-label="Chat">`, `bg-card`, right border): a rail header with the
  project name once built ("New app" before), the credit balance as a Badge with `tabular-nums`,
  and a **New app** action (`Plus`) — today there is no way to start a second app without editing
  the URL; this resets the thread/workspace/`buildId` and `router.replace("/studio")`. The
  thread is a `role="log"` region: user messages right-aligned in `--primary`, assistant messages
  left with the brand mark, errors as `role="alert"` destructive bubbles with `TriangleAlert`,
  server error strings sentence-cased through the existing `formatServerError()`. **Working
  state**: an assistant bubble with a spinning `LoaderCircle`, the live phase label
  ("Starting…", "Generating your app… N characters so far" — the R-485 character count is
  kept — or "Applying your change…"), and three shimmer `Skeleton` lines standing in for the
  code being written (the audit's "skeletons, not spinners"). **Hydrating**: two skeleton
  bubbles instead of a string. **Empty state**: "What do you want to build?", one honest
  sentence, and three example-prompt buttons that fill and focus the composer — real actions,
  not decoration; prompts are entity-style apps the builder genuinely handles.
- **Composer**: a bordered container with `focus-within` ring, an auto-growing textarea
  (Tailwind v4 `field-sizing-content`, capped at 10rem), Enter sends / Shift+Enter newline (kept),
  an `ArrowUp` icon `Button size="icon"` labelled Send, a one-line hint, and an "Editing {name}"
  context line once a build exists.
- **Workspace** (`<section aria-label="Workspace">`): an indeterminate progress bar along the top
  while a request is in flight (`@keyframes studio-progress`, `transform`-only); a **designed
  empty state** — "Your app will show up here" with three truthful mini-cards (Live preview,
  Files & code, Problems check — exactly the four tabs' capabilities); once built, a compact
  project header (`StudioWorkspace` rewritten: name, description, entity badges capped at 8,
  a `dl` of files / commit / latest-turn usage in `tabular-nums`) replacing the stats card, then
  `<StudioTabs>` untouched below it.
- **CSS**: dead legacy blocks removed from `globals.css` — `.studio-shell`, `.studio-topbar*`
  (dead since R-492), `.studio-main`, `.studio-credit-row`, `.chat-*`, `.workspace-empty`,
  `.studio-workspace-column`; `.studio-grid` redefined; `.studio-progress` + keyframes added.
  `.spinner`, `.pill`, `.pill--accent`, `--radius-*`, `--surface-2` stay (R-475 assertion and
  R-494-owned consumers). The tab/code/problems/preview/file-list classes stay for R-494.
- **No new dependencies; no API/lib changes; no agent-engine/control-plane changes.**
