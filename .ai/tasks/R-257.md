# R-257 — Full-Stack Connectivity: Next.js Typed API Client (`lib/api.ts`) & Backend CORS Middleware

**Status:** done  
**Phase:** BASIC/MVP — Founder Stage 0  
**Branch:** `main`  
**Complexity:** L2  

## Objective

Connect the generated Next.js frontend (`apps/web`) and backend services (`services/api` in Go & FastAPI):
1. **Next.js Typed API Client (`apps/web/lib/api.ts`)**:
   Generate a strongly-typed TypeScript API client with:
   - Configurable base URL via `process.env.NEXT_PUBLIC_API_URL || ""`
   - `ApiOptions` supporting custom headers, query `params`, and `token` for Bearer auth
   - `ApiError` custom error class with HTTP `status` and `data`
   - Generic `request<T>(path: string, options?: ApiOptions): Promise<T>` helper
   - Strongly-typed functions for every IR endpoint:
     - Operations with path parameters interpolate variables safely
     - LIST operations accept pagination (`limit?: number`, `offset?: number`)
     - CREATE / UPDATE operations take typed payload (`Partial<T>`)
     - Responses are typed with interfaces from `lib/types.ts`
     - Exported `api` namespace object bundling all client methods
2. **Backend CORS Middleware (Go & FastAPI)**:
   - **Go Backend**: Wrap `mux` with `corsMiddleware` in `main.go` setting `Access-Control-Allow-Origin`, `Access-Control-Allow-Methods` (`GET, POST, PUT, PATCH, DELETE, OPTIONS`), `Access-Control-Allow-Headers` (`Content-Type, Authorization`), and handling HTTP `OPTIONS` preflight with 204.
   - **FastAPI Backend**: Configure `CORSMiddleware` in `app/main.py`.

## Acceptance Criteria

1. `NextjsWebAdapter` outputs `lib/api.ts` in every generated Next.js project.
2. `lib/api.ts` imports interfaces from `./types` when entities exist.
3. Every endpoint in `ir.apis` generates a typed client function:
   - Named deterministically based on operation / path.
   - Path parameters typed as `string`.
   - Query pagination (`limit`, `offset`) supported on list operations.
   - Payload typed with `Partial<Entity>` when matching request schema.
   - Return type reflects entity / entity list / void.
4. `ApiOptions.token` adds `Authorization: Bearer ${token}` header when provided.
5. Go backend `main.go` emits `corsMiddleware` with standard CORS headers and `OPTIONS` preflight handling.
6. FastAPI backend `app/main.py` adds `CORSMiddleware`.
7. `task verify` runs offline and green with 0 network calls.
