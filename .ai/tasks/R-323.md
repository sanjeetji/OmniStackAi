# Task Contract: R-323 — Generated Accessible Reusable Popover Component (components/popover.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Rich contextual disclosures, inline date/time pickers, multi-parameter filter cards, quick entity inspection cards, and in-place mini forms require non-modal or light-dismiss floating containers anchored to specific UI triggers.

To provide this functionality across generated applications, the platform needs a standalone, accessible, reusable compound Popover component (`apps/web/components/popover.tsx`). Following previously implemented primitives (`components/badge.tsx`, `components/card.tsx`, `components/tabs.tsx`, `components/drawer.tsx`, `components/avatar.tsx`, `components/toggle.tsx`, `components/accordion.tsx`, `components/dropdown-menu.tsx`), the Popover component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and strictly adhere to WAI-ARIA Dialog / Popover design patterns.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/popover.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Compound Subcomponents**:
   - `Popover`: Root provider managing open/close state, controlled/uncontrolled modes, and ref bindings.
   - `PopoverTrigger`: Accessible trigger button emitting `aria-haspopup="dialog"`, `aria-expanded={isOpen}`, and keyboard toggles.
   - `PopoverContent`: Positioned floating dialog container emitting `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, click-outside dismiss, and Escape listener.
   - `PopoverClose`: Accessible close button emitting `aria-label="Close popover"`.
   - `PopoverArrow`: Optional visual orientation arrow pointer.
3. **Placements & Positioning**:
   - `align?: "start" | "end" | "center"`
   - `side?: "top" | "bottom" | "left" | "right"`
   - `sideOffset?: number`
4. **WAI-ARIA Popover / Dialog Semantics & Interactions**:
   - Trigger: `aria-haspopup="dialog"`, `aria-expanded={isOpen}`, `aria-controls={contentId}`.
   - Content: `role="dialog"`, `aria-modal="true"`, `id={contentId}`, `aria-labelledby={triggerId}`.
   - Click outside dismiss listener (`mousedown`).
   - Escape key dismiss with trigger focus restoration.
   - Controlled (`open`, `onOpenChange`) and uncontrolled (`defaultOpen`) operation modes.
5. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
6. **Verification & Gates**:
