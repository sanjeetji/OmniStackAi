## Goal
Add configurable page size selection and contextual empty state call-to-actions (CTAs) in Next.js generated screens:
- Add `setPageSize: (size: number) => void;` to `UseListState<T>` in `lib/hooks.ts`.
- Implement `setPageSize` in `useList<Entities>` and `useList<Children>By<Rel>`, updating `limit` (clamped to at least 1) and resetting `offset: 0`.
- Include `pageSize` and `setPageSize` in returned state objects of both list hooks.
- In `_collection_screen_page`, destructure `pageSize` and `setPageSize` and render an accessible page size selector dropdown (10, 25, 50, 100 per page) next to pagination buttons in the footer.
- In `_collection_screen_page` table body when `data && data.length === 0`:
  * When search is active (`searchInput.trim()`): render `No <plural> matching "<searchInput>".` with an interactive `Clear search` CTA button (`onClick={() => { setSearchInput(""); setSearch(""); }}`).
  * When no search is active and `form_screen` exists: render `No <plural> found yet.` with a styled `+ Create first <Entity>` CTA link (`href="/{form_screen.id}"`).
  * When no `form_screen` exists: render fallback `No <plural> found.`.
- In subcollection panels (`_collection_screen_page` and `_detail_screen_page`), when child data is empty and `child_form` exists, render a styled `+ Add first <Child>` CTA link pointing to `/{child_form.id}?{sub.id_param}=${selectedId}`.
- Preserve byte-for-byte diff invariance across `ir.description` modifications.
- 100% offline, zero network calls, zero external dependencies.

## Acceptance Criteria
1. `UseListState<T>` interface declares `setPageSize: (size: number) => void;`.
2. `useList<Entities>` hook implements `setPageSize` with `Math.max(1, newPageSize)` and resets `offset: 0`.
3. `useList<Entities>` returns both `pageSize` and `setPageSize`.
4. `useList<Children>By<Rel>` hook implements `setPageSize` resetting offset to 0 and returns `pageSize` and `setPageSize`.
5. Collection screens destructure `pageSize` and `setPageSize` from list hooks.
6. Collection screen footer renders page size selector `<select>` with options 10, 25, 50, 100 per page.
7. Collection screen table empty state renders search mismatch message with `Clear search` button when search is active.
8. Collection screen table empty state renders `+ Create first <Entity>` CTA link when form screen exists.
9. Subcollection empty state renders `+ Add first <Child>` CTA link when child form exists in both collection and detail views.
10. Strict diff invariance maintained across `ir.description` modifications.
11. End-to-end multi-target generation via `NextjsWebAdapter` passes.
12. `task verify` (598 tests) green; zero network calls; zero external dependencies.
