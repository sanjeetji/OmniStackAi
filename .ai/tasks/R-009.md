# R-009 — Deterministic usage and cost accounting for the model gateway

## Requirement

Add usage and cost accounting so the platform can optimize **cost per successful accepted change**
(Brief 18.4, 68, 92.15). Every gateway dispatch produces one immutable, metadata-only record; a
configurable price book computes estimated USD cost (local Ollama = zero, unknown models = unpriced);
a ledger aggregates totals, per-provider/per-model breakdowns, latency percentiles, success/failure
counts, and cost per successful call. Founder selected this scope for R-009 and asked for a
best-in-class implementation.

Reconstructed from Brief Sections 18, 18.2, 18.4, 23, 25, 26, 27, 68, 74, 84, 85, 90, 91, and 92.

## Acceptance criteria

- Usage records are immutable, validated, and **metadata-only** — no message content, response text,
  request payload, or secret — capturing provider, model, tier, complexity, token usage, latency,
  finish reason, success, and error code.
- A configurable price book computes cost exactly with `Decimal`; local Ollama is zero; unknown
  models are recorded as unpriced rather than guessed; cached input can be priced separately.
- The gateway records exactly one record per dispatch for success and failure, **without changing**
  the returned result or the raised error, and only when a recorder is configured.
- The ledger aggregates overall and per-provider/per-model totals, token sums, cost, success/failure
  counts, deterministic p50/p95 latency (nearest-rank), unpriced-call count, and cost per successful
  call.
- Recording is safe under concurrent dispatch and adds no network dependency.
- Offline standard-library tests cover record validation, pricing paths, ledger aggregation and
  percentiles, gateway success/failure recording, and the no-content privacy guarantee.
- Static `task verify` stays network-independent and green; existing behavior/tests unchanged.

## Expected blast radius

Additive `accounting.py` and `test_accounting.py`, an optional `recorder` parameter on `ModelGateway`
(default `None`, backward compatible), `__init__` exports, a live-runner cost summary, and doc/state/
tracker evidence. No change to PostgreSQL, Compose, infrastructure, the Section 74 contract, or the
routing outcomes of R-005/R-006/R-007/R-008.

## Design notes

- `accounting.py`: `ModelPrice`, `PriceBook` (exact (provider,model) then (provider,*) fallback;
  `DEFAULT_PRICE_BOOK` with illustrative, clearly-configurable cloud prices and zero-cost Ollama),
  immutable `UsageRecord`, `UsageLedger` (thread-safe append; `records()`, `summary()`), and
  `UsageSummary`/breakdown dataclasses. `Decimal` money.
- Gateway integration: `ModelGateway(..., recorder=UsageLedger|None)`; `generate`/`stream` record one
  success or failure record and re-raise unchanged on error.

## Model and cost trace

Accounting is deterministic; zero model calls to implement or test. Local live checks use Ollama;
no cloud key configured, so cloud calls stay zero.
