## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Heatmap & Activity Contribution Matrix compound component suite (`components/heatmap.tsx`) for Next.js web applications generated by OmniStackAI. The component supports:
- Dual layout modes:
  1. `calendar`: GitHub-style 52-week activity contribution grid with month headers, weekday labels (Mon, Wed, Fri), and quantile cell intensity.
  2. `grid`: Dense 2D coordinate matrix (e.g. 24x7 hourly load, resource utilization, server metrics) with custom X/Y axis labels.
- 5 Cyberpunk and natural color palettes:
  - `emerald`: Classic GitHub green gradient.
  - `cyan`: Futuristic cyberpunk neon cyan.
  - `violet`: Deep cosmic purple & indigo.
  - `amber`: Solar thermal gold & orange.
  - `rose`: Critical activity crimson & ruby.
- Dynamic quantile intensity bucketing (levels 0 to 4).
- Interactive cell hover/focus floating tooltip displaying date, count, and description.
- Arrow-key keyboard navigation and cell selection (`onCellClick`, `selectedCell`).
- WAI-ARIA grid accessibility semantics (`role="grid"`, `role="row"`, `role="gridcell"`, `aria-selected`).
- Integrated legend (`HeatmapLegend`) displaying "Less" -> "More" indicators.
- 4 futuristic visual styling variants: `default`, `card`, `glass`, `neon` (with glowing cell borders and neon intensity radiance).
- 3 size presets: `sm`, `md`, `lg`.
- React ref forwarding (`forwardRef`), explicit `displayName` across all exports.
- Compound and semantic alias exports: `Heatmap`, `ActivityCalendar`, `ContributionGraph`, `HeatmapLegend`, `HeatmapCell`, default export (`Heatmap`).
- Imperative handle (`HeatmapHandle`) with `selectCell`, `clearSelection`, `getStats`, `scrollToLatest`.
- Zero external runtime npm dependencies (pure React 18+ and native HTML/SVG).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_heatmap_component.py`.
