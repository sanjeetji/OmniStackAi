## 1. Objective

Provide a standalone, accessible, futuristic, and zero-dependency reusable Stat & Metric KPI Card component suite (`components/stat-card.tsx`) across all generated OmniStackAI Next.js web applications. The component must support:
1. `StatCard` compound suite:
   - `StatCardVariant`: `"default"` | `"glass"` | `"bordered"` | `"glow"`.
   - `StatTrend`: `"positive"` | `"negative"` | `"neutral"`.
   - `StatCard`: Main card wrapper with hover depth elevation, ambient glow, and optional click affordance (`role="button"`, `tabIndex={0}`, `Enter`/`Space`).
   - `StatCardHeader`: Title, optional icon slot, and optional action/menu button slot.
   - `StatCardValue`: Prominent numerical metric with prefix (e.g. `$`), suffix (e.g. `k`, `/mo`), and subtext.
   - `StatCardDelta`: Trend percentage pill with directional SVG arrow (`↑`, `↓`, `→`), positive/negative/neutral color mapping, and accessible `aria-label`.
   - `StatCardSparkline`: Pure mathematical SVG mini-graph generating smooth cubic bezier / Catmull-Rom spline path (`M ... C ...`), gradient area fill stop (`<linearGradient>`), and interactive hover dot tracking nearest coordinate.
   - `StatCardFooter`: Contextual footnote or comparison period label ("vs last 30 days").
2. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--color-primary, #2563eb)`, `var(--color-surface, #ffffff)`, etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
