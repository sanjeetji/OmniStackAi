# R-529: Phase T handoff document and draft-template demo (Phase T)

**Phase:** Phase T (Template Marketplace)
**Status:** COMPLETED (2026-09-22)

## Objective

The founder asked for two things (2026-09-22):

- a proper document in `R_&_D/` for the remaining templates and tasks, so that work can continue
  with any AI tool;
- a way to show the entire platform, including the new RideNow template.

## Delivered

- `R_&_D/OmniStackAI_Template_Marketplace_Plan_v1.md`. It covers:
  - the current state;
  - the template model and anatomy, including the pinned stack and Next 16 pitfalls;
  - the build-and-test method (scratch install, live preview, workflow tests, digest behaviour);
  - the publish checklist, with the open screenshot problem;
  - specifications for the 9 remaining templates (apps, roles, look, pages, domain, seed, live
    workflows);
  - T-5;
  - a demo guide;
  - a resume checklist.
- `scripts/preview-drafts.sh`: copies published templates and every `_draft` that has a
  `template.json` into a separate catalogue, dropping the `_`. It excludes `node_modules`,
  `.next`, `.env` and build output, then restarts the platform pointed at that catalogue. The
  repository is not changed. `--no-restart` only builds and prints the path.
- `templates/catalog/_ride-now/template.json`: RideNow's draft manifest (0.3.0; rider, driver and
  api apps; full roles, entities, features, integrations and demo users). Before this it existed
  only in a scratch folder. The catalogue still ignores `_ride-now`.
- **Renumbering:** the RideNow admin app and publish task is now **R-530**.
