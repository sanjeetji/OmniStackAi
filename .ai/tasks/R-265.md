## 1. Goal
Connect parent entity views (e.g. `Post` in `minimal-blog`) to nested child subcollections (e.g. `Comments`) using typed React hooks and interactive master-detail layouts:
- Detect foreign-key relations for entities on collection and detail screens using `_subcollections_for_parent`.
- In `_collection_screen_page`, import subcollection hooks (`useList<Children>By<Rel>`) and child types (`import type { <Child> }`) when subcollections exist.
- Manage `selectedId` state (`string | null`) in the collection component, with interactive master table row click selection and "View Details" / "Hide Details" toggle buttons.
- Render the interactive master-detail subcollection section below the table, displaying parent entity summary, total count badges (`{subcol.total}`), child item lists with display fields, loading/error/empty states, and refresh actions.
- Support multi-subcollection parent entities with tabbed navigation and per-collection live count badges.
- Implement dedicated detail screens (`_detail_screen_page`) for screens with `intent == "detail"`.
- Ensure clean fallback safety for entities without subcollections (e.g. `rideshare-favourites`), emitting zero subcollection code.
- Maintain byte-identical screen page outputs across IR description changes (diff invariance).
- Fully offline, 0 network, 0 external Python dependencies.
