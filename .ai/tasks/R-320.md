# Task Contract: R-320 — Generated Accessible Reusable Toggle Switch Component (components/toggle.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Boolean configuration settings, feature flags, published state toggles, and notification preferences are ubiquitous across enterprise web applications.

Standard HTML checkboxes often feel dated and lack modern sliding affordances. To provide a superior user experience, the platform needs a standalone, accessible, reusable Toggle Switch component (`apps/web/components/toggle.tsx`). Like previously implemented UI primitives (`components/badge.tsx`, `components/tooltip.tsx`, `components/card.tsx`, `components/alert.tsx`, `components/skeleton.tsx`, `components/drawer.tsx`, `components/avatar.tsx`), the Toggle component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and strictly adhere to WAI-ARIA 1.2 switch accessibility specifications.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/toggle.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Subcomponents**:
   - `Toggle` (also exported as `ToggleSwitch`).
   - Supports controlled (`checked`, `onChange`) and uncontrolled (`defaultChecked`) operation modes.
3. **Sizes & Styling**:
   - `ToggleSize = "sm" | "md" | "lg"` with standardized track and thumb pixel dimensions.
   - Smooth CSS transitions on background color and thumb translation.
   - Distinct active (`#2563eb`), inactive (`#cbd5e1`), and disabled (`opacity: 0.5`, `cursor: "not-allowed"`) visual states.
4. **Labels & Description Slots**:
   - Optional `label` and `description` props with automated ID binding (`aria-labelledby`, `aria-describedby`).
5. **WAI-ARIA 1.2 Switch Semantics**:
   - Emits `role="switch"`, `aria-checked={isChecked}`, `aria-disabled={disabled}`.
   - Focusable (`tabIndex={disabled ? -1 : 0}`) with accessible focus ring styling.
   - Full keyboard accessibility: toggles state on `Space` and `Enter` key presses (`preventDefault`).
6. **Form Integration**:
   - Hidden input element when `name` prop is provided for seamless HTML form integration.
7. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
