## Objective
Emit a standalone, accessible, zero-dependency, desktop-grade, and futuristic Checkbox & Checkbox Group compound component suite (`apps/web/components/checkbox.tsx`) in Next.js web applications generated by `NextjsWebAdapter`.

## Requirements
1. **WAI-ARIA 1.2 Checkbox Semantics**:
   - Single checkbox: `role="checkbox"`, `aria-checked={checked === "indeterminate" ? "mixed" : checked}`, `aria-disabled={disabled}`, `aria-required={required}`, `aria-labelledby`, `aria-describedby`, `tabIndex={disabled ? -1 : 0}`.
   - Group container: `role="group"`, `aria-label` / `aria-labelledby`, `aria-orientation`.
2. **Tri-State / Indeterminate Support**:
   - Supports `checked: boolean | "indeterminate"`.
   - Custom SVG checkmark indicator when `checked === true`.
   - Custom SVG minus/dash indicator when `checked === "indeterminate"`.
   - Smooth scale/opacity CSS transition on indicators.
3. **Keyboard Accessibility**:
   - `Space` key toggles checked state with `event.preventDefault()` to prevent page scrolling.
   - Focus ring styles for high-contrast accessibility.
4. **4 Futuristic Visual Variants**:
   - `"default"`: Sleek dark rounded container with blue accent fill and white icon.
   - `"card"`: Interactive selectable card surface with border highlight, title, and optional description text.
   - `"pill"`: Compact rounded badge button format with active filled state.
   - `"neon"`: Cyberpunk futuristic neon cyan theme with luminous glow aura (`boxShadow: 0 0 10px rgba(6, 182, 212, 0.45)`).
5. **3 Size Scales**:
   - `"sm"`: Compact 14px indicator box / 12px label text.
   - `"md"`: Balanced 18px indicator box / 14px label text (default).
   - `"lg"`: Prominent 22px indicator box / 16px label text.
6. **Controlled & Uncontrolled State**:
   - Supports `checked` and `defaultChecked` with `onCheckedChange` callback.
   - CheckboxGroup supports `value: string[]` and `defaultValue: string[]` with `onValueChange` callback.
   - Hidden input integration (`<input type="hidden" name={name} value={...} />`) for native form submissions.
7. **Compound Component Architecture & React Standards**:
   - Subcomponents: `Checkbox`, `CheckboxGroup`, `CheckboxItem = Checkbox`, and `useCheckboxGroup` context hook.
   - Both `Checkbox` and `CheckboxGroup` implement `forwardRef` and explicit `displayName`.
8. **Diff-Invariance & Purity**:
   - 100% diff-invariant across `ir.description`.
   - Zero external npm packages (pure React standard library).
