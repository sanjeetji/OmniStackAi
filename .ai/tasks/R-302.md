## Objective
Elevate visual hierarchy, data readability, and operational workflow in generated Next.js web applications (`apps/web/app/<screen>/page.tsx`):
1. Collection Screen Visual Status Badges:
   - For boolean fields (`FieldType.BOOL`), render an accessible styled pill badge:
     - Truthy: emerald badge (background `#dcfce7`, color `#166534`, border `1px solid #bbf7d0`, text "Yes").
     - Falsy: slate badge (background `#f1f5f9`, color `#475569`, border `1px solid #e2e8f0`, text "No").
   - For enum fields (fields with `parse_field_rules(f).enum`), render an accessible styled categorical badge:
     - Background `#eff6ff`, text `#1d4ed8`, border `1px solid #bfdbfe`, text `{val}` (or `-` when undefined/null).
   - Other field types (datetime, text, int, float, string) retain their formatted display expressions.
2. Detail Screen One-Click Copy-to-Clipboard Affordances:
   - In detail screens (`_detail_screen_page`), provide an accessible one-click copy affordance:
     - Beside the record heading and ID display, include a "Copy ID" button (`aria-label="Copy ID to clipboard"`).
     - In the definition list (`<dl>`), render an inline copy button for `id` or UUID fields (`aria-label="Copy <field_label> to clipboard"`).
     - Implement `handleCopy(text: string, label: string)`:
       - Uses `navigator.clipboard.writeText(text)` with fallback to `document.execCommand("copy")`.
       - On success triggers `toast.success("Copied <label> to clipboard")` via `useToast()`.
       - On error triggers `toast.error("Failed to copy to clipboard")`.
3. Subcollection Master-Detail Cards:
   - In subcollection child cards (both collection page master-detail drawer and detail screen subcollection tabs), boolean fields render the styled pill badge and enum fields render categorical badges.

## Invariance & Constraints
- 100% offline, stdlib-only Python codegen in `services/agent-engine`.
- Strict diff invariance across `ir.description`.
- Zero network or cloud model calls.
- Preserves all existing collection filters, optimistic delete, keyboard shortcuts, and pagination.
