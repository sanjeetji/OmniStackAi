## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic QR Code & Barcode compound component suite (`components/qr-code.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ and native SVG/Canvas mathematical rendering (no external `qrcode`, `jsbarcode` packages).
- Built-in mathematical QR generator with Galois Field $GF(2^8)$ Reed-Solomon error correction supporting standard Error Correction Levels: `"L"` (~7%), `"M"` (~15%), `"Q"` (~25%), `"H"` (~30%).
- Built-in mathematical 1D barcode generator (Code 128 / EAN-13 format) rendered cleanly into SVG.
- Module / dot styling options: `"square"`, `"rounded"`, `"dots"`, `"diamonds"`.
- Customizable corner finder pattern (eyes) styling with distinct outer and inner colors.
- Center logo / icon slot (`logo`, `logoSize`, `logoBackgroundColor`) with automatic quiet zone padding and masking.
- Gradient color support (linear, radial) and futuristic neon cyberpunk glow filter.
- Action toolbar with imperative handle and UI triggers:
  - Copy QR code image to clipboard (`copyToClipboard()`) with animated checkmark feedback.
  - Download as high-resolution PNG (`download(filename, "png")`).
  - Download as vector SVG (`download(filename, "svg")`).
  - Print button support.
- WAI-ARIA 1.2 accessibility semantics: `role="img"`, informative `aria-label`, alt text fallback.
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast crisp clean monochrome/dark theme.
  - `"card"`: Framed card with title, description, badge, and action buttons.
  - `"glass"`: Frosted glassmorphic container with `backdropFilter: blur(16px)`.
  - `"neon"`: Cyberpunk glowing cyan/magenta theme with radiant halo and luminous eyes.
- 3 size scales: `"sm"` (128px), `"md"` (200px), `"lg"` (280px), plus custom numeric size.
- Compound and semantic alias exports: `QrCode`, `Barcode`, `QrCard`, and `default` export (`QrCode`).
- React `forwardRef` and explicit `displayName` across compound exports.
- Imperative handle (`QrCodeHandle`): `toDataURL()`, `download()`, `copyToClipboard()`.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_qr_code_component.py`.
