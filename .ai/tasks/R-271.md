## Goal
Add client-side RFC 4180 CSV export and bulk export functionality to generated Next.js collection screens:
- Add `handleExportCsv(selectedOnly: boolean = false)` helper function to `_collection_screen_page`.
- Full-page export: Top controls bar includes an "Export CSV" button (disabled when `!data || data.length === 0`).
- Bulk export: Contextual Bulk Actions Bar includes an "Export Selected ({checkedIds.length})" button when `checkedIds.length > 0`.
- RFC 4180 compliance:
  * Headers include all declared entity fields (`entity.fields`).
  * Values are sanitized via `toCsvVal`: `null` and `undefined` format to empty quotes `""`, strings replace internal quotes `"` with `""` and wrap in double quotes, objects serialize cleanly via `JSON.stringify`.
  * Newline separation (`\n`) for standard CSV parsing.
- Browser download lifecycle:
  * Create `Blob` with MIME type `text/csv;charset=utf-8;`.
  * Generate object URL via `URL.createObjectURL(blob)`.
  * Create temporary dynamic `<a>` anchor with `download` filename formatted as `{plural.lower()}_export.csv`.
  * Programmatically trigger `link.click()`.
  * Clean up DOM node and release memory via `URL.revokeObjectURL(url)`.
- Symmetrical layout: Export Selected button is available in the Bulk Actions Bar regardless of whether the entity supports DELETE; Delete Selected button coexists when DELETE is supported.
- Maintain strict diff invariance across `ir.description` modifications.
- 100% offline, zero network calls, zero external runtime dependencies.

## Acceptance Criteria
1. Collection screens emit `handleExportCsv(selectedOnly: boolean = false)` helper.
2. Top controls bar renders "Export CSV" button bound to `handleExportCsv(false)`.
3. Top controls bar "Export CSV" button is disabled when data is null or empty.
4. Contextual Bulk Actions Bar renders "Export Selected ({checkedIds.length})" button bound to `handleExportCsv(true)`.
5. RFC 4180 escaping properly handles null/undefined (`""`), internal quotes (`""`), and objects.
6. All declared entity fields are included in CSV headers and mapped in rows.
7. Blob creation uses `text/csv;charset=utf-8;` MIME type.
8. URL object lifecycle uses `URL.createObjectURL` and `URL.revokeObjectURL`.
9. Dynamic anchor download lifecycle appends, clicks, and removes the element.
10. Download filename is formatted as `{plural.lower()}_export.csv`.
11. `handleExportCsv` filters items by `checkedIds` when `selectedOnly=true`.
12. `handleExportCsv` early-returns when there are no items to export.
13. Bulk export button is present in Bulk Actions Bar even when entity has no DELETE route.
14. Bulk export button and Delete Selected button coexist when entity has DELETE route.
15. Strict diff invariance maintained across `ir.description` modifications.
16. Full project generation succeeds across example IRs.
17. `task verify` (630 tests) green; zero network calls; zero external dependencies.
