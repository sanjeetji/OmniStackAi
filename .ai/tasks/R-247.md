# R-247 — Render the project plan and unified edit patch in the static console

## Requirement

Make the existing offline builder proof visible in the dependency-free Stage 0 console. Extend the
metadata-only console snapshot with the R-245 combined project plan for a real bundled IR example and
an R-246 hunk-level unified patch produced from an actual old/new IR assembly. Render both with safe
DOM APIs alongside the model-fabric overview. Read-only and offline: no generated app is installed,
run, verified, deployed, or connected to a database.

## Acceptance criteria

- The snapshot contains a deterministic, JSON-serializable `builderShowcase` with a real `ProjectPlan`;
  `apps/web` and `services/api` expose preview + verify details and no deploy plan by default.
- The edit preview is derived from two actually assembled `ApplicationIR` values and contains changed
  file metadata plus a non-empty hunk-level `unifiedPatch`.
- The committed JSON contains no secret value; existing provider configuration remains metadata-only.
- The static console shows app targets, preview URLs, gate/command steps, the requested change, changed
  files, and patch using `textContent` only and no external requests.
- Standard-library tests cover shape/content, determinism, and secret exclusion; `node --check`,
  `task console:snapshot`, `task verify`, `task security:quick`, and `task env:check` pass.
