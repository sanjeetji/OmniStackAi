# R-233 — Runtime & deployment provider layer (Tier 0/1 local; Tier 2/3 add-keys)

## Requirement

Wire preview/deploy behind platform-owned provider contracts (Brief §51 SandboxProvider, §75
RuntimeProvider/DeploymentProvider) so it works locally now (Tier 0/1, no keys) and cloud providers
plug in by adding a key (Tier 2/3). Deterministic and offline: plans are constructed and asserted;
nothing is installed, run, or deployed here. Committed directly to `main`. New IDs continue after the
workbook backlog's R-010..R-219 (this is R-233).

## Tier map

- **Tier 0/1 (now, no keys):** `LocalRuntimeProvider` (`id="local"`) — the default runtime; produces a
  `PreviewPlan` (install + run `Command` + local URL) per target. Executing the plan runs the app on a
  network-capable machine (your Mac / a Codespace).
- **Tier 2/3 (add a key):** cloud sandbox providers (`e2b`, `daytona`, `fly-machines`) and deploy
  providers (`vercel`, `fly`, `render`, `netlify`) — declared with a key env var; activated only when
  the key is present; selected via `OMNISTACKAI_RUNTIME_PROVIDER` / `OMNISTACKAI_DEPLOY_PROVIDER`.

## Acceptance criteria

- `RuntimeProvider`/`DeploymentProvider` are runtime-checkable contracts; `LocalRuntimeProvider`
  returns deterministic `PreviewPlan`s for `nextjs-web`, `backend-python`, `backend-go` (correct
  install/run commands + `127.0.0.1` URL) and errors on unsupported targets.
- `build_runtime_from_env` / `build_deploy_from_env` register local always, mark each cloud provider
  active only when its key env is set, default runtime = local and deploy = none, and raise a clear
  error when a keyless cloud provider is selected.
- No key is ever logged/stored/shown; `.env.example` gains placeholders + tier docs; `task verify`
  stays green and network-independent.
- Offline tests cover local plans per target, unsupported-target error, env registration with/without
  keys, unknown-selector errors, and the no-secret guarantee.

## Design notes

- New `runtime/` package: `contracts.py` (`Command`, `PreviewStep`, `PreviewPlan`, `DeployPlan`,
  `RuntimeProvider`, `DeploymentProvider`), `local.py` (`LocalRuntimeProvider`, `run_preview` executor
  for Tier 0), `providers.py` (cloud `ProviderSpec`s), `bootstrap.py` (`build_runtime_from_env`,
  `build_deploy_from_env`), `errors.py`. Mirrors the model-gateway env-bootstrap pattern.

## Model and cost trace

Deterministic; no model call, no run/deploy. No cloud key set; cloud_calls zero.
