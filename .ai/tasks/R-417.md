# R-417: Prompt -> generated app repo (chat-to-create front door, brick 2)

## Status
DONE

## Objective
Extend the "chat -> create an app" front door so a single plain-English description produces a real,
customer-owned Git repository. Add `omnistackai_agent_engine/intake/build_app.py`: `build_app_from_ir(ir,
target_dir, ...)` composes the existing pipeline (`assemble_project(ir)` -> `create_repository(project,
target_dir, ...)`) into a materialized owned repo and returns an `AppBuildResult` (prompt, ir, target_dir,
file_count, commit_sha); `async build_app_from_prompt(prompt, provider, target_dir, *, model_id, ...)` chains
the R-416 intake agent (`generate_ir`) into `build_app_from_ir` so a sentence -> validated IR -> assembled
monorepo -> owned Git repo in one call, depending only on the vendor-neutral `ModelProvider` protocol (so
`task verify` runs it against an in-memory stub -> 0 model calls, 0 network). Refactor the local-Ollama
provider construction shared by the live runners into `intake/_ollama.py`
(`build_ollama_provider_from_env`), used by both `live_run.py` (R-416) and a new opt-in `build_run.py` wired
as `task agent-engine:app:build -- "<description>"` (out dir via `OMNISTACKAI_APP_OUT_DIR` or a fresh temp
dir) that compiles a description through local Ollama and materializes the generated repo, printing its path,
file count, and first commit.
