## Objective
Provide an accessible, highly optimized, and futuristic Code Block & Syntax Presentation component suite (`components/code-block.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Built-in zero-dependency lexical tokenizer (TypeScript/JavaScript, Python, JSON, SQL, Bash/Shell, HTML/CSS, YAML, Go).
- Multi-tab snippet switcher with active tab indicators and keyboard navigation.
- Line numbers with customizable starting index and toggleability.
- Line highlighting supporting discrete lines and ranges (`highlightLines={[2, 4, "7-10"]}`).
- Diff mode with emerald addition (`+`) and rose deletion (`-`) glows.
- One-click copy to clipboard with smooth animated checkmark feedback.
- Word wrap toggle and expandable/collapsible max-height view for long snippets.
- 4 futuristic visual variants (`"terminal"`, `"glass"`, `"neon"`, `"minimal"`) with glassmorphic blur and neon glow accents.
- Full WAI-ARIA compliance (`role="region"`, keyboard scrollable `<pre>`, screen reader announcements).
- 100% diff-invariant across `ir.description`; zero external npm runtime dependencies.
