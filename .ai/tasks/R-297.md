## Requirements
Generated Next.js web application collection screens must support power-user keyboard navigation and shortcuts:
1. Pressing `/` outside of existing form inputs/selects/textareas/contenteditable elements immediately focuses the collection search input and prevents default character insertion.
2. Pressing `Escape` when focused inside the collection search input clears the search query (resets search input to empty and clears the active search state) and blurs the input.
3. If boolean/enum filters are active (`activeFilterCount > 0`), pressing `Escape` outside text inputs clears active filters (calls `clearFilters`).
4. Keep `refetch`, `clearFilters`, and `setSearch` semantics deterministic, backward-compatible, and standard-library-only.
5. Strict diff-invariance across `ir.description` changes.
