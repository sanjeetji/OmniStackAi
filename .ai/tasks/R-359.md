# Task R-359: Generated Accessible Futuristic Reusable Mobile Bottom Navigation Bar Suite

- **Tracker ID:** R-359
- **Status:** DONE
- **Phase:** MVP
- **Started At:** 2026-09-11
- **Target Component:** `apps/web/components/bottom-nav.tsx`

## Objective
Emit a standalone, accessible, zero-dependency, desktop-and-mobile-grade, and futuristic Bottom Navigation Bar compound component suite (`apps/web/components/bottom-nav.tsx`) in Next.js web applications generated by `NextjsWebAdapter`.

## Requirements
1. **WAI-ARIA 1.2 Navigation & Tablist Semantics**:
   - Root `<nav>` container emits `role="navigation"`, `aria-label="Bottom Navigation"`.
   - Items container emits `role="tablist"` or items emit `role="tab"` (or navigation links with `aria-current="page"`).
   - Selected/active item emits `aria-selected={active}`, `aria-current={active ? "page" : undefined}`, `data-state={active ? "active" : "inactive"}`.
   - Disabled items emit `aria-disabled="true"`.
2. **Badge & Notification Affordances**:
   - Support count badge (`badge?: number | string`), status indicator dot (`dot?: boolean`), and badge styling presets.
3. **Interactive Features & Action Floating Center Button**:
   - Optional elevated center FAB action button (`floatingAction?: React.ReactNode` or `prominent?: boolean`).
   - Active indicator glow / highlight indicator with smooth transition.
   - Haptic-ready click handler / `onChange` / `onTabChange` callback.
4. **4 Futuristic Visual Styling Variants**:
   - `"default"`: Sleek dark/light solid backdrop with top border divider.
   - `"glass"`: Frosted glassmorphism with backdrop blur (`backdrop-filter: blur(16px)`), luminous border.
   - `"neon"`: Cyberpunk cyan/indigo glow with ambient top border glow (`box-shadow: 0 -4px 20px rgba(56, 189, 248, 0.2)`).
   - `"floating"`: Floating pill dock with rounded-full border radius and elevated drop shadow.
5. **3 Size Scales**:
   - `"sm"` (52px height), `"md"` (64px height), `"lg"` (72px height) with responsive icon/label scaling.
6. **Compound Components & React Standards**:
   - `BottomNav`, `BottomNavItem`, `BottomNavAction`, `BottomNavBadge`.
   - Full React `forwardRef` and explicit `displayName`.
   - 100% diff-invariance across `ir.description`.
   - Zero external runtime npm dependencies (pure React).
