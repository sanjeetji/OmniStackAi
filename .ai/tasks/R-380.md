## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Flowchart & Node-Based Workflow Canvas compound component suite (`components/flow-canvas.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Interactive 2D workspace with pan (drag canvas / space+drag) and zoom (mouse wheel, zoom controls, fit-to-view).
- Node model (`FlowNode`): `id`, `label`, `type` (`"default"` | `"input"` | `"output"` | `"action"` | `"condition"`), `x`, `y`, `width?`, `height?`, `selected?`, `status?` (`"idle"` | `"running"` | `"success"` | `"error"`), `data?`, `inputs?`, `outputs?`.
- Node ports (`FlowNodePort`): input and output connection anchor handles with magnetic snapping and color accents.
- Edge / Connection model (`FlowEdge`): `id`, `sourceNodeId`, `sourcePortId?`, `targetNodeId`, `targetPortId?`, `label?`, `animated?`, `style?` (`"bezier"` | `"straight"` | `"step"`), `color?`.
- Smooth SVG cubic-bezier and step connector lines with customizable directional arrow markers.
- Active animated dataflow pulses along edges (`animated: true`).
- Interactive node dragging with grid snapping (`snapToGrid`, `gridSize`).
- Interactive port-to-port edge connection creation via drag.
- Built-in real-time interactive Minimap (`FlowMinimap`) with viewport indicator box and click-to-pan.
- Floating canvas toolbar controls (`FlowControls`): Zoom In, Zoom Out, Reset Zoom, Fit to View, Toggle Grid.
- 4 futuristic visual styling variants: `default`, `card`, `glass` (with `backdropFilter: blur(16px)`), `neon` (cyberpunk glowing cyan/magenta theme with radiant node halos and luminous neon bezier connectors).
- 3 size scales: `sm`, `md`, `lg`.
- WAI-ARIA 1.2 accessibility (`role="application"`, `aria-label="Workflow Canvas"`, keyboard arrow keys to nudge selected nodes, Delete to remove, Escape to deselect).
- React `forwardRef` and explicit `displayName` across compound exports: `FlowCanvas`, `WorkflowBuilder`, `NodeGraph`, `FlowNodeItem`, `FlowEdgeLine`, `FlowMinimap`, `FlowControls`, default export `FlowCanvas`.
- Imperative handle (`FlowCanvasHandle`): `zoomIn`, `zoomOut`, `fitView`, `resetView`, `getNodes`, `getEdges`, `addNode`, `deleteSelected`, `exportJson`.
- Zero external npm dependencies (pure React and native SVG trigonometry math).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_flow_canvas_component.py`.
