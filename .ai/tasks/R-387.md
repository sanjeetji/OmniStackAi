## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Interactive Geo Map & Location Pinpoint compound component suite (`components/geo-map.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ hooks and native mathematical vector SVG world landmass projections.
- Interactive pan & zoom engine: Mouse drag-to-pan, mouse scroll wheel zoom, touch drag, reset view, and fit-to-view controls.
- Location pinpoints & radar halos: Multiple pin styles (`"pin"`, `"dot"`, `"pulse"`, `"beacon"`), animated pulsating radar rings, and interactive click/hover popup callout cards (`MapCallout`).
- Route polyline visualizer: Waypoint connection paths with animated glowing pulse data flow.
- Interactive location search & category filter: Real-time search query filtering and category segment pill buttons.
- Coordinate crosshair & pin dropper mode: Click-to-place pin capturing latitude and longitude coordinates (`onCoordinateSelect`).
- Floating HUD controls (`MapControls`): Zoom In, Zoom Out, Reset, Recenter, Layer toggle.
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast slate dark map surface with clean vector borders.
  - `"card"`: Bordered elevated card with soft drop-shadow.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)` HUD overlays.
  - `"neon"`: Cyberpunk glowing neon theme with radiant cyan/magenta routes and illuminated landmasses.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- WAI-ARIA 1.2 application semantics (`role="application"`, `aria-label="Interactive Map"`, keyboard navigation).
- React `forwardRef` and `useImperativeHandle` (`GeoMapHandle`): `zoomIn()`, `zoomOut()`, `resetView()`, `panTo()`, `selectMarker()`, `getSelectedMarker()`.
- Compound and semantic alias exports: `GeoMap`, `InteractiveMap`, `LocationPicker`, `MapPin`, `MapCallout`, `MapControls`, `RouteLine`, and default export (`GeoMapComponent`).
- Explicit `displayName` across all compound exports.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_geo_map_component.py`.
