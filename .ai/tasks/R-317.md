# Task Contract: R-317 — Generated Accessible Reusable Skeleton Loader Component (components/skeleton.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. To ensure smooth perceptible loading experiences and eliminate Cumulative Layout Shift (CLS) during asynchronous data fetching across collections, detail views, and dashboard screens, the platform needs a standalone, accessible, reusable compound Skeleton component (`apps/web/components/skeleton.tsx`).

Like previously implemented UI primitives (`components/badge.tsx`, `components/tooltip.tsx`, `components/card.tsx`, `components/alert.tsx`), the Skeleton component must be completely self-contained, dependency-free (0 npm packages), 100% diff-invariant across changes to `ir.description`, and strictly adhere to WAI-ARIA loading accessibility specifications (`role="status"`, `aria-busy="true"`, accessible hidden announcements).

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/skeleton.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Subcomponents**:
   - `Skeleton` (base component supporting shapes, dimensions, animations, and inline styling).
   - `SkeletonText` (multi-line text loader with configurable line count, gap, and last line width).
   - `SkeletonCard` (card shape loader with optional image/banner, header, body lines, and footer).
   - `SkeletonTable` (tabular loader with header row, data rows, and configurable column count).
3. **Variants & Shapes**:
   - `SkeletonVariant = "text" | "circular" | "rectangular" | "rounded"`.
   - Appropriate border-radius styling (circular 50%, text 4px, rounded 8px, rectangular 0px).
4. **Animation Control & Accessibility**:
   - `SkeletonAnimation = "pulse" | "wave" | "none"`.
   - Subtle pulse keyframes embedded safely via inline `<style>` keyframes or CSS animation.
   - Respects `prefers-reduced-motion` media query to disable animations for users sensitive to motion.
5. **WAI-ARIA & Screen Reader Semantics**:
   - Root container emits `role="status"` and `aria-busy="true"`.
   - Emits an accessible visually-hidden announcement (`<span style={srOnlyStyle}>{ariaLabel}</span>`) with default `"Loading..."` or custom label.
6. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
