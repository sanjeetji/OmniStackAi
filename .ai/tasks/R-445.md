# R-445: Solution Pack Ecosystem Pack Registry Integration, Catalog Discovery, and Studio Multi-Surface Selection

## Standard AI Task Contract

### 1. Task Specification
- **Task ID:** R-445
- **Title:** Solution Pack Ecosystem Pack Registry Integration, Catalog Discovery, and Studio Multi-Surface Selection
- **Phase:** MVP
- **Category:** Feature / Engine / Studio / Solution Pack
- **Dependencies:** R-444 (Solution Pack Multi-Surface Ecosystem Pack Synthesis)

### 2. Objectives
1. Implement `EcosystemPack` and `EcosystemPackRegistry` in `services/agent-engine/src/omnistackai_agent_engine/solution_packs/ecosystem_registry.py`:
   - Immutable registry with `list_packs()`, `get()`, `select()`, `recommend()`, and dynamic `register_package()`.
   - Built-in default ecosystem packs (`minimal-blog-ecosystem`, `rideshare-favourites-ecosystem`) exposed via `DEFAULT_ECOSYSTEM_PACK_REGISTRY`.
   - `load_surface_ir(ecosystem_id, surface_slug)` method loading clean, normalized, valid `ApplicationIR` for any surface.
2. Extend Studio Server (`studio/server.py`):
   - Add `GET /api/ecosystem-packs` returning registered ecosystem catalog.
   - Add `POST /api/ecosystem-packs/recommend` returning domain classification and matching ecosystem recommendation.
   - Accept `ecosystem_id`, `ecosystem_version`, `surface_slug` in `POST /api/build`.
3. Extend Studio Build Pipeline (`studio/live_serve.py`):
   - Build individual surface application or entire multi-surface ecosystem when `ecosystem_id` is supplied.
   - Zero model calls when building from registered ecosystem packs.
   - Record complete provenance (including `ecosystem_id`, `surface_slug`, `surface_kind`, etc.).
4. Extend Studio History (`studio/history.py`):
   - Record `ecosystem_id`, `ecosystem_version`, `surface_slug`.
5. Enhance Studio Web UI (`studio/page.py`):
   - Ecosystem catalog selection dropdown (`#ecosystem-select`).
   - Dynamic surface selector (`#surface-select`) with "All Surfaces" and individual surfaces.
   - Real-time ecosystem recommendation banner and surface cards.
   - History item badge rendering (`[Ecosystem: <id>] [Surface: <slug>]`).
   - Zero external HTTP/HTTPS/script/font links.
6. Extend Ecosystem CLI (`solution_packs/ecosystem_cli.py`):
   - Add `catalog` subcommand listing registered ecosystem packs.
