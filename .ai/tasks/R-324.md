# Task Contract: R-324 — Generated Design Tokens & CSS Custom Properties Theming Engine (styles/tokens.css)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. To ensure visual coherence, professional styling, WCAG-compliant contrast, and seamless dynamic theme switching across generated applications, a central, production-grade Design Tokens and Theming Engine is required.

Currently, `app/globals.css` in generated web apps contains only minimal boilerplate (`body { font-family: system-ui, sans-serif; margin: 0; }`). Generated components (`Button`, `Card`, `Badge`, `Tabs`, `Modal`, `Drawer`, `Toast`, `Table`, `Avatar`, `Toggle`, `Accordion`, `DropdownMenu`, `Popover`) rely on standard color values and semantic tokens.

Task R-324 establishes `apps/web/styles/tokens.css` as a self-contained, zero-npm-dependency Design Token and Theming Engine. It supplies a comprehensive scale of CSS custom properties for semantic colors (light and dark palettes), typography, spacing, border radii, elevation/shadows, z-indices, and motion transitions, along with seamless support for both manual theme toggling (`data-theme="dark"` / `data-theme="light"`) and automatic system color scheme preference (`prefers-color-scheme: dark`).

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/styles/tokens.css` via `NextjsWebAdapter.generate()`.
2. **Global Integration**: Update `apps/web/app/globals.css` to import `../styles/tokens.css` and define consistent base layout rules.
3. **Comprehensive Token System**:
   - **Semantic Color Palette (Light Theme `:root`)**:
     - Brand/Primary: `--color-primary`, `--color-primary-hover`, `--color-primary-focus`, `--color-primary-foreground`
     - Secondary: `--color-secondary`, `--color-secondary-hover`, `--color-secondary-foreground`
     - Accent: `--color-accent`, `--color-accent-foreground`
     - Background & Surface: `--color-background`, `--color-surface`, `--color-surface-subtle`, `--color-surface-elevated`
     - Typography & Foreground: `--color-text`, `--color-text-muted`, `--color-text-subtle`, `--color-text-inverse`
     - Borders & Separators: `--color-border`, `--color-border-subtle`, `--color-border-focus`
     - Status & Feedback:
       - Success: `--color-success`, `--color-success-bg`, `--color-success-foreground`
       - Warning: `--color-warning`, `--color-warning-bg`, `--color-warning-foreground`
       - Danger / Error: `--color-danger`, `--color-danger-bg`, `--color-danger-foreground`
       - Info: `--color-info`, `--color-info-bg`, `--color-info-foreground`
   - **Dark Theme Palette (`[data-theme="dark"]`, `:root.dark`, `@media (prefers-color-scheme: dark)`)**:
     - Inverted and recalibrated surfaces (`#0f172a`, `#1e293b`), borders (`#334155`), text, and adjusted contrast ratios.
   - **Spacing Scale**:
     - `--space-0` through `--space-16` (0 to 4rem / 64px scale).
   - **Typography Scale**:
     - Fonts: `--font-sans`, `--font-mono`
     - Sizes: `--font-size-xs` through `--font-size-3xl`
     - Weights: `--font-weight-normal`, `--font-weight-medium`, `--font-weight-semibold`, `--font-weight-bold`
     - Line Heights: `--line-height-tight`, `--line-height-normal`, `--line-height-relaxed`
   - **Border Radii**:
     - `--radius-none`, `--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-xl`, `--radius-full`
   - **Box Shadows & Elevation**:
     - `--shadow-none`, `--shadow-sm`, `--shadow-md`, `--shadow-lg`, `--shadow-xl`
   - **Z-Index Scale**:
     - `--z-dropdown`, `--z-sticky`, `--z-modal`, `--z-popover`, `--z-toast`, `--z-tooltip`
   - **Transitions & Easing**:
     - `--transition-fast`, `--transition-normal`, `--transition-slow`
4. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - Zero external dependencies (pure CSS custom properties).
