# R-536 — CareClinic (Part 2 of 4): Shared Library & Patient Web App

## Context & Objective
Build the client foundation and patient-facing experience for CareClinic (Tracker ID T-8, category: `healthcare`):
1. Build `packages/shared` (`@careclinic/shared`):
   - TypeScript domain interfaces matching database schema and API contracts:
     - Doctor profile, clinic, patient, family member, appointment, slot, vitals, consultation (SOAP), diagnosis (ICD-10), prescription, lab order, invoice, review, notification, telehealth session.
   - Universal `CareClinicApiClient` with session token management, typed methods for all public and patient endpoints, error handling.
   - Clinical and date/time formatting helpers (INR currency formatting, slot time label, appointment status badge color/label, cancellation refund calculator).
   - Real-time `useStream` SSE event bus client hook.
2. Build `apps/patient`:
   - Next.js 16 App Router + React 19 + Turbopack + Tailwind CSS 4.
   - Design: Calm clinical aesthetic — soft teal (`#0D9488` / `#14B8A6` / `teal-600`), clean slate/white foundations, Plus Jakarta Sans typography, generous whitespace, accessible contrast.
   - Demo User Quick Login: Ananya Deshmukh (`ananya@careclinic.test` / `Patient@2026`).
   - 16 patient routes:
     - `/`: Patient Portal Home (Hero, active appointment card, quick actions: Book, Telehealth, Prescriptions, Lab Reports, Doctors grid, Health tips).
     - `/doctors`: Doctor Directory & Search (filter by specialty, consultation mode, language, sort by fee/rating).
     - `/doctors/[id]`: Doctor Profile & Weekly Schedule (qualifications, experience, consultation fees, clinic address, patient reviews).
     - `/book`: Step-by-step Slot Picker & Appointment Booking (doctor selector, mode: in-person or video, date calendar, dynamic 20-min slot picker, patient/family member selector, reason for visit, payment mock, instant confirmation).
     - `/appointments`: Appointments List (tabbed: Upcoming, Past, Cancelled, token numbers, status badges).
     - `/appointments/[id]`: Appointment Detail (status tracker, doctor info, clinic room or video link, download summary, reschedule & cancel with refund preview modal).
     - `/telehealth/[id]`: Telehealth Video Visit Room (WebRTC video preview/call interface, doctor avatar, mute/video toggles, live chat panel, consult timer).
     - `/prescriptions`: Digital Prescriptions List (filter by date, doctor, condition).
     - `/prescriptions/[id]`: Prescription Detail & Printable View (doctor digital signature badge, Rx medication list with dosage, frequency, instructions, SOAP notes summary).
     - `/lab-reports`: Lab Reports List (test category filters, status: ordered, processing, ready).
     - `/lab-reports/[id]`: Lab Report Detail (diagnostic lab details, reference ranges, abnormal indicators, PDF download).
     - `/health-records`: Health Records & Vitals Tracker (vitals trends chart/cards: BP, Sugar, Pulse, BMI; past medical history, chronic conditions, allergy tags, log new vitals entry).
     - `/family`: Family Members Management (add/edit family profiles, relationship tags, age, blood group).
     - `/invoices`: Billing & Invoices (paid/unpaid invoices, download receipt, pay outstanding consultation fee).
     - `/reviews`: Doctor Ratings & Reviews (submit review with star rating and feedback for completed appointments).
     - `/notifications`: Real-time Notifications & Reminders (appointment alerts, prescription notifications, SSE updates).
     - `/login`: Patient Sign In with 1-click Ananya Deshmukh demo button.
3. Verification:
   - Run Next.js production build (`pnpm --filter @careclinic/patient build`).
   - Validate catalog draft (`test_studio_templates.py`).
   - Run `task verify`.
