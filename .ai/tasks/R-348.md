## Objective
Provide an accessible, production-grade, zero-dependency, and futuristic **Context Menu / Right-Click Action Menu** compound component suite (`apps/web/components/context-menu.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone compound suite: `ContextMenu` (with compound aliases `ContextMenu.Trigger`, `ContextMenu.Content`, `ContextMenu.Item`, `ContextMenu.CheckboxItem`, `ContextMenu.RadioGroup`, `ContextMenu.RadioItem`, `ContextMenu.Separator`, `ContextMenu.Label`, `ContextMenu.Sub`, `ContextMenu.SubTrigger`, `ContextMenu.SubContent`).
- Exports TypeScript interfaces: `ContextMenuVariant` (`"neon"` | `"glass"` | `"bordered"` | `"minimal"`), `ContextMenuSize` (`"sm"` | `"md"` | `"lg"`), `ContextMenuProps`, `ContextMenuTriggerProps`, `ContextMenuContentProps`, `ContextMenuItemProps`, `ContextMenuCheckboxItemProps`, `ContextMenuRadioGroupProps`, `ContextMenuRadioItemProps`, `ContextMenuSeparatorProps`, `ContextMenuLabelProps`, `ContextMenuSubProps`, `ContextMenuSubTriggerProps`, `ContextMenuSubContentProps`, `ContextMenuContextValue`, `ContextMenuSubContextValue`.
- Viewport Boundary Clamping: Right-click coordinates `(clientX, clientY)` are dynamically adjusted against `window.innerWidth` and `window.innerHeight` so the menu never overflows the screen edges.
- Submenu nesting (`ContextMenu.Sub`, `ContextMenu.SubTrigger`, `ContextMenu.SubContent`) with automated edge flipping.
- Checkbox and radio items with custom vector indicators (`role="menuitemcheckbox"`, `role="menuitemradio"`, `aria-checked`).
- Keyboard shortcut annotations (`shortcut?: string`, rendered with `<kbd>`).
- Destructive item variant (`destructive?: boolean`).
- Click-outside and Escape dismissal with focus restoration.
- Full WAI-ARIA 1.2 Menu semantics (`role="menu"`, `role="menuitem"`, `role="menuitemcheckbox"`, `role="menuitemradio"`, `role="separator"`, `role="group"`, `aria-haspopup="menu"`, `aria-expanded`).
- Full keyboard navigation (`Escape`, `ArrowDown`/`ArrowUp`, `ArrowRight`/`ArrowLeft`, `Home`/`End`, `Enter`/`Space`).
- 4 futuristic visual variants: `"neon"`, `"glass"`, `"bordered"`, `"minimal"`.
- 3 size presets: `"sm"`, `"md"`, `"lg"`.
- 100% diff-invariant across `ir.description`; zero external npm packages.
