## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Audio & Voice Recorder compound component suite (`components/audio-recorder.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ hooks, HTML5 `<canvas>`, and native inline vector SVGs.
- Real-time sound recording lifecycle state machine: `"idle"`, `"recording"`, `"paused"`, `"stopped"`.
- Live sound waveform canvas visualizer (`WaveformVisualizer`) supporting 3 rendering modes: `"bars"`, `"wave"`, `"mirror"`.
- Real-time recording duration timer (`MM:SS`) with animated pulsing live recording indicator.
- Maximum duration limit guard (`maxDuration`) with automatic stop.
- Integrated playback bar with seek scrubber slider, play/pause toggle, and elapsed/total time readout.
- Audio export actions (`Download`, `Delete`/discard).
- WAI-ARIA 1.2 media semantics (`role="region"`, `aria-label="Audio Recorder"`, `aria-live="polite"`, accessible action buttons).
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast crisp clean slate dark surface.
  - `"card"`: Bordered card surface with soft elevation.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)`.
  - `"neon"`: Cyberpunk glowing cyan/magenta theme with radiant halos and luminous waveform bars.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- Compound and semantic alias exports: `AudioRecorder`, `VoiceRecorder`, `SoundRecorder`, `WaveformVisualizer`, `AudioPlayerBar`, and default export (`AudioRecorderComponent`).
- React `forwardRef` and explicit `displayName` across compound exports.
- Imperative handle (`AudioRecorderHandle`): `startRecording()`, `stopRecording()`, `pauseRecording()`, `resumeRecording()`, `reset()`, `getRecording()`.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_audio_recorder_component.py`.
