## Objective
Provide an accessible, production-grade, zero-dependency, and futuristic **Color Picker & Palette Swatch** component suite (`apps/web/components/color-picker.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone compound suite: `ColorPicker` (with compound aliases `ColorPicker.Area`, `ColorPicker.HueSlider`, `ColorPicker.AlphaSlider`, `ColorPicker.Swatches`, `ColorPicker.Inputs`, `ColorPicker.EyeDropper`).
- Exports TypeScript interfaces: `ColorPickerFormat` (`"hex"` | `"rgb"` | `"hsl"`), `ColorPickerVariant` (`"neon"` | `"glass"` | `"bordered"` | `"minimal"`), `ColorPickerSize` (`"sm"` | `"md"` | `"lg"`), `ColorSwatch`, `ColorPickerProps`, `ColorAreaProps`, `ColorSliderProps`, `ColorSwatchesProps`, `ColorPickerContextValue`.
- Pure mathematical color models without external libraries:
  - Hex to RGB / RGBA parsing and formatting (`#RRGGBB`, `#RRGGBBAA`, `#RGB`).
  - RGB to HSV / HSL and HSV/HSL to RGB conversion functions.
- Interactive Saturation / Value 2D spectrum canvas or gradient area (`pointerdown`, `pointermove`, `pointerup`, touch events).
- Hue bar slider (0° to 360°) and Alpha opacity slider (0 to 100%).
- Input field toggle switcher between HEX, RGB, and HSL formats.
- Preset palette swatches with keyboard selection (`role="listbox"`, `role="option"`, `aria-selected`).
- Native EyeDropper API trigger button when supported by the browser with fallback graceful degradation.
- 4 visual variants: `"neon"` (cyberpunk glowing border with current color accent glow), `"glass"` (translucent frosted backdrop blur `12px`), `"bordered"` (clean border frame with slate neutral borders), and `"minimal"` (compact popover/inline trigger).
- Full WAI-ARIA accessibility semantics and keyboard navigation (`ArrowLeft`/`Right`, `ArrowUp`/`Down`, `Home`, `End`, `Tab`).
- 100% diff-invariant across `ir.description`; zero external npm packages.
