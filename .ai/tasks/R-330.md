# Task Contract: R-330

## Objective
Provide a standalone, accessible, zero-dependency reusable Command Palette / Search Modal component suite at `apps/web/components/command-palette.tsx` in generated Next.js web applications, supporting global keyboard activation (`Cmd+K` / `Ctrl+K`), real-time search filtering, grouped command lists, keyboard arrow traversal, item shortcut badges, WAI-ARIA combobox and listbox pattern semantics, backdrop blur overlay, and clean dismiss behavior.

## Acceptance Criteria
- [x] Implement standalone Command Palette component (`apps/web/components/command-palette.tsx`) with client directive (`"use client";`).
- [x] Export component: `CommandPalette`.
- [x] Export types: `CommandItem`, `CommandGroup`, `CommandPaletteProps`.
- [x] Global shortcut listener:
  - Listens for `Meta+k` (macOS) or `Control+k` (Windows/Linux) to toggle palette visibility.
  - Configurable `triggerShortcut?: boolean` (defaults to true).
- [x] Real-time search filtering:
  - Search input with placeholder (default "Type a command or search...").
  - Instant filtering across command `label`, `keywords`, `description`, and `group`.
  - Search input includes search SVG icon and clear affordance.
- [x] Keyboard navigation and selection:
  - Arrow down (`ArrowDown`) advances active item, skipping disabled items and wrapping gracefully.
  - Arrow up (`ArrowUp`) traverses backwards.
  - `Enter` executes selected item's `onSelect` callback and closes palette (unless prevented).
  - `Escape` dismisses the palette and restores prior focus.
  - `Home` / `End` jumps to first / last selectable item.
- [x] Grouping & categorisation:
  - Displays items organised under group headings (`role="group"`) when `group` is specified.
- [x] Shortcut badges:
  - Visual keyboard shortcut hints on items (e.g. `<kbd>` tags).
- [x] WAI-ARIA combobox semantics:
  - Input with `role="combobox"`, `aria-autocomplete="list"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`.
  - Results container with `role="listbox"`, `id` referenced by `aria-controls`.
  - Command items with `role="option"`, unique `id`, and `aria-selected={isActive}`.
  - Modal overlay with `role="dialog"`, `aria-modal="true"`, `aria-label="Command palette"`.
- [x] Zero external npm dependencies, pure React (React 18), TypeScript, and CSS custom properties.
- [x] 100% diff-invariant across changes to `ir.description`.
- [x] Export `render_command_palette_component()` in `omnistackai_agent_engine.codegen` and register `components/command-palette.tsx` in `NextjsWebAdapter.generate()`.
- [x] Comprehensive unit tests in `services/agent-engine/tests/test_command_palette_component.py` passing cleanly (at least 13 tests).
- [x] Verification gates pass: `task verify`, `task lint`, `task security:quick`, `task env:check`, `task builder:demo`.
