# R-475: Studio visual foundation

**Phase:** MVP
**Status:** COMPLETED
**Started:** 2026-09-19
**Completed:** 2026-09-19

## Objective

First task of the approved Phase D roadmap (`R_&_D/OmniStackAI_Commercial_Platform_Kickoff_v1.md`'s
"Remaining Phase D roadmap", now seven tasks R-475–R-481 — renumbered from the original six-task
sketch after two research passes and two founder decisions; see the plan record for full reasoning).
Turn `/studio` into a real app shell the later chat (R-477) and tabbed workspace (R-481) tasks build
on top of, rather than a one-off skin of the current single-page form that gets discarded when R-481
replaces it. No backend changes. No behavior changes to the existing build/file-browsing flow.

## Design

- New `apps/console-web/app/studio/layout.tsx` (async Server Component): takes over the auth gate
  (`getCurrentUser()` → `redirect("/login")`, moved out of `page.tsx` so every future Studio
  sub-view inherits it for free) and renders persistent chrome — a slim top bar (product mark,
  "Studio" label, a back-to-home link, the existing `<LogoutButton/>`) plus a `{children}` slot. No
  left sidebar: there is nothing else inside Studio to navigate to yet.
- `app/studio/page.tsx` shrinks to rendering content inside that shell (drops its own inline
  `<main className="wrap wrap--wide">`/`<header className="masthead">`).
- `globals.css` gains, additively, mirrored into the existing `@media (prefers-color-scheme: dark)`
  block exactly like every token today: `--radius-sm/md/lg` (replacing today's inconsistent inline
  8/12/14px radius values), `--surface-2` (an elevated tone distinct from `--panel`, for future
  nested cards), an accent-tinted chip background token, a refined `.panel` using the new radius
  token (a pure CSS change — zero markup changes anywhere, so `/`, `/fabric`, `/login`, `/register`
  get a free visual uplift as a side effect), a CSS-only `.spinner` (`@keyframes spin`, zero
  dependency, reusable by later tasks' pending/loading states), and a `.pill--accent` modifier on
  the existing `.pill` for a persistent credit-balance chip.
- New `apps/console-web/app/studio/studio-icons.tsx`: ~8-10 small hand-rolled inline-SVG stroke
  icons. **Decision: stay dependency-free** rather than add an icon library — the fixed, small icon
  surface needed across the whole roadmap doesn't clear the bar for a new dependency when the
  in-house alternative is this cheap and everything else in this app is already hand-rolled CSS/SVG.
- `studio-form.tsx`: restyle only, zero logic change. Credit balance moves from its own stat panel
  into a `.pill--accent` chip near the top.
- **Deliberately not built yet**: the two-column "chat rail + workspace" CSS grid — introduced in
  R-477 alongside its first real consumer, not shipped unverified/unused now.
