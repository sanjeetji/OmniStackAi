## Objective
Provide an accessible, highly optimized, and futuristic Carousel & Content Slider compound component suite (`components/carousel.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone `Carousel` compound component suite (`Carousel`, `Carousel.Content`, `Carousel.Slide`, `Carousel.Previous`, `Carousel.Next`, `Carousel.Indicators`, `Carousel.Progress`, `Carousel.AutoplayToggle`).
- Pure React and CSS transitions with zero third-party slider library dependencies.
- 4 futuristic visual variants: `"neon"` (cyberpunk glowing border and accent indicators), `"glass"` (translucent backdrop-filtered controls), `"cards"` (3D perspective card deck with scale transform), and `"minimal"` (clean borderless presentation).
- Slide transition modes: `"slide"` (smooth track translateX) and `"fade"` (cross-dissolve opacity).
- Touch and pointer swipe gesture handling (`onTouchStart`, `onTouchMove`, `onTouchEnd` with minimum delta threshold).
- Configurable autoplay with interval timer, pause on mouse hover and keyboard focus, and accessible play/pause toggle.
- Keyboard navigation adhering to WAI-ARIA Carousel Pattern (`ArrowLeft`, `ArrowRight`, `Home`, `End`).
- Full WAI-ARIA accessibility semantics (`role="region"`, `aria-roledescription="carousel"`, `role="group"`, `aria-roledescription="slide"`, `aria-label`, `aria-hidden`, `aria-live`).
- Multiple indicator styles: dot pills, fraction count (`1 / 5`), and animated progress bar.
- 100% diff-invariant across `ir.description`; zero external npm runtime dependencies.
