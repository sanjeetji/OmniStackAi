## Status
DONE

## Objective
Add an accessible, zero-dependency, desktop-and-mobile-grade, futuristic Countdown Timer, Stopwatch & Live Clock compound component suite (`components/countdown.tsx`): three modes — `countdown` (to a `targetDate` or a fixed `duration` in seconds), `stopwatch` (elapsed time), and `clock` (live current time, 12h/24h) — driven by a real `setInterval` tick with SSR-safe mounting (deterministic first paint via a `mounted` flag; real time computed only after mount to avoid hydration mismatch); day/hour/minute/second unit segments with optional labels and configurable separator, `autoStart`, controlled + uncontrolled `paused`, `onComplete` + `onTick` callbacks, a JS `prefers-reduced-motion` guard that disables the per-tick pulse animation, WAI-ARIA semantics (`role="timer"`, `aria-atomic`, and a visually-hidden `aria-live` completion announcement), 4 futuristic visual styling variants ("default", "card", "glass", "neon"), 3 size scales ("sm", "md", "lg"), React ref forwarding (`forwardRef`), `useImperativeHandle` (`CountdownHandle`: `start`/`pause`/`reset`/`restart`/`getTime`/`isRunning`), and explicit `displayName` across compound and semantic alias exports (`Countdown`, `CountdownTimer`, `Stopwatch`, `LiveClock`, default export). Static module constant — never references `ir.name`/`ir.description`.
