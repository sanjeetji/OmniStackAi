## Requirements
Generated Next.js web application form screens (`_form_screen_page`) must enforce schema validation rules natively in HTML and provide live visual feedback:
1. String and Text fields with `max_length` validation rule:
   - Emits `maxLength={rules.max_length}` HTML attribute on `<input>` and `<textarea>`.
   - Renders a live character counter displaying `{length}/{max_length}`.
   - Counter dynamically shifts color to amber warning (`#b45309`) when input length exceeds 90% of `max_length`.
   - Displays helper hint `Max {max_length} characters` when no validation error is present.
2. Number fields with `minimum` or `maximum` validation rules:
   - Emits `min={rules.minimum}` when minimum is specified.
   - Emits `max={rules.maximum}` when maximum is specified.
   - Displays helper badge indicating valid range (`Range: {min} to {max}`).
3. Non-constrained fields preserve existing markup byte-identically.
4. 100% diff-invariant across `ir.description` changes.
5. Fully offline, standard-library-only platform code, 0 model calls.
