# R-442: Studio AI-delta feature modification controls above Solution Packs

## Objective
Wire natural-language AI feature additions / modifications on top of selected Solution Packs into the OmniStackAI Studio:
- HTTP API (`server.py`): accept `ai_features` (list of feature specifications or prompt string) in `POST /api/build`.
- Live Build Pipeline (`live_serve.py`): when AI features are provided on top of a Solution Pack, formulate typed `ai-delta` changes, call `generate_ai_delta_proposal` via the `ModelProvider` boundary (or bypass when none requested), merge the proposal safely via `apply_solution_pack_manifest`, compile into an owned repo with `build_solution_pack_project`, and return full provenance including applied AI delta change IDs.
- History (`history.py`): track `applied_ai_delta_change_ids` in `StudioBuildHistory`.
- Studio Web UI (`page.py`): provide feature addition input (`#ai-features`), pass to build request, indicate AI synthesis progress, and render applied AI deltas alongside configuration and base IR digests.
- Zero External Resources: `STUDIO_HTML` strictly preserves inline CSS and JS with 0 external resources (`http://`, `https://`, `src=`, `<link`).
- Offline Verification: full offline verification in `task verify` with zero model calls required during test execution.
