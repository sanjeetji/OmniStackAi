# R-419: Turnkey local run for a generated app (chat-to-create front door, brick 4)

## Status
DONE

## Objective
Make a generated app repo run locally in one command, removing the manual DB/venv/pnpm dance. New
`omnistackai_agent_engine/localrun/` package (Python 3.13 stdlib only), following the platform's
"deterministic plan + opt-in executor" pattern: `plan.py` provides `RunStep`/`RunPlan` dataclasses and
`build_run_plan(repo_dir, *, db_*, api_port, web_port, jwt_secret, db_name=None)` which inspects the repo
(backend flavor via `services/api/requirements.txt` -> python / `go.mod`|`main.go` -> go; migrations under
`services/api/migrations/*.sql`; web via `apps/web/package.json`) and composes an ordered, JSON-safe plan:
recreate a per-app PostgreSQL database (DROP IF EXISTS + CREATE) in the running local container, apply each
migration, start the backend (`uvicorn app.main:app` with `DATABASE_URL`/`JWT_SECRET`, or `go run .`), and
start the web app with `next dev` (the Next binary directly, NOT `pnpm dev`) with `NEXT_PUBLIC_API_URL`; it
resolves `api_url`/`web_url` and a `RunPlan.to_dict()` (masking the DB password). `run.py` is the opt-in
executor (`task agent-engine:app:run -- <dir>`, excluded from static verify): it runs the setup steps
synchronously (skipping an existing `.venv`/`node_modules`), launches the two servers, polls the backend
`/healthz`, prints the URLs, and cleans both up on Ctrl+C. The Task depends on `db:up` so Postgres is
guaranteed healthy first. All local, no paid cloud.
