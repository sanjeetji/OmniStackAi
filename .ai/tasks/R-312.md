# Task R-312: Generated Accessible Reusable Badge & Status Pill Component (components/badge.tsx)

## Status: DONE

## Objective
Elevate visual hierarchy, status signaling, and enterprise design consistency across generated Next.js web applications: emit a standalone, reusable, accessible Badge and Status Pill component (`apps/web/components/badge.tsx`) conforming to WAI-ARIA status semantics, supporting semantic variants (`"success"`, `"warning"`, `"error"`, `"info"`, `"neutral"`), dot indicators with pulse effect, and compact/standard sizing.

## Requirements
1. **Component Architecture & Interfaces (`apps/web/components/badge.tsx`)**:
   - Emitted with `"use client"` directive.
   - Exports `BadgeVariant = "success" | "warning" | "error" | "info" | "neutral"`.
   - Exports `BadgeSize = "sm" | "md"`.
   - Exports `BadgeProps` interface:
     - `children: React.ReactNode`
     - `variant?: BadgeVariant` (defaults to `"neutral"`)
     - `size?: BadgeSize` (defaults to `"md"`)
     - `dot?: boolean` (defaults to `false`)
     - `pulse?: boolean` (defaults to `false`)
     - `style?: React.CSSProperties`
     - `className?: string`
     - `ariaLabel?: string`
2. **Accessible Semantics & Visual Design**:
   - Renders semantic `role="status"` with optional `aria-label`.
   - Built-in status dot indicator with `aria-hidden="true"`.
   - High-contrast, WCAG-compliant color tokens for each variant:
     - `success`: `#dcfce7` bg, `#166534` text, `#bbf7d0` border, `#22c55e` dot.
     - `warning`: `#fef3c7` bg, `#92400e` text, `#fde68a` border, `#f59e0b` dot.
     - `error`: `#fee2e2` bg, `#991b1b` text, `#fecaca` border, `#ef4444` dot.
     - `info`: `#eff6ff` bg, `#1d4ed8` text, `#bfdbfe` border, `#3b82f6` dot.
     - `neutral`: `#f1f5f9` bg, `#475569` text, `#e2e8f0` border, `#94a3b8` dot.
3. **Platform Codegen & Adapter Integration**:
   - Implemented as `_BADGE_COMPONENT` template in `nextjs.py`.
   - Exported as `render_badge_component() -> str` in `omnistackai_agent_engine.codegen`.
   - Registered in `NextjsWebAdapter.generate()` at path `components/badge.tsx`.
   - 100% diff-invariant across `ir.description` changes.
4. **Offline & Safety Discipline**:
   - Pure codegen changes, 100% offline, 0 network, 0 model calls.
   - Zero git commit or git push (strictly working tree uncommitted per user instruction).
