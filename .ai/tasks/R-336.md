## 1. Objective

Provide a standalone, accessible, zero-dependency reusable Timeline / Activity Feed component suite (`components/timeline.tsx`) across all generated OmniStackAI Next.js web applications. The component must support:
1. `Timeline` root component:
   - `TimelineVariant`: `"default"` | `"compact"` | `"centered"`.
   - `TimelineItemStatus`: `"pending"` | `"active"` | `"completed"` | `"error"` | `"warning"`.
   - `TimelineItem`: `id`, `title`, `description`, `timestamp`, `status`, `icon`, `action`.
   - `TimelineProps`: `items`, `variant`, `label`, `className`, `style`.
   - Vertical connector line with status-driven colored fill (e.g. green for completed steps).
   - Built-in status icons: completed (check circle), error (X circle), warning (alert circle), active (pulsing dot), pending (clock).
   - Custom icon slot override (`item.icon`) and action slot (`item.action`).
   - Timestamp rendered as semantic `<time>` element.
   - Alternating left/right layout for `centered` variant.
   - Compact variant with reduced spacing and tighter connector lines.
   - WAI-ARIA accessibility: `role="list"` on timeline container, `role="listitem"` on each entry, `aria-label`.
2. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--color-primary, #2563eb)`, `var(--color-success, #22c55e)`, `var(--color-danger, #ef4444)`, etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
