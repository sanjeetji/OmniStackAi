# R-405: Accessible Futuristic Reusable Mention / @-Autocomplete Textarea Suite (`components/mention.tsx`)

## Status
DONE

## Objective
Add an accessible, zero-dependency, desktop-and-mobile-grade, futuristic Mention / @-Autocomplete Textarea compound component suite (`components/mention.tsx`): a textarea that detects a configurable `trigger` character (default `@`) at the caret via a `detectTrigger()` helper (scans back to a whitespace-delimited token), opens a filtered suggestion listbox from an `items` prop, supports full keyboard navigation (ArrowDown/ArrowUp to move, Enter/Tab to insert, Escape to close), inserts the chosen mention token and keeps typing flowing, extracts the set of mentioned ids from the text, supports controlled + uncontrolled `value`, and fires `onChange(value, mentions)` + `onMention` callbacks; ARIA combobox/listbox pattern (textarea with `aria-autocomplete="list"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`; listbox `role="listbox"` with `role="option"` + `aria-selected`); 4 futuristic visual styling variants ("default", "card", "glass", "neon"); 3 size scales ("sm", "md", "lg"); React ref forwarding (`forwardRef`); `useImperativeHandle` (`MentionHandle`: `getValue`/`setValue`/`getMentions`/`focus`/`clear`); and explicit `displayName` across compound and semantic alias exports (`Mention`, `MentionInput`, `MentionTextarea`, `AtMention`, default export). Static module constant — never references `ir.name`/`ir.description`.
