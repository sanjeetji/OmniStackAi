## 1. Objective

Provide a standalone, accessible, zero-dependency reusable Stepper / Multi-step Wizard component suite (`components/stepper.tsx`) in all generated OmniStackAI Next.js web applications. The component must support:
1. `Stepper` root component:
   - `StepperOrientation`: `"horizontal"` | `"vertical"`.
   - `StepperVariant`: `"default"` | `"dots"` | `"progress"`.
   - `StepStatus`: `"idle"` | `"active"` | `"completed"` | `"error"`.
   - `StepDef`: `id`, `title`, `description`, `icon`, `optional`, `status`.
   - `StepIndicator`: numeric index, checkmark SVG for completed, error-X SVG for error.
   - `StepConnector`: vertical or horizontal line with completion-proportional color fill.
   - `StepContent`: tabpanel container for active step contents.
   - `useStepperState` hook: `activeStep`, `goNext`, `goPrev`, `goTo`, `canGoNext`, `canGoPrev`.
   - Controlled (`activeStep`, `onChange`) and uncontrolled (`defaultStep`) modes.
   - WAI-ARIA tablist / tab / tabpanel semantics: `role="tablist"`, `role="tab"`, `aria-selected`, `aria-controls`, `role="tabpanel"`, `aria-labelledby`, `aria-disabled`.
   - Full keyboard navigation: `ArrowRight`/`ArrowLeft` (horizontal), `ArrowDown`/`ArrowUp` (vertical), `Home`, `End`.
2. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--color-primary, #2563eb)`, `var(--color-border, #e2e8f0)`, etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
