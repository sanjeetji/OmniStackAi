# Task Contract: R-322 — Generated Accessible Reusable Dropdown Menu Component (components/dropdown-menu.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Action bars, row item menus ("... More Actions"), user profile menus, contextual filters, and data export selectors are fundamental interaction points in modern web applications.

To provide consistent, accessible action menus across generated applications, the platform needs a standalone, accessible, reusable compound Dropdown Menu component (`apps/web/components/dropdown-menu.tsx`). Following previously implemented primitives (`components/badge.tsx`, `components/card.tsx`, `components/tabs.tsx`, `components/drawer.tsx`, `components/avatar.tsx`, `components/toggle.tsx`, `components/accordion.tsx`), the Dropdown Menu component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and strictly adhere to WAI-ARIA 1.2 Menu / MenuButton design patterns.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/dropdown-menu.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Compound Subcomponents**:
   - `DropdownMenu`: Root provider managing open/close state, active item focus, and keyboard navigation.
   - `DropdownMenuTrigger`: Accessible trigger button emitting `aria-haspopup="menu"`, `aria-expanded={isOpen}`, and keyboard toggles.
   - `DropdownMenuContent`: Positioned menu container emitting `role="menu"`, `aria-labelledby`, click-outside dismiss, and Escape listener.
   - `DropdownMenuItem`: Interactive item emitting `role="menuitem"`, supporting click handler, `disabled`, `destructive` variant, and optional icon/shortcut slot.
   - `DropdownMenuSeparator`: Visual divider emitting `role="separator"` with `aria-orientation="horizontal"`.
   - `DropdownMenuLabel`: Contextual section label.
3. **Placements & Positioning**:
   - `align?: "start" | "end" | "center"`
   - `side?: "top" | "bottom" | "left" | "right"`
   - Default position: `bottom-start` or `bottom-end`.
4. **WAI-ARIA 1.2 Menu Semantics & Keyboard Navigation**:
   - Trigger: `aria-haspopup="menu"`, `aria-expanded={isOpen}`, `aria-controls={contentId}`.
   - Menu: `role="menu"`, `id={contentId}`, `aria-labelledby={triggerId}`, `tabIndex={-1}`.
   - Items: `role="menuitem"`, `aria-disabled={disabled}`.
   - Keyboard interaction:
     - `ArrowDown`: cycle to next item (skipping disabled).
     - `ArrowUp`: cycle to previous item (skipping disabled).
     - `Home`: move to first item.
     - `End`: move to last item.
     - `Escape`: dismiss menu and restore focus to trigger.
     - `Enter` / `Space`: activate selected item and close menu.
5. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
6. **Verification & Gates**:
