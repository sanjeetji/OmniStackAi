# Task Contract: R-321 — Generated Accessible Reusable Accordion / Collapsible Component (components/accordion.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Complex master-detail views, nested record inspections, collapsible filter panels, FAQ sections, and categorized configuration accordions are essential UI structures in enterprise web software.

To provide structured progressive disclosure in generated applications, the platform needs a standalone, accessible, reusable compound Accordion component (`apps/web/components/accordion.tsx`). Following previously implemented primitives (`components/badge.tsx`, `components/card.tsx`, `components/tabs.tsx`, `components/drawer.tsx`, `components/avatar.tsx`, `components/toggle.tsx`), the Accordion component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and strictly adhere to WAI-ARIA 1.2 accordion specifications.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/accordion.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Compound Subcomponents**:
   - `Accordion` (root container & context provider).
   - `AccordionItem` (individual collapsible section wrapper with unique value key).
   - `AccordionTrigger` (accessible header button with animated rotating chevron).
   - `AccordionContent` (collapsible content panel).
3. **Accordion Modes & Behavior**:
   - `type: "single" | "multiple"` (single active section or multi-expandable).
   - `collapsible: boolean` (in single mode, allows closing all sections).
   - Controlled (`value`, `onValueChange`) and uncontrolled (`defaultValue`) operation modes.
4. **Visual Variants**:
   - `variant: "default" | "bordered" | "separated"`.
   - Smooth CSS transitions on chevron rotation (`rotate(180deg)`), background, and padding.
5. **WAI-ARIA 1.2 Accordion Semantics**:
   - Trigger emits `aria-expanded={isOpen}`, `aria-controls={contentId}`, and dynamic `id`.
   - Content panel emits `role="region"`, `id={contentId}`, `aria-labelledby={triggerId}`, and `hidden={!isOpen}`.
   - Rotating chevron SVG emits `aria-hidden="true"`.
6. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
7. **Verification & Gates**:
