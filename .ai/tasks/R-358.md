## Objective
Emit a standalone, accessible, zero-dependency, desktop-grade, and futuristic Searchable Combobox & Autocomplete compound component suite (`apps/web/components/combobox.tsx`) in Next.js web applications generated by `NextjsWebAdapter`.

## Requirements
1. **WAI-ARIA 1.2 Combobox & Listbox Semantics**:
   - `role="combobox"`, `aria-expanded={isOpen}`, `aria-haspopup="listbox"`, `aria-autocomplete="list"`, `aria-controls={listboxId}`, `aria-activedescendant={activeOptionId}`.
   - Listbox emits `role="listbox"`, `aria-multiselectable={multiple || undefined}`, `id={listboxId}`.
   - Options emit `role="option"`, `aria-selected={isSelected}`, `id={optionId}`, `data-highlighted={isHighlighted}`.
2. **Keyboard Navigation & Type-Ahead**:
   - `ArrowDown` / `ArrowUp` to cycle through options (with wrap-around).
   - `Enter` to select highlighted option.
   - `Escape` to close dropdown and restore trigger focus.
   - `Home` / `End` to jump to first/last options.
   - Typing in input filters options instantly with case-insensitive matching across label, description, and keywords.
3. **Single-Select & Multi-Select Modes**:
   - Single selection: displays selected option label with clear button (`allowClear`).
   - Multiple selection: displays selected options as chips/badges with individual removal buttons (`x`).
4. **4 Futuristic Visual Variants**:
   - `"default"`: Sleek dark/light minimal border with smooth focus ring.
   - `"card"`: Segmented options with subtitle descriptions and category badges.
   - `"glass"`: Glassmorphism with backdrop-filter blur and subtle luminous border.
   - `"neon"`: Cyberpunk cyan/indigo glow with ambient shadow highlights (`box-shadow: 0 0 15px rgba(56, 189, 248, 0.3)`).
5. **3 Size Scales**:
   - `"sm"`, `"md"`, `"lg"` with proportional padding, font sizes, and icon metrics.
6. **Compound Components & React Standards**:
   - `Combobox`, `Autocomplete = Combobox`.
   - Full React `forwardRef` and explicit `displayName`.
   - 100% diff-invariance across `ir.description`.
   - Zero external runtime npm dependencies (pure React).
