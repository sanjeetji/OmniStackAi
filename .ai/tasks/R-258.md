# R-258 — Query Parameter Sorting (`sort` & `order=asc|desc`) on LIST Endpoints with SQL Injection Whitelist Protection

**Status:** done  
**Phase:** BASIC/MVP — Founder Stage 0  
**Branch:** `main`  
**Complexity:** L2  

## Objective

Add query parameter sorting (`sort` field name and `order=asc|desc`) to `Op.LIST` and `Op.LIST_BY` endpoints across Go and FastAPI backends, accompanied by strict whitelist validation to protect against SQL injection, and update the Next.js typed API client (`lib/api.ts`):

1. **Go Shared Handlers & Wired Handlers**:
   - `internal/handlers/handlers.go`: added `parseSort(r *http.Request) (string, string)`.
   - `internal/handlers/*.go`: pass `sort, order` into `store.List<Entity>` and `store.List<Entity>By<Rel>`.
2. **Go Store (`internal/store/*.go`)**:
   - Validate `sort` against known entity fields via switch statement; if invalid or unrecognized, fallback to `"id"`.
   - Validate `order`: `"DESC"` if `strings.ToLower(order) == "desc"`, else `"ASC"`.
   - Format query: `ORDER BY <safe_col> <safe_dir> LIMIT $1 OFFSET $2`.
3. **FastAPI Routers & Repositories**:
   - `app/routers/*.py`: add `sort: str = "id", order: str = "asc"` to list endpoint parameters.
   - `app/repositories/*.py`: validate `sort` against `ALLOWED_SORT_FIELDS`, normalize `order`, format safe `ORDER BY {safe_col} {safe_dir} LIMIT %s OFFSET %s`.
4. **Next.js Client**:
   - `lib/api.ts`: type `params` on list functions with `sort?: string; order?: "asc" | "desc"`.

## Acceptance Criteria

1. `GET /entities?sort=field&order=desc` sorts by `field` in descending order.
2. In Go, sort field is validated against declared entity fields. Invalid or un-whitelisted values fall back to `"id"`.
3. In Python, sort field is validated against declared entity fields. Invalid or un-whitelisted values fall back to `"id"`.
4. `order` parameter accepts `"asc"` or `"desc"` (case-insensitive); any other value defaults to `"asc"`.
5. List endpoints without query parameters continue to work with default `sort="id"` and `order="asc"`.
6. Next.js `lib/api.ts` accepts `sort` and `order` in options params.
7. `task verify` passes with 0 network calls.
