## 1. Objective

Provide a lightweight, fully accessible, reusable rating and review component suite (`components/rating.tsx`) in all generated OmniStackAI Next.js web applications. The component must support:
1. `Rating` component:
   - Configurable maximum score (`max`, default 5).
   - Full and half-increment rating selection (`allowHalf`, e.g. 3.5 / 5).
   - Read-only (`readOnly`) and disabled (`disabled`) modes.
   - Interactive hover preview (`onHover`, temporary score highlight on mouseenter/move, reset on mouseleave).
   - Click-to-set rating selection (`onChange`).
   - Keyboard navigation when focused: `ArrowRight`/`ArrowUp` (increment), `ArrowLeft`/`ArrowDown` (decrement), `Home` (min), `End` (max).
   - WAI-ARIA slider pattern semantics: `role="slider"`, `tabIndex`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-valuetext`, `aria-readonly`, `aria-disabled`, `aria-label`.
   - Built-in vector icons: `star`, `heart`, and `thumb` via inline SVG (zero external icon dependencies).
   - Fractional visual fill rendering via SVG clipPath or overlay for precise half-star and fractional score rendering.
   - Optional numeric score display badge (`showScore`, `formatScore`).
   - Size presets (`sm`: 16px, `md`: 24px, `lg`: 32px) and custom color themes (`color`, `emptyColor`).
2. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--warning, #f59e0b)`, `var(--muted, #cbd5e1)` etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
