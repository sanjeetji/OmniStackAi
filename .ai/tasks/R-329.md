# Task Contract: R-329

## Objective
Provide a standalone, accessible, zero-dependency reusable Data Grid / Table component suite at `apps/web/components/data-grid.tsx` in generated Next.js web applications, supporting generic typed columns (`ColumnDef<T>`), interactive column sorting (`aria-sort`), row selection checkboxes with select-all and indeterminate states (`aria-selected`), display density presets (`compact`, `comfortable`, `spacious`), sticky headers, striped rows, loading skeleton state, custom cell renderers, and full WAI-ARIA table semantics.

## Acceptance Criteria
- [x] Implement standalone Data Grid component (`apps/web/components/data-grid.tsx`) with client directive (`"use client";`).
- [x] Export components: `DataGrid`.
- [x] Export types: `ColumnDef<T>`, `DataGridProps<T>`, `SortDirection`, `SortState`, `DataGridDensity`.
- [x] Implement sortable columns:
  - Column header button or cell with `aria-sort` (`"ascending"`, `"descending"`, or `"none"`).
  - Visual sort indicator SVGs for ascending, descending, and sortable states.
  - Column click and keyboard (`Enter` / `Space`) sort toggling with cycle (`asc` -> `desc` -> none).
- [x] Implement row selection:
  - Checkbox column with header select-all supporting checked, unchecked, and indeterminate states.
  - Row checkboxes with `aria-label` identifying each row.
  - `aria-selected` attribute on selected `<tr>` rows.
  - `onSelectionChange` callback with selected row IDs or items.
- [x] Implement display density modes:
  - `"compact"` (reduced padding and font size for data-dense dashboards).
  - `"comfortable"` (default balanced spacing).
  - `"spacious"` (relaxed padding for reading ease).
- [x] Implement table styling options:
  - Sticky header (`stickyHeader = true`) with background and border preservation.
  - Striped rows (`striped = true`) for alternating row readability.
  - Hover highlight on rows (`hoverable = true`).
- [x] Implement loading and empty states:
  - Loading skeleton state with animated placeholder rows, `role="status"`, and `aria-busy="true"`.
  - Empty state fallback rendering when data array is empty.
- [x] Full WAI-ARIA table semantics (`role="table"` or native `<table>`, `role="columnheader"`, `role="row"`, `role="cell"`, `aria-label`).
- [x] Zero external npm dependencies, pure React (React 18), TypeScript, and CSS custom properties.
