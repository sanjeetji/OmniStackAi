# R-443: Solution Pack Packaging, Verification, and Export CLI

## Objective
Fourteenth brick of the differentiating spine and tenth Solution Pack task. Implement standalone, portable Solution Pack packaging (`SolutionPackPackage`), package verification, and export/inspect CLI tools (`package_cli.py`), enabling Solution Packs to be bundled with their canonical Application IR, verification plans, and SHA-256 integrity digests into self-contained, redistributable, and tamper-evident `.pack.json` artifacts that can be independently inspected, verified, exported, and imported into registry instances without reliance on Python module imports.

## Requirements
1. **Self-Contained Package Data Model (`package.py`)**:
   - `SolutionPackPackage` dataclass (frozen, slots=True) containing schema version, pack metadata (id, version, display name, description, domains, capabilities, targets, verify_targets), canonical IR SHA-256 digest, full Application IR dictionary, verification plans, and package integrity SHA-256 checksum.
   - `from_solution_pack(pack, registry=None)` factory: extracts Application IR, computes canonical IR digest, derives verification plans via `build_project_plan`, and computes the package checksum.
   - `to_dict()`, `to_json()`: byte-stable canonical JSON serialization with deterministic key ordering.
   - `parse_solution_pack_package(data, verify_integrity=True)`: strictly parses JSON or dictionary, verifies package checksum, validates embedded Application IR using `validate_ir` and `from_dict`, checks that the computed IR digest strictly matches `ir_sha256`, and rejects unknown keys or corrupted fields with `SolutionPackError`.
   - `to_application_ir()`: safely reconstructs a validated `ApplicationIR` instance.
2. **Registry Package Support (`registry.py`)**:
   - Extend `SolutionPack` to support package-backed baselines (`from_package(pkg)`).
   - Extend `SolutionPackRegistry` with `register_package(pkg)` to register standalone packages dynamically without needing Python module imports.
3. **Packaging & Export CLI (`package_cli.py`)**:
   - `export`: exports registered pack by ID to file or stdout.
   - `verify`: cryptographically and semantically verifies a `.pack.json` file.
   - `inspect`: formats a clean terminal report of a pack bundle's metadata, targets, entities, APIs, and screens.
4. **Taskfile & Script Wiring**:
   - Add `agent-engine:solution-pack:package` / `agent-engine:solution-pack:export` tasks to `Taskfile.yml` and `scripts/agent-engine.sh`.
5. **Quality & Verification Gates**:
   - Python 3.13 stdlib only (zero new third-party dependencies).
   - 100% offline, deterministic verification in `task verify` (0 model calls).
   - Comprehensive test suite in `test_solution_pack_package.py`.
   - All gates pass: `task lint`, `task security:quick`, `task env:check`, `task builder:demo`.
