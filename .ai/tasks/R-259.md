# R-259 — Total Count Queries & `X-Total-Count` Header on LIST Endpoints

**Status:** done  
**Phase:** BASIC/MVP — Founder Stage 0  
**Branch:** `main`  
**Complexity:** L2  

## Objective

Add total count computation and standard `X-Total-Count` HTTP response header to `Op.LIST` and `Op.LIST_BY` endpoints across Go and FastAPI backends, with CORS header exposure and Next.js client integration:

1. **Go Store (`internal/store/*.go`)**:
   - Emit `Count<Entity>(ctx context.Context, db *sql.DB) (int, error)` using `SELECT COUNT(*) FROM <table>`.
   - Emit `Count<Entity>By<Rel>(ctx context.Context, db *sql.DB, <rel>ID string) (int, error)` using `SELECT COUNT(*) FROM <table> WHERE <rel>_id = $1`.
2. **Go Handlers & CORS (`internal/handlers/*.go`, `main.go`)**:
   - In wired `Op.LIST` and `Op.LIST_BY` handlers, call store count method and set `w.Header().Set("X-Total-Count", strconv.Itoa(total))`.
   - In `corsMiddleware`, add `w.Header().Set("Access-Control-Expose-Headers", "X-Total-Count")`.
3. **FastAPI Repositories, Routers & CORS (`app/repositories/*.py`, `app/routers/*.py`, `app/main.py`)**:
   - In repository, emit `async def count_<table>() -> int` and `async def count_<table>_by_<rel>(<rel>_id: str) -> int`.
   - In router, inject `response: Response`, call count repository method, and set `response.headers["X-Total-Count"] = str(total)`.
   - In `CORSMiddleware`, add `expose_headers=["X-Total-Count"]`.
4. **Next.js Client SDK (`apps/web/lib/api.ts`)**:
   - Export `PaginatedResult<T> { data: T; total: number }`, emit `requestWithMeta<T>`, and generate `list<Entity>WithCount` / `list<Entity>sBy<Rel>WithCount` methods.
5. **Backwards Compatibility**:
   - Response payload remains `Entity[]`, preserving complete compatibility.
