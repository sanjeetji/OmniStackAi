## Requirements
Generated Next.js web application detail screens (`_detail_screen_page`) must support power-user keyboard navigation and shortcuts:
1. When navigating outside editable controls (`INPUT`, `TEXTAREA`, `SELECT`, `contentEditable`):
   - Pressing `ArrowLeft` or `[` navigates to the previous record when available (`prevItem && handleSelectId(prevItem.id)`).
   - Pressing `ArrowRight` or `]` navigates to the next record when available (`nextItem && handleSelectId(nextItem.id)`).
   - Pressing `e` or `E` navigates to edit mode for the current record when edit capability and form screen exist (`can_edit && form_screen && selectedId`).
   - Pressing `Escape` deselects the current record (`handleSelectId(null)`).
2. Proper event listener cleanup on unmount with comprehensive dependencies.
3. 100% diff-invariant across `ir.description` changes.
4. Fully offline, standard-library-only platform code, 0 model calls.
