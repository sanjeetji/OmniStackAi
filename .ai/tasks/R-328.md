# Task Contract: R-328

## Objective
Provide a standalone, accessible, zero-dependency reusable Date Picker and Calendar component suite at `apps/web/components/date-picker.tsx` in generated Next.js web applications, supporting interactive month/year navigation, day grid keyboard traversal, WAI-ARIA grid and dialog semantics, date selection, min/max constraints, custom formatting, and trigger popover integration.

## Acceptance Criteria
- [x] Implement standalone Date Picker component (`apps/web/components/date-picker.tsx`) with client directive (`"use client";`).
- [x] Export components: `DatePicker`, `Calendar`.
- [x] Export types: `DatePickerProps`, `CalendarProps`, `DateFormatter`.
- [x] Implement `Calendar` view with:
  - Header with month and year title and prev/next navigation buttons with accessible `aria-label`s.
  - Day of week header row (`Sun`, `Mon`, `Tue`, `Wed`, `Thu`, `Fri`, `Sat`) with `abbr` or accessible labels.
  - Interactive day grid with `role="grid"`, `role="row"`, and `role="gridcell"`.
  - Proper `aria-selected` on the selected date, `aria-current="date"` on today's date, and `aria-disabled` / `disabled` on out-of-range dates (`minDate`, `maxDate`).
  - Keyboard navigation (Left/Right Arrow for +/- 1 day, Up/Down Arrow for +/- 7 days, Enter/Space to select, Home/End for start/end of week).
- [x] Implement `DatePicker` trigger and popover:
  - Accessible trigger button with `aria-haspopup="dialog"`, `aria-expanded`, and calendar icon.
  - Displays selected date formatted or placeholder text when empty.
  - Optional clear button (`clearable`) to reset selected date.
  - Popover with `role="dialog"` that dismisses on outside click and `Escape` key.
- [x] Built-in lightweight date helper utilities (`formatDate`, `isSameDay`, `isToday`, `getDaysInMonth`) without any external dependencies (like moment or date-fns).
- [x] Zero external npm dependencies, pure React (React 18), TypeScript, and CSS custom properties.
- [x] 100% diff-invariant across changes to `ir.description`.
