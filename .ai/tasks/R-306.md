## Context & Objectives
In complex multi-entity applications, users need clear visual wayfinding and hierarchy navigation when moving from the global overview into collections, detail screens, and create/update forms.
This task introduces a dedicated, reusable, accessible Breadcrumbs component:
1. `apps/web/components/breadcrumbs.tsx`:
   - Emits client component (`"use client";`) with zero npm dependencies.
   - WAI-ARIA 1.2 compliance: `<nav aria-label="Breadcrumb">`, `<ol>`, `<li>`, `aria-current="page"` for current item, `aria-hidden="true"` separator (`/`).
   - Typed `BreadcrumbItem` (`label: string; href?: string;`) and `BreadcrumbsProps`.
   - Accessible rendering: links for ancestor levels, non-link bold text with `aria-current="page"` for terminal level.
2. `apps/web/app/<screen>/page.tsx` (Detail Screens via `_detail_screen_page`):
   - Mounts `<Breadcrumbs items={[ { label: "Overview", href: "/" }, ...(has_collection ? [{ label: "{plural}", href: "/{col_screen.id}" }] : []), { label: selectedId ? "{name} #{selectedId}" : "{name} Details" } ]} />` at the top.
   - Preserves existing `&larr; Back to {plural}` link for backwards compatibility with existing assertions.
3. `apps/web/app/<screen>/page.tsx` (Form Screens via `_form_screen_page`):
   - Mounts `<Breadcrumbs items={[ { label: "Overview", href: "/" }, ...(has_collection ? [{ label: "{plural}", href: "/{list_screen.id}" }] : []), { label: isEdit ? "Edit {name}" : "New {name}" } ]} />` at the top.
   - Preserves existing `&larr; Back to {plural}` link.
4. Codegen Export & Registration:
   - Exports `render_breadcrumbs_component` from `omnistackai_agent_engine.codegen`.
   - Registers `components/breadcrumbs.tsx` in `NextjsWebAdapter.generate()`.
5. Diff Invariance:
   - Pure static template independent of `ir.description`, strictly guaranteeing diff invariance across IR updates.
