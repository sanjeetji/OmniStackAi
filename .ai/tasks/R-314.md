## Objective
Elevate micro-copy accessibility, user guidance, and design polish across generated Next.js web applications: emit a standalone, reusable, accessible Tooltip component (`components/tooltip.tsx`) conforming to WAI-ARIA 1.2 Tooltip design pattern (role="tooltip", aria-describedby linkage, escape key dismiss, hover and focus triggers), supporting position placement ("top" | "bottom" | "left" | "right"), customizable delay (delayMs), 100% diff-invariance across `ir.description`, and 0 external dependencies.

## Implementation Details
1. **Component Design**:
   - `TooltipPosition`: `"top"` | `"bottom"` | `"left"` | `"right"`.
   - `TooltipProps`: `content`, `children`, `position`, `delayMs`, `className`, `style`.
   - `useId` for unique dynamic tooltip ID.
   - Linkage: `React.cloneElement(children, { "aria-describedby": visible ? tooltipId : undefined })`.
   - Accessible roles: `<span id={tooltipId} role="tooltip">`.
   - Triggers: `onMouseEnter`, `onMouseLeave`, `onFocus`, `onBlur`.
   - Escape key dismiss: listens for `Escape` keydown when `visible` and closes immediately.
   - Clean positioning CSS for top, bottom, left, and right offsets.
