## 1. Objective

Provide a lightweight, fully accessible, reusable progress indicator and loading animation component suite (`components/progress.tsx`) in all generated OmniStackAI Next.js web applications. The component must support:
1. `ProgressBar` (or `Progress`):
   - Linear bar with track and filled progress indicator.
   - Determinate mode: numeric `value`, `min`, `max`, `showValue`, `formatValue`. Sets `role="progressbar"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-valuetext`.
   - Indeterminate mode: when `value` is omitted/undefined, omits `aria-valuenow` (per WAI-ARIA specification) and animates a pulsing/sliding continuous bar.
   - Striped and animated striped variants.
   - Size presets (`sm`, `md`, `lg`) and semantic variants (`default`, `success`, `warning`, `error`, `info`).
   - Accessible label support via `label`, `aria-label`, or `aria-labelledby`.
2. `CircularProgress`:
   - Circular SVG progress ring with track and progress stroke.
   - Determinate percentage stroke-dasharray / stroke-dashoffset.
   - Indeterminate continuous rotating spinner sweep.
   - Center text support (`showValue`, custom label, or icon).
   - Semantic color variants and size options.
3. `Spinner`:
   - Ultra-lightweight rotating loader icon / circle.
   - `role="status"` with accessible live region (`aria-live="polite"`).
   - Visually hidden screen-reader announcement (`sr-only` text, default "Loading...").
   - Size presets and custom sizes.
4. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--primary, #2563eb)`, `var(--muted, ...)` etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
