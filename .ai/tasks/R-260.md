# R-260 — OpenAPI 3.1 Specification Generation from Application IR

**Status:** done  
**Phase:** BASIC/MVP — Founder Stage 0  
**Branch:** `main`  
**Complexity:** L2  

## Objective

Generate a deterministic, canonical OpenAPI 3.1.0 specification directly from the `ApplicationIR` (Brief Section 43: *"Contracts: OpenAPI + generated clients"*, `packages/contracts/openapi/`):

1. **Core Generator (`codegen/openapi.py`)**:
   - `render_openapi(ir: ApplicationIR) -> dict[str, Any]`:
     - OpenAPI version: `"3.1.0"`.
     - Info object: title (`ir.name`), description (`ir.description`), version (`"1.0.0"`).
     - Components schemas: for each `Entity` in `ir.entities`, convert fields to JSON Schema typed properties with validation metadata (`maxLength`, `enum`, `minimum`, `maximum`, `required`).
     - Standard `ValidationError` and `ErrorResponse` schemas.
     - Security schemes: `BearerAuth` (HTTP Bearer / JWT).
     - Paths: declare all endpoints from `ir.apis` with path parameters, query parameters (`limit`, `offset`, `sort`, `order` on LIST endpoints), request bodies referencing schemas, responses (200, 201, 204, 400, 401, 403, 404), and `X-Total-Count` header on 200 LIST responses.
     - Security requirements: map `api.auth` and `api.required_roles`.
   - `render_openapi_json(ir: ApplicationIR, indent: int = 2) -> str`: deterministic formatted JSON string.
2. **Monorepo Assembler (`codegen/assembler.py`)**:
   - In `assemble_project(ir)`, emit `contracts/openapi.json` at root of the customer monorepo.
3. **Backend Adapters (`codegen/backend_go.py`, `codegen/backend_python.py`)**:
   - Emit `openapi.json` at the root of generated Go and FastAPI backend services.
4. **Offline & Pure**:
   - Standard library `json` only. 0 platform dependencies, 0 network, 0 DB connection.

## Acceptance Criteria

1. `render_openapi(ir)` produces valid OpenAPI 3.1.0 dict matching Application IR entities and APIs. [PASS]
2. Field types and validation constraints (`maxLength`, `enum`, `minimum`, `maximum`, `required`) map accurately to OpenAPI schemas. [PASS]
3. LIST endpoints include query parameters (`limit`, `offset`, `sort`, `order`) and `X-Total-Count` header on 200 responses. [PASS]
4. Security schemes declare `BearerAuth` and operations with `auth=True` declare security requirement. [PASS]
5. Monorepo assembler emits `contracts/openapi.json`. [PASS]
6. Go and FastAPI backend projects emit `openapi.json`. [PASS]
7. `task verify` passes with 0 network calls (475 tests pass). [PASS]
