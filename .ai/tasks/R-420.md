# R-420: SQL-safe generated PostgreSQL identifiers and FK dependency order

## Status

DONE — 2026-09-13

## Objective

Correct the two generator defects proven by R-419's live PostgreSQL run. A prompt-generated bookstore
must not emit `CREATE TABLE order`, and a child entity declared before its FK parent must not emit a
forward `REFERENCES` to a table that does not exist. The fix must be coherent across the migration,
honest fixture seed migration, FastAPI/Python repositories, and Go stores—not a schema-only patch that
fails on the first runtime query.

## Requirements and acceptance

- Keep logical snake_case names unchanged for paths, Python/Go symbols, route wiring, and API contracts.
- Double-quote every generator-owned PostgreSQL table, column, relation-column, and index identifier in
  emitted SQL; escape embedded quotes defensively even though current IR identifiers cannot contain them.
- Use one stable FK dependency ordering for entity `CREATE TABLE` blocks and fixture entity groups.
  Independent entities retain input order; fixture row order remains authored order.
- Self-references are valid. A non-self dependency cycle fails deterministically with an explanatory
  `ValueError` rather than returning SQL known to fail when applied.
- Association tables remain after entity tables. Output stays byte-stable.
- Cover Order/User-style names, field/relation/index identifiers, child-before-parent and transitive
  ordering, independent stability, self-reference, cycles, seed ordering, and Python/Go repository SQL.

## Blast radius

Primary generator files are `codegen/schema_sql.py`, `codegen/seed_sql.py`, and
`codegen/data_access.py`, plus a new focused `test_schema_sql_safety.py`. Exact string assertions may be
updated only when they directly encode the intentionally changed quoted SQL. Documentation/state files
listed in `.ai/CURRENT_TASK.yaml` are completion-only updates.

## Forbidden changes

No Application IR change, DB-engine change, dependency, network/model/DB call in `task verify`, new
service/infrastructure/top-level folder, runtime/studio/localrun change, or native/mobile work. Preserve
the unrelated untracked `.claude/` directory and never include it in R-420.
