# Task Contract: R-331

## Objective
Provide a standalone, accessible, zero-dependency reusable Slider & Range component suite at `apps/web/components/slider.tsx` in generated Next.js web applications, supporting single-value and dual-thumb range modes, interactive drag traversal (pointerdown/move/up), full keyboard navigation (Arrow keys, PageUp, PageDown, Home, End), tick marks and labels, WAI-ARIA slider pattern semantics (`role="slider"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-orientation`, `aria-disabled`), vertical and horizontal orientations, and diff invariance.

## Acceptance Criteria
- [x] Implement standalone Slider component (`apps/web/components/slider.tsx`) with client directive (`"use client";`).
- [x] Export component: `Slider` (default and named export).
- [x] Export types: `SliderOrientation`, `SliderValue`, `SliderProps`, `SliderMark`.
- [x] Support both single value (`number`) and range selection (`[number, number]`).
- [x] Range mode prevents thumb crossover (Thumb 0 <= Thumb 1).
- [x] Pointer drag interactions on track and thumbs (mouse and touch via pointer events).
- [x] Full keyboard navigation for focused thumb:
  - `ArrowRight` / `ArrowUp` increments by `step`.
  - `ArrowLeft` / `ArrowDown` decrements by `step`.
  - `PageUp` increments by large step (10x step).
  - `PageDown` decrements by large step (10x step).
  - `Home` snaps to minimum valid value.
  - `End` snaps to maximum valid value.
- [x] WAI-ARIA slider pattern semantics:
  - Thumbs render `role="slider"`, `tabIndex={disabled ? -1 : 0}`.
  - `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.
  - `aria-orientation="horizontal" | "vertical"`.
  - `aria-disabled={disabled}`.
  - `aria-label` and `aria-valuetext` support.
- [x] Tick marks and labels rendering when `marks` prop is provided.
- [x] Value badge/display support when `showValue` is true.
- [x] Zero external npm dependencies, pure React (React 18), TypeScript, and CSS custom properties.
- [x] 100% diff-invariant across changes to `ir.description`.
- [x] Export `render_slider_component()` in `omnistackai_agent_engine.codegen` and register `components/slider.tsx` in `NextjsWebAdapter.generate()`.
- [x] Comprehensive unit tests in `services/agent-engine/tests/test_slider_component.py` passing cleanly (at least 13 tests).
- [x] Verification gates pass: `task verify`, `task lint`, `task security:quick`, `task env:check`, `task builder:demo`.
