# R-524: Chat edits use the provider's output budget (Gemini edits were cut off)

**Phase:** MVP (core loop on Google)
**Status:** COMPLETED
**Started:** 2026-09-21
**Completed:** 2026-09-21

## Objective

The R-523 smoke on Google failed twice at the chat edit with `model response was not valid JSON:
Unterminated string`. Chat edits always asked for at most 2,048 output tokens
(`DEFAULT_APP_DELTA_MAX_OUTPUT_TOKENS`) and discarded the provider's own budget (8,192 for
Gemini). Gemini counts its reasoning against that budget, so the reply was truncated mid-JSON.
Builds already use the provider budget.

## Fix

`_edit` and `_workspace_edit` pass `max_output_tokens = max(2,048, provider budget)` to
`generate_app_delta_proposal`. Local Ollama keeps 2,048 (its configured 1,024 is smaller).

## Gates

`test_studio_edit` `EditOutputBudgetTests` (fail first), `task verify`, `task lint`,
`task security:quick`, `task env:check`, and `./scripts/smoke-core.sh` on Google: 17/17.

## Gates & Evidence (real runs, 2026-09-21)

- `EditOutputBudgetTests` failed first (2 failures: the provider budget was ignored). Now
  `test_studio_edit` passes, including "never below 2,048".
- `task verify`: 3,946 OK, 0 model calls. `task lint`, `security:quick`, `env:check`: exit 0.
- `./scripts/smoke-core.sh` on Google (`gemini-3-flash-preview`), two consecutive runs: **17/17
