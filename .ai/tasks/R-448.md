### 2. Objectives
1. Implement Ecosystem Cross-Surface Webhook and Event Bridge Engine (`solution_packs/ecosystem_events.py`):
   - `WebhookRetryPolicy`: Configurable retry attempts, backoff, and timeout parameters.
   - `EcosystemWebhookSubscription`: Subscription ID, event type, source surface, target surface, webhook path, secret reference, retry policy, and active state.
   - `EcosystemEventPayload`: Standardized cross-surface event payload containing `event_id`, `event_type`, `ecosystem_id`, `source_surface`, `timestamp`, `entity_name`, `entity_id`, `action`, `data`, and `idempotency_key`.
   - `WebhookDeliveryRecord`: Canonical record of webhook delivery attempt including status (`delivered`, `failed`, `simulated`), HTTP status code, duration, attempt count, and error details.
   - `EcosystemEventBridgeContract`: Canonical specification of ecosystem event bridge parameters (signature algorithm `HMAC-SHA256`, signature header `X-OmniStack-Signature`, idempotency header `X-Idempotency-Key`, event type header `X-OmniStack-Event-Type`, secret reference, subscriptions, and supported event types).
   - Python 3.13 stdlib-only webhook signing & verification (`sign_webhook_payload`, `verify_webhook_signature`) with constant-time comparison (0 external dependencies, 100% offline).
   - In-process `EcosystemEventBridge`: Subscription management, event routing, bounded delivery logging (max 100 entries), and simulated or live HTTP delivery.
   - Deterministic contract synthesis (`synthesize_ecosystem_events`) deriving events and cross-surface subscriptions from entity definitions, lifecycle state flows, and surfaces.
2. Package & Registry Integration:
   - Update `EcosystemPackPackage` in `solution_packs/ecosystem_pack.py` with optional `event_bridge`, serializing, parsing, and verifying with checksums.
   - Update `synthesize_ecosystem_pack` to synthesize and bundle event bridge contracts.
   - Update `EcosystemPack` and `EcosystemPackRegistry` in `solution_packs/ecosystem_registry.py` with `get_event_bridge`.
   - Export all symbols in `solution_packs/__init__.py`.
3. Studio Preview & Server Integration:
   - In `StudioPreviewManager` (`studio/preview.py`), manage `EcosystemEventBridge`, inject `has_events` into preview payloads, and expose `get_ecosystem_events()` and `dispatch_ecosystem_event()`.
   - In `studio/server.py`, expose `GET /api/ecosystem/events` and `POST /api/ecosystem/events/dispatch`.
   - In `studio/live_serve.py`, wire handlers from the preview manager.
   - In `studio/page.py`, add `#preview-events-info` bar with event stats, a "Simulate Event" button/modal, and live delivery logs, strictly maintaining 0 external network requests.
4. CLI & Taskfile Tooling:
   - Add `events` subcommand in `solution_packs/ecosystem_cli.py` supporting both file paths and registered ecosystem IDs (`task agent-engine:solution-pack:ecosystem -- events <id|file>`).
   - Update `scripts/agent-engine.sh` and `Taskfile.yml`.
5. 100% Offline Verification in `task verify` (0 model calls). Python 3.13 stdlib only.
