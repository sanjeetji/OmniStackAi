## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Chat & Real-Time Messaging compound component suite (`components/chat.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ and native SVG icons.
- Conversational message bubbles with distinct styles for user, bot/agent, and system messages.
- Message status indicators: sending (clock/spinner), sent (single check), delivered (double check), read (colored double check).
- Timestamp grouping and date divider banners.
- Typing indicators with pulsing animated dots.
- Rich input bar with auto-expanding textarea, Enter to send, Shift+Enter for newline, and send button.
- Quick action pills / suggestion chips for rapid response.
- Media attachment previews (images, files) with metadata and download triggers.
- Multi-conversation thread sidebar (`ChatSidebar`) with unread badge counter, search filtering, and live online indicator dot.
- Auto-scroll to bottom with floating "Scroll to bottom" button when scrolled up.
- WAI-ARIA 1.2 log accessibility semantics (`role="log"`, `aria-live="polite"`, `role="list"`, `role="listitem"`).
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast crisp clean dark surface.
  - `"card"`: Bordered card surface with soft elevation.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)`.
  - `"neon"`: Cyberpunk glowing cyan/magenta theme with radiant halos and luminous message bubbles.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- Compound and semantic alias exports: `Chat`, `ChatWindow`, `ChatMessageList`, `ChatMessageItem`, `ChatInput`, `ChatHeader`, `ChatSidebar`, `Messenger`, `ChatWidget`, and default export (`ChatComponent`).
- React `forwardRef` and explicit `displayName` across compound exports.
- Imperative handle (`ChatHandle`): `scrollToBottom()`, `clearInput()`, `focusInput()`, `appendMessage(msg)`.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_chat_component.py`.
