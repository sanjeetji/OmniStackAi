## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Terminal & Command Console compound component suite (`components/terminal.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Interactive CLI command line prompt with customizable prefix (`"$ "`, `"> "` or `user@host:~ $`).
- Command history stack with keyboard navigation (ArrowUp / ArrowDown recall).
- Interactive command execution callback (`onCommand(cmd)`) returning stdout/stderr response or promise.
- ANSI color & style formatting parser (supporting standard 16-color ANSI codes e.g. red, green, yellow, blue, cyan, magenta, bold, dim, underline).
- Line types: `"stdout"`, `"stderr"`, `"command"`, `"system"`, `"info"`.
- Multi-tab terminal session manager (`TerminalTabs`, `TerminalTab`: `id`, `title`, `icon`, `closable`).
- Search / filter toolbar to filter output lines in real time.
- Action toolbar: copy entire buffer to clipboard with animated checkmark feedback, download buffer as `.txt` log file, clear screen.
- Keyboard shortcuts: `Ctrl+L` to clear screen, `Ctrl+C` to cancel prompt, `Tab` completion trigger.
- Max lines buffer limit with automatic scrolling to bottom (auto-scroll toggle).
- Window header bar with macOS-style window traffic light dots (red, yellow, green) and window title.
- WAI-ARIA 1.2 log & region accessibility semantics (`role="region"`, `role="log"`, `aria-live="polite"`, `aria-label="Terminal Console"`).
- 4 futuristic visual styling variants:
  - `terminal`: Classic CRT amber/green phosphor glow with subtle scanlines.
  - `neon`: Cyberpunk glowing cyan prompt with luminous violet accents.
  - `glass`: Frosted glassmorphic container with `backdropFilter: blur(16px)`.
  - `minimal`: High-contrast sleek dark developer console.
- 3 size scales: `sm` (font 11px), `md` (font 13px), `lg` (font 15px).
- React `forwardRef` and explicit `displayName` across compound exports: `Terminal`, `TerminalHeader`, `TerminalTabs`, `TerminalOutput`, `TerminalPrompt`, `ConsoleViewer`, `CommandLine`, default export `Terminal`.
- Imperative handle (`TerminalHandle`): `write(text, type?)`, `writeln(text, type?)`, `clear()`, `focus()`, `scrollToBottom()`, `getHistory()`, `getOutput()`, `execute(cmd)`.
- Zero external npm dependencies (pure React and native string parsing math).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_terminal_component.py`.
