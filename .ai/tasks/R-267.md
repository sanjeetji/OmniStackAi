## 1. Goal
Replace raw foreign key text inputs with typed parent relation selectors (`<select>` dropdowns) and automatic query parameter pre-population in generated Next.js forms:
- In `_form_screen_page`: Detect `RelationKind.MANY_TO_ONE` relations and foreign key fields on child entities (e.g. `article_id`, `driver_id`, `post_id`).
- When parent entity has `Op.LIST`, import and wire `useList<ParentPlural>()` from `"../lib/hooks"`.
- Replace raw text inputs for foreign key fields with accessible `<select>` dropdowns displaying parent title/name (`{String(item.title ?? item.name ?? item.id)}`), loading state placeholder, and required HTML5 / ARIA validation.
- Display contextual parent linkage badge (`&bull; Selected <Parent> linked`) when a foreign key value is selected or passed via URL.
- Pre-populate foreign keys from `searchParams` on form mount, checking parameter aliases (`article_id`, `articleId`, `article`).
- Ensure client-side required validation and field error display for foreign key selectors.
- Provide clean fallback safety for independent entities without relations (zero dropdowns/hooks emitted).
- Preserve byte-for-byte diff invariance across `ir.description` changes.
- Fully offline, 0 network, 0 external Python dependencies.
