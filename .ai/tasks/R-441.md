# R-441: Live Studio integration and UI controls for Solution Pack selection and modification

## Objective
Wire Solution Pack discovery, recommendation, selection, customization, and provenance into the OmniStackAI Studio web interface (`page.py`), live server (`live_serve.py`), HTTP server (`server.py`), and history tracking (`history.py`).

## Constraints & Requirements
1. **Zero External Resources in UI**: `STUDIO_HTML` in `studio/page.py` must remain 100% self-contained inline CSS and JavaScript. No external CDN, script, font, or CSS links (`http://`, `https://`, `src=`, `<link` remain strictly forbidden in HTML content).
2. **Deterministic & Offline**:
   - `GET /api/solution-packs` returns registered packs from `DEFAULT_SOLUTION_PACK_REGISTRY`.
   - `POST /api/solution-packs/recommend` returns prompt-based recommendation and domain classification.
   - Building with a selected pack requires 0 model calls and produces an owned, verified repository passing all target verification plans.
3. **Customization Controls**:
   - Allow user to specify custom project name and description.
   - Apply configuration changes immutably via `create_solution_pack_manifest` and `apply_solution_pack_manifest`.
4. **Provenance Transparency**:
   - Return full pack provenance (`pack_id`, `pack_version`, `base_ir_sha256`, `derived_ir_sha256`, `applied_configuration_change_ids`, `verify_targets`).
   - Display verified Solution Pack badges in Studio build result and history items.
5. **Quality Gates**:
   - All tests pass in `task verify` (fully offline).
   - `task lint`, `task security:quick`, `task env:check` pass.
   - Do NOT stage or touch `.claude/`.
