# Task Contract: R-444 — Solution Pack Multi-Surface Ecosystem Pack Synthesis

## Status
in_progress

## Phase
BASIC/MVP — Founder Stage 0

## Objective
Implement Solution Pack Multi-Surface Ecosystem Pack Synthesis (the 15th brick of the differentiating spine and 11th Solution Pack task). Enable synthesizing a coordinated multi-surface ecosystem (e.g. customer web, operator portal, admin dashboard) from a Solution Pack's unified data model, packaging the entire ecosystem into a byte-stable verifiable `EcosystemPackPackage` bundle, and providing CLI export, verification, inspect, and build capabilities.

## Requirements
1. `EcosystemPackPackage` and `EcosystemSurfacePackage` schema in `solution_packs/ecosystem_pack.py` with schema version `"1.0"`.
2. Whole-ecosystem checksum computation (`compute_ecosystem_checksum`) and strict canonical JSON serialization (`to_json()`, `to_dict()`).
3. `parse_ecosystem_pack_package()` strictly validates schema, semver, slugs, validates all embedded surface Application IRs with `validate_ir`, confirms `ir_sha256` matching for each surface, verifies package checksum, and fails closed with `SolutionPackError` on any corruption, drift, or mismatch.
4. Multi-surface synthesis (`synthesize_surface_ir` and `synthesize_ecosystem_pack`): derives surface-specific Application IRs from the pack's unified entity model, scoping entity visibility, mutation authority, actor roles, APIs, and screens per surface while maintaining relational integrity.
5. Ecosystem planner integration: `plan_ecosystem()` synthesizes secondary surfaces using the pack's authoritative data model when `pack_result` is provided.
6. Ecosystem pack CLI (`solution_packs/ecosystem_cli.py`): `synthesize`, `verify`, `inspect`, and `build` subcommands exposed via `scripts/agent-engine.sh` and `Taskfile.yml` (`task agent-engine:solution-pack:ecosystem`).
7. 100% offline verification in `task verify` (0 model calls). Python 3.13 stdlib only.
