# R-222 — First platform console slice (read-only model & cost overview)

## Requirement

Stand up the first slice of the visual platform console (Brief 8 product UI, 40/41 web/admin, 15.2
instant browser preview) under `apps/console-web`, surfacing the model fabric from R-005..R-221:
providers (local + all supported cloud, with tier / default model / active key-state), the Balanced
routing ladder, the price book, and the usage/cost dashboard from the R-009 ledger.

New IDs continue after the workbook backlog's R-010..R-219 (this is R-222).

## Approach and why (important)

Founder asked for the best/advanced industry-standard approach (Next.js) and a smooth, secure
platform. A full Next.js App-Router app was authored, but this sandbox's network repeatedly timed out
fetching Next's native SWC binary (`@next/swc-darwin-arm64`), so it cannot be installed or built here
and a frozen install would break the offline `task bootstrap`. To ship a working, verifiable, secure
console now, this slice is **dependency-free** (static `index.html` + `styles.css` + `app.js`) with
the **identical data contract and design**. The Next.js upgrade is the documented next step once the
build environment has reliable registry access; `data/overview.json` and the layout carry over.

## Acceptance criteria

- The console renders providers (local + all supported cloud, tier/default-model/active state), the
  Balanced routing ladder, the price book, and the usage/cost dashboard from a metadata-only snapshot.
- The snapshot is produced by the Python exporter and contains no key/secret (active state is a
  boolean); the page uses safe DOM APIs (`textContent`, never `innerHTML`) and a strict CSP meta tag;
  no external network requests.
- The Python exporter has offline tests, including a no-secret / active-without-key assertion; `app.js`
  passes a JS syntax check.
- `task bootstrap` stays offline; `task verify` stays green and independent of the console;
  `task console:snapshot` refreshes data and `task console:serve` serves it locally.

## Design notes

- Python `overview.py` `platform_overview()` returns a metadata-only dict (routing ladder, providers
  with active flags from env key presence, price book from `DEFAULT_PRICE_BOOK`, usage summary);
  `PriceBook.entries()` exposes prices read-only. CLI/`scripts/console.sh snapshot` writes
  `apps/console-web/data/overview.json`.
- Static console: `index.html` (CSP meta), `styles.css` (light/dark), `app.js` (fetches the
  same-origin snapshot, renders with safe DOM APIs). `task console:serve` serves via `python http.server`
  on loopback.

## Model and cost trace

Deterministic; no model call. No cloud key set; cloud_calls zero.
