## Requirements
Generated Next.js web application form screens (`_form_screen_page`) must support power-user keyboard shortcuts:
1. `Cmd+Enter` or `Ctrl+Enter` anywhere in the form (including textareas and inputs) triggers form submission:
   - Prevents default event.
   - Triggers `form.requestSubmit()` if not currently submitting/updating.
2. `Cmd+S` or `Ctrl+S` anywhere in the form triggers form submission:
   - Prevents default browser "Save Page As..." dialog.
   - Triggers `form.requestSubmit()` if not currently submitting/updating.
3. `Escape`:
   - When focused in an editable element (`INPUT`, `TEXTAREA`, `SELECT`), blurs the active element.
   - When focused outside editable elements, triggers cancel navigation to `cancel_href`, prompting confirmation if `isDirty`.
4. Event listener lifecycle is properly managed with window listener cleanup on unmount and dependency array.
5. 100% diff-invariant across `ir.description` changes.
6. Fully offline, standard-library-only platform code, 0 model calls.
