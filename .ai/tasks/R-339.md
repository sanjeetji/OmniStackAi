## 1. Objective

Provide a standalone, accessible, futuristic, zero-dependency Tag and Chip Tokenizer component suite (`components/tag-input.tsx`) across all generated OmniStackAI Next.js web applications.

Key features:
1. `TagItem` / `TagValue` type: string | `{ id: string; label: string; color?: string; disabled?: boolean }`
2. `TagInputVariant`: `"default"` | `"glass"` | `"neon"` | `"bordered"`
3. `TagInputSize`: `"sm"` | `"md"` | `"lg"`
4. `TagInputProps`:
   - `tags`: Array of active tags (controlled)
   - `onChange`: Callback when tags are added or removed
   - `suggestions`: Autocomplete options array
   - `maxTags`: Optional maximum allowed tags limit
   - `delimiters`: Custom keys/characters (default `["Enter", ","]`)
   - `allowDuplicates`: Boolean (default `false`)
   - `validateTag`: Custom validation function returning boolean or error string
   - `clearable`: Render a button to clear all tags
   - `placeholder`: Input placeholder text
   - `disabled` & `readOnly` states
5. Keyboard Navigation & WAI-ARIA 1.2:
   - `Backspace` on empty input focuses/deletes the previous tag
   - `ArrowLeft` / `ArrowRight` chip traversal
   - `ArrowDown` / `ArrowUp` autocomplete dropdown item selection
   - `Enter` / `Tab` commits suggestion or typed value
   - `Escape` closes suggestion dropdown
   - `role="combobox"`, `role="listbox"`, `role="option"`, `aria-expanded`, `aria-activedescendant`
6. Built-in vector icons:
   - TagIcon, XIcon, ClearIcon, ChevronDownIcon
7. 100% diff-invariance across `ir.description`, zero external npm dependencies.
