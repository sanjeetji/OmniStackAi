## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Pivot Table & Cross-Tabulation Matrix compound component suite (`components/pivot-table.tsx`) for Next.js web applications generated by OmniStackAI. The component supports:
- Multi-dimensional row and column grouping (e.g. `rows: ["region", "category"]`, `columns: ["year", "quarter"]`).
- Aggregation functions: `sum`, `avg`, `count`, `min`, `max`.
- Collapsible and expandable row hierarchy levels with chevron indicators.
- Automatic subtotals at each hierarchy level and global grand totals for rows and columns.
- Interactive sorting by dimension or metric values.
- Built-in search input filtering rows across dimension values.
- Cell selection callbacks (`onCellClick`, `selectedCell`).
- CSV export capability via imperative handle (`exportCsv`).
- WAI-ARIA 1.2 table/grid accessibility semantics (`role="table"`, `role="row"`, `role="columnheader"`, `role="rowheader"`, `role="gridcell"`, `aria-expanded`, `aria-sort`).
- 4 futuristic visual styling variants: `default`, `card`, `glass`, `neon` (with glowing cyan borders and radiant total cells).
- 3 size presets: `sm`, `md`, `lg`.
- React ref forwarding (`forwardRef`), explicit `displayName` across all exports.
- Compound and semantic alias exports: `PivotTable`, `CrossTab`, `MatrixTable`, `PivotCell`, `PivotHeader`, default export (`PivotTable`).
- Imperative handle (`PivotTableHandle`) with `expandAllRows`, `collapseAllRows`, `exportCsv`, `getAggregatedData`.
- Zero external runtime npm dependencies (pure React 18+ and native HTML table elements).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_pivot_table_component.py`.
