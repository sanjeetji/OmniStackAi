## Acceptance Criteria
1. `build_solution_pack_project` builds an owned Git repo for a `SolutionPackApplicationResult` or manifest + proposal, verified against its verify plans.
2. `SolutionPackBuildResult` records pack id, version, base/derived digests, applied/unapplied change IDs, verify targets, commit sha, and file count.
3. `plan_ecosystem` accepts optional `pack_result` or `pack_manifest` (+ `pack_proposal`) and wires the derived Application IR to the matching ecosystem surface.
4. `build_ecosystem` validates verify plans for all apps and captures pack provenance in `EcosystemAppBuild`.
5. Deterministic byte-stable JSON serialization for all result structures.
6. 100% offline verification in `task verify` (0 model calls).
