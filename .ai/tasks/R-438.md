## Acceptance Criteria
1. `AIDeltaProposal` is an immutable, frozen value object containing `pack_id`, `pack_version`, `base_ir_sha256`, `addressed_change_ids`, bounded `entities` (0–8 `Entity` records), `apis` (0–16 `ApiEndpoint` records), `screens` (0–16 `Screen` records), `capabilities` (0–16 slugs), and `rationale` (≤500 chars).
2. Manifests containing zero `ai-delta` changes bypass the provider completely, making 0 calls and returning an empty proposal.
3. `build_ai_delta_messages` constructs system and user messages embedding base IR context and exact pending manifest `ai-delta` change definitions without prompt injection vulnerability.
4. `parse_ai_delta_proposal` strictly validates untrusted model responses, rejecting unknown keys, missing required fields, controls, malformed types/identifiers, entity name collisions with base IR, and credential fields.
5. `generate_ai_delta_proposal` issues a single bounded `GenerateRequest` to `provider.generate()`, parsing and returning a validated `AIDeltaProposal` without mutating the base IR.
6. Verification runs fully offline with mock providers (0 real model calls in `task verify`), maintaining diff invariance and existing baseline test suite passes.
