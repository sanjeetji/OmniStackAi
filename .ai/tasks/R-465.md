# R-465: Grounded Hybrid UI Synthesis — LLM writes the UI over the deterministic typed data layer

**Phase:** MVP
**Status:** COMPLETED
**Started:** 2026-09-17
**Completed:** 2026-09-17

## Objective

First brick of the founder-approved **hybrid** generation engine: an LLM writes the modern Next.js UI, but
constrained to OmniStackAI's deterministic, typed data layer (the generated `lib/types.ts` / `lib/api.ts` /
`lib/hooks.ts`) and the existing design-token layer (`styles/tokens.css`), with a bounded
validation→feedback→retry loop and a deterministic-template fallback — so generated apps are both
modern AND verifiably wired to a real API + DB + auth. Model calls are **opt-in only** (Groq/Gemini via
`OMNISTACKAI_CLOUD_PROVIDER`, Ollama fallback) and **never run under `task verify`** (stub providers, 0 real calls).

The R-462 seed (`codegen/llm_ui.py`) hallucinated and looked generic because: the model was never shown the
real generated hooks (the prompt hand-described them and disagreed with reality — `refresh()` vs the real
`refetch()`, `page/pageSize` params vs the real `limit/offset`; it omitted `use<Entity>`,
`useUpdate/useDelete<Entity>`, `useList<Child>By<Rel>`, and advertised `useAuth` even when no auth-provider is
generated); it was told to hardcode hex colours although a full token layer exists; per-screen synthesis was
gated behind an env var set nowhere (`OMNISTACKAI_SYNTHESIZE_ALL_SCREENS`) with zero test coverage; a
validation failure's reason was discarded (one attempt); and the import whitelist had a multi-line bypass.

## Acceptance Criteria

- [x] `summarize_data_layer(ir)` (nextjs.py) renders the REAL typed surface by parsing the same generators'
      output — entity interfaces, the `Use*` interfaces, every exported hook signature (list/detail/subcollection
      + mutation hooks rendered from their bodies), `api.*` names — with a "NO data hooks" line when the IR has no
      entity-schema APIs; size-capped. A drift test proves every `use*` name/signature exists in `render_hooks(ir)`.
- [x] `summarize_components(ir)` lists the real `components/*.tsx` files with their real export names
      (from a new `_component_files(ir)` that reproduces the component file set byte-identically); the
      auth-provider/`useAuth` entry appears only when `needs_auth(ir)` and is listed first so the size cap can
      never drop it (the library is ~110 files; the cap was raised to 16k chars, 12 names per file).
- [x] `summarize_design_tokens()` lists the real `--color-*`, `--space-*`, … token names from `_DESIGN_TOKENS_CSS`.
- [x] Both prompt builders embed the three grounding blocks (lazily computed when not supplied), replace the
      drifting hook text, replace the hardcode-hex rule with token-based styling guidance, and make the
      `useAuth` rule conditional on `needs_auth(ir)`.
- [x] `clean_and_validate_jsx` checks imports with a multi-line-aware statement scanner (closing the bypass),
      allows exactly `react`/`react-dom` + the platform prefixes, and rejects `react-*` third-party packages,
      `require(`, and dynamic `import(`.
- [x] One `_synthesize_file` core with a bounded repair loop: on validator rejection, append the prior output
      (ASSISTANT, capped at 8k chars) + a corrective USER turn carrying the reason and retry, up to
      `max_attempts=3`; retry ONLY on validator rejection, NEVER on exceptions; then deterministic fallback with
      no marker (byte-equal to the template). Success marker:
      `// [OmniStackAI] Mode: LLM-Synthesized Bespoke UI (<model>; attempt k/N)`.
- [x] A JSON-safe, secret-free `UiSynthesisOutcome(path, mode, attempts, model_id, last_reason)` per file
      (`last_reason` is a validator reason or an exception TYPE NAME only).
- [x] Explicit `synthesize_screens: bool = False` + `ui_outcomes` threaded `NextjsWebAdapter.generate →
      assemble_project → build_app_from_ir / build_app_from_prompt`; the env gate and the unused `import os` are
      removed; default output is byte-identical (diff-invariance/snapshot tests untouched); no provider ⇒ deterministic.
- [x] Opt-in CLI `task agent-engine:ui:synthesize -- "<prompt>"` (`intake/ui_synthesize_run.py`, script case,
      Taskfile, COMMANDS.md) prints a per-file outcome table + repo path; warns on the local-Ollama context limit;
      provider errors (e.g. HTTP 429) exit cleanly with a bounded message, no traceback.
- [x] New `tests/test_llm_ui_grounding.py` (15 tests; stub providers, 0 real calls) covers grounding,
      no-hallucination, drift guard, tokens, components, repair success/exhaustion/exception, the switch,
      byte-identical default, import hardening, and the assemble/build threading. Existing tests updated
      honestly (the R-462 test IR gained real APIs; the drifted `page?`/`pageSize?` assertions became the real
      `limit?`/`offset?`). `task verify` green.
- [x] Live proof (opt-in, founder's Groq key) run and reported honestly — see Gates & Evidence.
