## Objective
Add an accessible, desktop-grade, zero-dependency, and futuristic Hover Card / Preview Card compound component suite (`apps/web/components/hover-card.tsx`) in the OmniStackAI Next.js application generator (`services/agent-engine`).

## Requirements & Acceptance Criteria
1. **Component Emitted**: `NextjsWebAdapter.generate()` emits `apps/web/components/hover-card.tsx` in all generated Next.js web applications. (Verified: `builder:demo` emits `components/hover-card.tsx` across minimal-blog and rideshare-favourites).
2. **Codegen Helper**: `omnistackai_agent_engine.codegen` exports `render_hover_card_component()`. (Verified in `codegen/__init__.py`).
3. **Compound Architecture**:
   - `HoverCard`: Root provider managing open/closed state (controlled and uncontrolled), trigger/content IDs, and configurable entrance/exit delays.
   - `HoverCard.Trigger`: Triggers card on pointer enter and keyboard focus, supports child element forwarding.
   - `HoverCard.Content`: Floating card with directional positioning, viewport edge collision clamping/flipping, backdrop styling, and entrance animations.
   - `HoverCard.Arrow`: Directional SVG pointer notch.
   - `useHoverCard()`: Context hook exposing internal state to custom components.
4. **Timing Physics**:
   - `openDelay`: Default 300ms, avoids accidental popups.
   - `closeDelay`: Default 200ms, permits smooth transit between trigger and content.
   - Seamless cursor transit keeping the card open when interacting with links/buttons inside.
5. **Positioning & Collision Avoidance**:
   - Sides: `"top"`, `"bottom"`, `"left"`, `"right"`.
   - Alignments: `"start"`, `"center"`, `"end"`.
   - Clamps coordinates to `window.innerWidth` and `window.innerHeight` with 8px margins.
6. **Visual Variants & Sizes**:
   - 4 variants: `"neon"`, `"glass"`, `"bordered"`, `"minimal"`.
   - 3 size presets: `"sm"` (260px), `"md"` (320px), `"lg"` (400px).
7. **Accessibility**:
   - `aria-haspopup="dialog"`, `aria-expanded`, `aria-controls` on trigger.
   - `role="dialog"`, `tabIndex={-1}` on content.
   - `Escape` dismisses card and restores trigger focus.
8. **Diff Invariance & Independence**:
   - Pure React (zero third-party npm packages).
   - 100% diff-invariant across `ir.description`.
