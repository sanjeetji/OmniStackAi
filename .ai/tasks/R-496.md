# R-496: Console — motion, states & polish (loading/error states, OG/meta, legacy CSS retired)

**Phase:** MVP
**Status:** COMPLETED
**Started:** 2026-09-19
**Completed:** 2026-09-19

## Objective

Sixth and last task of the Console UI overhaul (R-491..R-496). Every screen is now on the
R-491 stack; what remains is the finish: real loading and error states per Next 16's file
conventions, staggered entry motion that respects reduced-motion, OpenGraph/Twitter metadata
with a generated social image, a hover/active/focus sweep, and the deliberate retirement of the
last legacy CSS (the `.pill`/`.spinner` selectors and the dead token aliases the R-475 contract
block still pins) with that assertion edited. It closes with the redesign audit checklist
recorded honestly, item by item.

## Design (verified against Next 16's bundled docs and the real code)

- **Loading states** (`loading.js` convention — a Suspense fallback shown instantly on
  navigation): `app/studio/loading.tsx` (a skeleton of the two-column Studio grid so the layout
  doesn't jump) and `app/settings/loading.tsx` (page-header + section skeletons), both *under*
  their gated layouts. **Changed mid-task, found live**: a root `app/loading.tsx` was built and
  then removed — a Suspense boundary above the auth gates turns `redirect()` into a streamed
  200 carrying `<meta http-equiv="refresh">` and a `NEXT_REDIRECT` payload (signed-out `/`,
  `/studio`, `/settings` all answered 200 instead of 307). The dashboard and Settings now stream
  only their one network-dependent piece — the provider-status card — inside `<Suspense>` with a
  skeleton fallback *below* the gate, which is the pattern Next's own docs describe and keeps the
  real 307. A test.sh assertion now forbids a root `loading.tsx` with that note.
- **Error states** (`error.js` convention — must be a client component): `app/error.tsx` with
  the branded "Something went wrong" state, the `error.digest` shown as a mono reference when
  present (Next hides server error messages in production on purpose; the digest matches the
  server log), a **Try again** button on the documented `retry()` prop (Next 16's preferred API;
  `reset()` remains for the no-refetch case) and a Go home link; plus `app/global-error.tsx`
  for root-layout failures, which per the docs must ship its own `<html>`/`<body>` and gets no
  global styles — a minimal inline-styled page that matches the dark theme.
- **OG / meta**: `app/opengraph-image.tsx` via `ImageResponse` from `next/og` (built into
  Next, no dependency): the brand mark, wordmark and tagline on the dark background, 1200×630,
  with `alt`, `size`, `contentType` exports; `app/twitter-image.tsx` re-exports it. Root
  `metadata` gains `metadataBase`, `openGraph` and `twitter`. `metadataBase` is read from a new
  optional `OMNISTACKAI_CONSOLE_PUBLIC_URL` (added to `.env.example` with a comment; the console
  gets its env from the repo `.env` through `scripts/console.sh`), falling back to
  `http://127.0.0.1:<OMNISTACKAI_CONSOLE_PORT|4321>` — the real dev address — rather than an
  invented production domain.
- **Motion**: one `.reveal` utility in `globals.css` (`@keyframes rise`: 8px rise + fade,
  `transform`/`opacity` only, ~450ms, `animation-delay: calc(var(--reveal-index) * 60ms)`) and
  a `revealStyle(index)` helper in a new `lib/motion.ts`; applied to the dashboard header and
  cards, the settings sections, the fabric sections, the auth form card, the 404/error states,
  the Studio empty states and each new chat message. The existing `prefers-reduced-motion`
  block already collapses every animation, so nothing moves for users who asked it not to.
- **Hover/active/focus sweep**: every interactive element is checked for a hover and a visible
  `focus-visible` state; the few gaps found are fixed (recorded in evidence).
- **Legacy CSS retired**: `.pill`, `.pill--accent`, `.spinner`, `@keyframes spin`, the dead
  aliases (`--bg`, `--panel`, `--surface-2`, `--text`, `--accent-soft-*`, `--shadow`, `--ok-*`,
  `--off-*`, `--error-*` in both `:root` and `.dark`) and the "legacy aliases" comment text are
  removed; `--brand-soft*` stays (used by `::selection`), the `:root` `--radius-sm/md/lg`
  aliases stay (real Tailwind tokens; shadcn's own classes reference `var(--radius-md)`). The
  R-475 `scripts/test.sh` block is edited deliberately to assert only the three radius tokens.
- **No new dependencies; no API/lib data changes; no agent-engine/control-plane changes.**

## Gates & Evidence

**Console gates**: `pnpm run typecheck` and `pnpm run lint` clean; `pnpm run build` → **25
routes** (`/opengraph-image` and `/twitter-image` are new, both prerendered). **The contract
block's own first run failed on a shell detail**: `rg -qF "--shadow-tint"` parses a pattern that
starts with `--` as a flag; both loops now pass `--` before the pattern. `scripts/test.sh` then
passes; `task verify` → `Ran 3738 tests` / `OK` / `Stage 0 verification passed.` (checked for the
count line — it had run zero tests while `test.sh` failed); `task lint`, `task security:quick`,
`task env:check` pass (the optional `OMNISTACKAI_CONSOLE_PUBLIC_URL` sits in `.env.example` with
its comment; env-check only requires its own names to exist).

**A real regression, caught by the live smoke, fixed in-task.** With the root `app/loading.tsx`
in place, signed-out `/`, `/studio` and `/settings` returned **200** instead of the 307 every
earlier task had verified; the body carried `<meta http-equiv="refresh" content="1;url=/login">`
and `NEXT_REDIRECT;replace;/login;307` — Next's client-side fallback when `redirect()` fires after
a Suspense boundary above it has already started streaming. Fix: no root loading boundary; the
dashboard and Settings pages render their shell immediately and stream only the provider-status
card inside `<Suspense fallback={<skeleton/>}>` below the auth gate (`ProviderCard` /
`ProvidersSection` async server components). Re-verified: `/`, `/studio`, `/settings` signed out
→ **307 → /login**; `/login`, `/register` signed in → 307 → `/`; `/fabric` public 200; no
`http-equiv="refresh"` anywhere; the streamed cards render (dashboard: "Model provider", Ready,
"providers configured"; Settings: Ready, 11 provider cards, `ANTHROPIC_API_KEY` hint). Studio's
and Settings' own `loading.tsx` sit under their gated layouts, so they cannot cause this.

**Live smoke** (console rebuilt and restarted on 4321, detached with its own log): `<head>` on
`/login` carries `og:title`, `og:description`, `og:url`, **`og:image` =
`http://127.0.0.1:4321/opengraph-image?…`** (absolute, from `metadataBase`'s dev fallback),
`og:image:type/width/height/alt`, `og:type`, `twitter:card="summary_large_image"`,

## Redesign audit — final checklist (honest status)

- **Typography** — done: Geist / Geist Mono self-hosted; display tracking `-0.02em`;
  `text-wrap: balance` on headings, `pretty` on paragraphs; `tabular-nums` on every number;
  weights 400/500/600/700 in use.
- **Color & surfaces** — done: tinted OKLCH neutrals (hue 255), off-black never `#000`, one
  desaturated amber accent, tinted shadows (`--shadow-tint` → `shadow-sm/md/lg`), grain on the
  auth panel. *Not done, by choice*: no background imagery — this is a dev tool, not a marketing
  site; placeholder photography would be fake.
- **Layout** — done: asymmetric 7/5 dashboard (no three equal marketing cards), chat-left Studio
  grid at `100dvh`, 1180px containers, top navigation instead of a sidebar. *Noted*: the Studio
  empty state uses three small capability cards on purpose (an in-app list, not a hero).
- **Interactivity & states** — done: hover/active/`focus-visible` on nav, menu, tree rows, tabs,
  presets, prompts and all shadcn controls; `aria-current` navigation; skeletons for Studio and
  Settings routes, streamed provider cards, chat hydration, code loading, preview starting; empty
  states for thread, workspace, tabs, problems; error states for forms, chat, tabs, routes
  (`error.tsx`, `global-error.tsx`); `scroll-behavior: smooth`; motion on transform/opacity only,
  collapsed under reduced-motion.
- **Content** — done: sentence case, no exclamation-mark successes, no "Oops", no lorem, real
  example prompts (proven runnable in R-493), no invented numbers or names.
- **Components** — done: three-way theme control in Settings (not a sun/moon switch), rounded-
  square initials avatar, no modals, no pill "Beta" badges. shadcn cards use a 1px ring rather than
  border+shadow.
- **Iconography** — done with one recorded exception: Lucide is used deliberately (R-491) — one
  stroke family across the product beat differentiation for a dev tool; branded favicon and social
  image present.
- **Code quality** — done: semantic landmarks (`header`/`nav`/`main`/`aside`/`section`, skip
  link), inline styles only for dynamic values (tree indent, reveal index, preset width) and the
  isolated `global-error`, a small z-index scale (1 progress / 40 header / 50 overlays), title
  template + description + OG/Twitter meta. No dead code left in the stylesheet (330 lines).
- **Strategic omissions** — *honestly open*: no privacy policy / terms links because no such pages
  exist yet (nothing fabricated); no cookie banner because the only cookie is the httpOnly session
  and nothing tracks. Back navigation, custom 404, form validation and the skip link are done.
