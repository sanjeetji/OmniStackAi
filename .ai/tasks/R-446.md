### 2. Objectives
1. Enhance `StudioPreviewManager` (`services/agent-engine/src/omnistackai_agent_engine/studio/preview.py`):

   - Ensure `StudioBuildHistory` preserves the `surfaces` list for ecosystem entries.

   - Render tab buttons for each surface with status indicators (running/stopped), app name, and surface kind badge.
   - Allow 1-click surface switching via `POST /api/preview/switch` without iframe flicker or full page reload.
   - Add per-surface and global Stop/Restart buttons.
   - Add direct surface preview chips to recent ecosystem build cards in history.
   - Strictly maintain 0 external network requests (no external http/https/src/link/fonts).
