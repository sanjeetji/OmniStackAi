## 1. Goal
Enhance generated Next.js form screens (`apps/web/app/<screen.id>/page.tsx`) and the API client (`apps/web/lib/api.ts`) with real-time and server-side field-level validation feedback:
- Add `extractFieldErrors(error: unknown): Record<string, string>` helper in `lib/api.ts` that normalizes structured validation errors from Go backends (`{"errors": [{"field": "...", "rule": "...", "message": "..."}]}`) and FastAPI backends (`{"detail": [{"loc": ["body", "..."], "msg": "..."}]}`) into a clean key-value map.
- In generated form screens, declare and manage `fieldErrors` state (`Record<string, string>`).
- Highlight inputs with red borders (`#ef4444`) and `aria-invalid="true"` when errors are present.
- Render accessible field error messages directly below invalid inputs.
- Automatically clear the field's error when the user edits that input (`onChange`).
- Render `<select>` dropdowns for enum fields.
- Perform client-side pre-validation for required fields, `max_length`, and `min`/`max` constraints prior to network calls.
- Maintain byte-identical screen page outputs across IR description changes (diff invariance).
