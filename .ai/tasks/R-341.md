## Objective
Provide an accessible, highly optimized, and futuristic Radial Gauge & Activity Rings component suite (`components/radial-gauge.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Pure SVG arc trigonometry (`polarToCartesian`, `describeArc`) without third-party chart library dependencies.
- Single radial gauge mode supporting customizable angle sweeps (240° speedometer, 270° tachometer, 360° full circle), min/max range, threshold color transitions, target goal marker, and glowing indicator cap.
- Multi-ring concentric activity mode (`RadialGauge.Rings` / `ActivityRings`) with nested radius geometry, item icons, and interactive hover inspection.
- 4 futuristic visual variants: `"neon"` (cyberpunk glow filters), `"glass"` (translucent backdrop blur readout), `"gradient"` (smooth multi-stop SVG gradients), and `"minimal"`.
- Center readout slot with formatted numbers, unit suffixes (`%`, `GB`, `ms`, `RPM`, `req/s`), label/subtitle, or custom React children.
- Full WAI-ARIA compliance (`role="meter"`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-valuetext`, `aria-label`).
- 100% diff-invariant across `ir.description`; zero external npm runtime dependencies.
