# R-522: The Google (Gemini) provider actually runs builds

**Phase:** MVP (model gateway)
**Status:** COMPLETED
**Started:** 2026-09-21
**Completed:** 2026-09-21

## Objective

The founder added a Google API key. Every Studio start still logged "Failed to bootstrap cloud
provider 'google' (safe input and maximum output tokens must fit the context window); falling back
to Ollama". Once that was fixed, the first real build failed on one Gemini `503` ("model is
currently experiencing high demand").

## Defects

1. `model_gateway/bootstrap.py`: the cloud defaults are a 128,000 context, a fixed 120,000 safe
   input and Google's 8,192 output. 128,192 is more than 128,000, so **Google could never
   bootstrap**, whatever the key.
2. `model_gateway/cloud.py`: only a 429 was retried, and only for non-streaming calls. A temporary
   502/503/504 aborted the whole build, and opening a stream never retried at all.

## Fix

- The safe input defaults to `min(120,000, context - max_output)`. Explicitly configured values are
  still validated, never silently shrunk.
- 429 and 502/503/504 share the existing bounded backoff (provider hint or exponential, retry
  budget, max-wait cap) in `generate` and when opening a stream (nothing has been received yet, so a
  retry is safe). 500 still fails at once.

## Gates

`test_bootstrap` and `test_cloud_rate_limit` (new tests fail first), `task verify`, `task lint`,
`task security:quick`, `task env:check`, then a live `./scripts/smoke-core.sh` on Google.

  pass, and "500 is never retried" is still pinned.

- Live: no "Failed to bootstrap" line after the restart. The founder's key is valid.

    available to new users"). Pro models returned 429.
  - `gemini-3-flash-preview`, `gemini-3.6-flash`, `gemini-3.8-flash` and `gemini-3.5-flash-lite`
    answered.
  - `gemini-3.6-flash` hit the 120 s generation timeout on a real build.
- **Config change (founder's `.env`, not committed):** `OMNISTACKAI_GOOGLE_MODEL` changed from
  `gemini-3.5-flash` to `gemini-3-flash-preview`. The key is untouched. The old line is backed up in
  the session scratchpad.
- `./scripts/smoke-core.sh` on Google: **17/17**. Build 29 s (local Ollama: 124–243 s), preview
  ready in 5 s, home page 200, edit commit `26648df`.

## Notes

  usage count. The adapter then reports "token usage is invalid". Real builds use large budgets.
