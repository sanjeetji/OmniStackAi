## Delivered

1. **Database & Control-Plane (`services/control-plane`)**:
   - `migrations/000004_projects.up.sql` and `migrations/000004_projects.down.sql`:
     Creates `projects` table with UUID `id`, `user_id` foreign key, composite unique index `(id, user_id)`, `name`, `description`, `last_prompt`, `status` ('active'|'archived'), `state` ('created'|'building'|'ready'|'failed'), `entities`, `preview_url`, `opened_at`, `created_at`, `updated_at`.
   - `internal/projects/store.go`:
     `Store` interface and `PgStore` implementation with `CreateProject`, `GetProject`, `ListProjects`, `UpdateProject`, `DeleteProject` (soft archive and hard purge), `TouchProjectOpened`, and state/prompt updates with credit debits.
   - `internal/projects/handler.go`:
     Tenant-isolated REST endpoints mounted in `cmd/control-plane/main.go`: `GET /projects`, `POST /projects`, `GET /projects/{id}`, `PATCH /projects/{id}`, `DELETE /projects/{id}`, `POST /projects/{id}/opened`, `POST /projects/{id}/build/stream`, `POST /projects/{id}/edit`, `GET /projects/{id}/turns`, `GET /projects/{id}/files`, `GET /projects/{id}/file`, `GET/POST /projects/{id}/preview`, `GET/POST /projects/{id}/problems`.
   - `internal/projects/projects_test.go`:
     Unit test suite covering authentication, multi-tenant isolation (foreign project returns 404), soft archive/delete, and build/credit debiting (100% pass).

2. **Agent Engine (`services/agent-engine`)**:
   - `studio/workspace.py`:
     `StudioWorkspaceStore` managing disk workspaces under `~/.omnistackai/workspaces/<uuid>/`. Atomic `state.json` writes via temporary file and `os.replace`, append-only `turns.jsonl`, `ir.json` snapshot, and `.lock` flock file concurrency protection.
   - `studio/server.py`:
     Added `/api/workspaces/<id>` dispatch handlers (GET, POST, DELETE) with workspace mutex locking.
   - `studio/live_serve.py`:
     Added `_workspace_build`, `_workspace_build_stream`, and `_workspace_edit` functions.
   - `tests/test_studio_workspace.py`:
     Unit tests verifying persistence, roundtrip turns, IR saving, repo file reading, and atomic writes (8/8 pass).

3. **Console Web UI (`apps/console-web`)**:
   - `lib/control-plane.ts`:
     Added `Project` interface, `listProjects`, `createProject`, `getProject`, `updateProject`, `deleteProject`, `touchProjectOpened`, `streamProjectBuild`, `getProjectTurns`, `getProjectFiles`, `getProjectFile`, `editProject`, `previewProject`, `checkProjectProblems`, `getProjectProblems`.
   - `lib/time.ts`:
     Relative and absolute time formatting helpers.
   - 10 API route handlers in `app/api/projects/`:
     Secure cookie-authenticated proxy routes for all project operations.
   - `components/project-card.tsx`, `components/project-dialogs.tsx`, `components/project-switcher.tsx`, `components/home-projects.tsx`.
   - `app/projects/page.tsx`:
     Full project dashboard with search, active/archived tabs, sorting, and dialog operations.
   - `app/studio/[projectId]/page.tsx` and `app/studio/[projectId]/manage/page.tsx`:
     Studio project workspace routing and General project settings panel.
   - `app/studio/studio-chat.tsx` and `app/studio/studio-tabs.tsx`:
     Wired with `initialProjectId`, `ProjectSwitcher`, build streaming, and disk-persisted turn/file hydration.
