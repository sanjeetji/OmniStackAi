## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Gantt Chart & Project Roadmap compound component suite (`components/gantt-chart.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Interactive timeline and task bars with `id`, `name`, `startDate` (ISO), `endDate`, `progress` (0-100%), `color`, `dependencies` (`string[]`), and `milestone` (boolean).
- Visual task duration bars with proportional progress fill.
- Milestone diamond indicators for instantaneous events / target deadlines.
- SVG dependency connector lines and bezier arrows connecting predecessor tasks to successor tasks.
- Multi-scale timescale grid zoom levels: `"day"`, `"week"`, `"month"`.
- Synchronized header rows with year/month labels and day/week tick markers.
- Weekend column shading and vertical "Today" indicator line.
- Task list sidebar with task name, duration, and progress columns synchronized with the horizontal timeline scroll.
- Drag handles on task bar ends to adjust task duration (start/end dates) and task bar drag to reschedule.
- Task group collapsible hierarchy (phases / epics).
- Timescale navigation controls (Jump to Today, Zoom In, Zoom Out, Previous/Next period).
- WAI-ARIA 1.2 & keyboard accessibility (`role="treegrid"` or `role="grid"`, `role="row"`, `role="columnheader"`, `role="gridcell"`).
- 4 futuristic visual styling variants: `default`, `card`, `glass` (with `backdrop-filter: blur(16px)`), `neon` (cyberpunk glowing cyan/magenta theme with radiant progress bars and luminous dependency arrows).
- 3 size scales: `sm` (row height 32px), `md` (row height 44px), `lg` (row height 56px).
- React `forwardRef` and explicit `displayName` across all exports.
- Compound and semantic alias exports: `GanttChart`, `ProjectRoadmap`, `TimelineGantt`, `GanttTaskBar`, `GanttTimescale`, `GanttDependencyLine`, default export `GanttChart`.
- Imperative handle (`GanttChartHandle`) with `scrollToToday`, `zoomIn`, `zoomOut`, `exportSvg`, `getTasks`.
- Zero external npm dependencies (pure React and native SVG math).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_gantt_chart_component.py`.
