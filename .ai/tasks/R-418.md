# R-418: Chat studio web UI (chat-to-create front door, brick 3)

## Status
DONE

## Objective
Add the user-facing "chat -> create an app" screen: a minimal, dependency-free local web studio where a
person types a plain-English description and watches a real app get generated. New
`omnistackai_agent_engine/studio/` package (Python 3.13 stdlib only — `http.server`, no npm/pnpm, no web
framework): `page.py` holds a self-contained HTML page (inline CSS+JS, zero external deps) with a prompt
textarea, a "Build app" button, a building state, and a results panel; `server.py` provides
`create_studio_server(build_fn, host, port)` (a `ThreadingHTTPServer`) serving the page at `GET /` and
handling `POST /api/build` (reads `{prompt}` JSON, calls the injected `build_fn(prompt) -> dict`, returns the
result JSON; 400 on empty/invalid input, 502 on build failure) — the build function is injected so
`task verify` exercises the HTTP layer against an in-memory stub (0 model calls, 0 network); `live_serve.py`
is the opt-in entrypoint that wires the real local-Ollama `build_app_from_prompt` path and serves on
`OMNISTACKAI_STUDIO_HOST`/`OMNISTACKAI_STUDIO_PORT` (default 127.0.0.1:4173). Add
`app_build_result_to_dict(result)` to `intake/build_app.py` (pure, JSON-safe: name, description, entities,
file_count, target_dir, commit_sha, files) so the same shape is testable offline. Wire
`task agent-engine:studio:serve` (opt-in, live). Static page content is diff-invariant.
