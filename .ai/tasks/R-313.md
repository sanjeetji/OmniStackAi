## Objective
Elevate tabular data scanning and customization across generated Next.js web applications: emit an accessible column visibility dropdown ("Columns ▾") in the collection toolbar with role="menu", aria-label="Column visibility options", aria-haspopup="true", and aria-expanded state, containing checkbox toggle controls for each data column, guarding against hiding all columns (minimum 1 visible column), conditionally rendering `<th>` headers and `<td>` cells, maintaining 100% diff-invariance across `ir.description`, and preserving full backwards compatibility with colSpan, selection checkboxes, and actions column.

## Implementation Details
1. **State Management**:
   - `visibleColumns`: `Record<string, boolean>` initialized with all `display_fields` set to `true`.
   - `showColumnPicker`: boolean flag toggled by the toolbar button.
   - `toggleColumn`: function that flips visibility for a column while enforcing `currentVisible.length <= 1` guard so users cannot hide all columns.
2. **Accessible Toolbar Menu**:
   - Dropdown button with `aria-haspopup="true"`, `aria-expanded={showColumnPicker}`, and `aria-label="Toggle column visibility"`.
   - Dropdown menu container with `role="menu"` and `aria-label="Column visibility options"`.
   - Checkbox options for each field with `aria-label="Toggle {Column} column"`.
3. **Conditional Rendering**:
   - Header `<th>` elements wrapped in `{visibleColumns[field.name] !== false && (...)}`.
   - Row cell `<td>` elements wrapped in `{visibleColumns[field.name] !== false && (...)}`.
   - Actions/Details column and row selection checkboxes always preserved.
