# R-275 — Rich App Dashboard Overview Page in Generated Next.js Web App

**Status:** done
**Phase:** BASIC/MVP — Founder Stage 0
**Branch:** `main`
**Complexity:** L2

## Objective

Upgrade the generated Next.js app's home page (`app/page.tsx`) from a static bare-bones HTML
list into a rich, entity-aware dashboard overview page:

1. Make `app/page.tsx` a client component (`"use client"`) to enable live data hooks.
2. Call `useList<Entity>({ limit: 1 })` for each entity with `Op.LIST` wired, display `.total`
   as a live count badge in entity summary cards.
3. Render screen navigation cards for each primary screen (collection + form); exclude detail
   screens from the nav grid to keep navigation focused.
4. Render a "Quick Actions" section listing `+ Create {Entity}` CTAs linking to form screens.
5. Remove `ir.description` from the page body (it already appears in `README.md`) — this fixes
   the existing diff-invariance violation.
6. Fall back cleanly when `ir.entities` is empty (no hook calls, no cards).
7. Maintain strict diff invariance across `ir.description` changes; 100% offline, zero new IR
   fields, zero new npm dependencies.

## Acceptance criteria

1. `app/page.tsx` starts with `"use client";`.
2. Imports `useList<Entity>` hook for each entity with `Op.LIST` wired.
3. Calls `useList<Entity>({ limit: 1 })` and displays `.total` in an entity summary card.
4. Screen navigation cards render for collection and form screens with correct `href` (`/{screen.id}`).
5. Detail screens are excluded from the navigation card grid.
6. A Quick Actions section renders `+ Create {Entity}` link for each form screen.
7. `ir.description` is NOT present in the generated `app/page.tsx` output.
8. Page renders cleanly with no entities (no hook calls emitted, no broken imports).
9. Page renders cleanly with no screens (no nav cards section).
10. Role badge rendered for non-public screens in nav cards.
11. Strict diff invariance: identical `app/page.tsx` output for different `ir.description` values.
12. Stage 0 verification (`task verify`), `task lint`, `task security:quick`, `task doctor`,
    and builder demos pass.
