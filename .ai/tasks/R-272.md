## Goal
Enhance generated Next.js detail screens (`_detail_screen_page`) and connect collection screens (`_collection_screen_page`) to provide full-lifecycle deep linking, automated query param loading, cross-screen navigation, entity editing, deletion, and single-record JSON export:
- Auto-loading from Query Parameters: `_detail_screen_page` imports `useSearchParams` and `useEffect`, parses `searchParams.get("id")`, initializes `idInput` and `selectedId`, and automatically fetches the entity on mount without requiring manual typing.
- Detail Screen Actions (Edit & Delete):
  * "Edit {name}" link button navigating to `/{form_screen.id}?id=${selectedId}` when `can_edit` and `form_screen` exist.
  * "Delete {name}" button invoking `useDelete<Entity>()` with confirmation prompt, loading state (`deletingMain`), error banner (`deleteMainError`), and state cleanup (`setSelectedId(null); setIdInput("");`) when `can_delete` is True.
- Single-Record Data Export: "Export JSON" button downloading formatted JSON (`{name.lower()}_{id}.json`) via client-side Blob and temporary anchor lifecycle with `URL.revokeObjectURL(url)`.
- Collection Table Integration: When a dedicated detail screen exists in the IR, collection table rows render a styled "View" link button (`/{detail_screen.id}?id=${item.id}`) in the actions cell.
- Breadcrumb Navigation: Header breadcrumb renders `<Link href="/{collection_screen.id}">&larr; Back to {plural}</Link>` when a complementary collection screen is detected.
- Strict diff invariance across `ir.description` modifications.
- 100% offline, zero network calls, zero external dependencies.

## Acceptance Criteria
1. Detail screen imports `useSearchParams` and `useEffect`.
2. Detail screen initializes state from `searchParams.get("id")`.
3. Detail screen synchronizes state via `useEffect` when `queryId` changes.
4. Detail screen binds to `use<Entity>(selectedId)` hook.
5. Detail screen renders "Edit <Entity>" link to form screen when edit is supported.
6. Detail screen omits "Edit <Entity>" link when form screen is absent.
7. Detail screen imports and wires `useDelete<Entity>()` hook and `handleDelete` when deletable.
8. Detail screen renders "Delete <Entity>" button with confirmation prompt and loading indicator.
9. Detail screen omits delete hook and button when entity lacks DELETE route.
10. Detail screen renders "Export JSON" button with Blob and dynamic anchor download lifecycle.
11. Detail screen renders breadcrumb link back to collection screen when present.
12. Detail screen falls back to Overview breadcrumb when collection screen is absent.
13. Collection screen renders "View" link button to dedicated detail screen when one exists.
14. Collection screen omits "View" detail link when no detail screen is defined.
15. Strict diff invariance maintained across `ir.description` modifications.
16. Full project generation succeeds across example IRs.
17. `task verify` (646 tests) green; zero network calls; zero external dependencies.
