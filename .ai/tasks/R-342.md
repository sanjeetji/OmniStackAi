## Objective
Provide an accessible, highly optimized, and futuristic Segmented Control & Mode Switcher component suite (`components/segmented-control.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone SegmentedControl compound component with sliding pill indicator animation.
- Options support labels, icons, disabled state, and notification badges.
- 4 futuristic visual variants: `"neon"` (cyberpunk glow with cyan accent), `"glass"` (translucent backdrop blur `12px`), `"pills"` (elevated rounded pill tabs), and `"minimal"`.
- 3 size presets: `"sm"` (28px height, 12px text), `"md"` (36px height, 14px text), `"lg"` (44px height, 16px text).
- Controlled and uncontrolled operation modes (`value`, `defaultValue`, `onChange`).
- Full keyboard navigation and WAI-ARIA `role="radiogroup"` / `role="radio"` compliance (`ArrowLeft`/`ArrowRight` cycling, `Home`/`End` jump, `aria-checked`, `aria-disabled`).
- 100% diff-invariant across `ir.description`; zero external npm runtime dependencies.
