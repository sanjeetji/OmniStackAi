## Objective
Provide an accessible, highly optimized, and futuristic Resizable Panel & Splitter layout compound component suite (`components/resizable.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone compound suite: `ResizablePanelGroup` (or `Resizable`), `ResizablePanel`, `ResizableHandle` (with inline SVG grip dots / affordance).
- Pure React + pointer/touch events with zero third-party layout dependencies (no react-resizable-panels, react-split, etc.).
- 4 futuristic visual variants: `"neon"` (cyberpunk glowing cyan divider line on hover/active), `"glass"` (translucent frosted divider with backdrop blur), `"bordered"` (sleek slate border line with centered grip dots), and `"minimal"` (clean 1px line with expanded invisible hit-area).
- Layout directions: `"horizontal"` (side-by-side split) and `"vertical"` (stacked split).
- Precision pointer dragging and touch gesture handling with live size percentage calculation.
- Min and max constraints (`minSize`, `maxSize`, `defaultSize`).
- Collapsible panel support (`collapsible`, `collapsedSize`, `onCollapse`, `onExpand`).
- Keyboard navigation adhering to WAI-ARIA Separator (Window Splitter) Pattern (`ArrowLeft`/`Right` or `ArrowUp`/`Down` with 1% step and 5% with Shift, `Home` to collapse, `End` to expand to max, `Enter` to toggle collapse).
- Full WAI-ARIA accessibility semantics (`role="separator"`, `aria-orientation`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-label`, `tabIndex={0}`).
- 100% diff-invariant across `ir.description`; zero external npm runtime dependencies.
