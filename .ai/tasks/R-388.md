## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic PDF & Document Viewer compound component suite (`components/pdf-viewer.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ hooks and native inline vector SVGs.
- Multi-page document navigation: Page indicator, jumper input (`Page X of Y`), next/prev/first/last page controls.
- Interactive Zoom Engine: Zoom In, Zoom Out, presets (`50%`, `100%`, `150%`, `200%`), "Fit to Width" and "Fit to Page" auto-scaling.
- Page Rotation: 90° clockwise and counter-clockwise rotation per page or document.
- Thumbnails Navigation Drawer (`PdfThumbnails`): Slide-over sidebar showing miniature page cards with clickable jump navigation.
- In-Document Search: Search bar with match counter (`Match X of Y`) and Next/Prev match navigation.
- View modes: Single-page mode and continuous vertical scroll mode (`"single"` | `"continuous"`).
- Action Toolbar: Print affordance, download action trigger, and presentation/fullscreen toggle.
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast slate dark document workspace with clean page shadows.
  - `"card"`: Bordered elevated card with soft drop-shadow.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)` HUD toolbars.
  - `"neon"`: Cyberpunk glowing neon theme with radiant cyan document borders and luminous highlight accents.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- WAI-ARIA 1.2 document & toolbar semantics (`role="region"`, `role="toolbar"`, `aria-label="Document Viewer"`, keyboard navigation).
- React `forwardRef` and `useImperativeHandle` (`PdfViewerHandle`): `nextPage()`, `prevPage()`, `goToPage()`, `zoomIn()`, `zoomOut()`, `setZoom()`, `rotate()`, `search()`.
- Compound and semantic alias exports: `PdfViewer`, `DocumentViewer`, `FileViewer`, `PdfThumbnails`, `PdfToolbar`, `PdfPageCanvas`, and default export (`PdfViewerComponent`).
- Explicit `displayName` across all compound exports.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_pdf_viewer_component.py`.
