## Objective
Provide an accessible, production-grade, zero-dependency, and futuristic **PIN & OTP Code Input** component suite (`apps/web/components/pin-input.tsx`) in Next.js web applications generated by OmniStackAI.
Features:
- Standalone compound suite: `PinInput` (with compound aliases `PinInput.Group`, `PinInput.Slot`, `PinInput.Separator`).
- Exports TypeScript interfaces: `PinInputVariant` (`"neon"` | `"glass"` | `"bordered"` | `"minimal"`), `PinInputSize` (`"sm"` | `"md"` | `"lg"`), `PinInputType` (`"numeric"` | `"alphanumeric"` | `"password"`), `PinInputProps`, `PinInputGroupProps`, `PinInputSlotProps`, `PinInputSeparatorProps`, `PinInputContextValue`.
- Multi-slot discrete character cells (configurable `length`, default 6).
- Auto-advance on keystroke to next slot upon entering a valid character.
- Auto-retreat on Backspace to previous slot when deleting.
- Smart clipboard paste distribution across slots (e.g. pasting `"849201"` populates all 6 slots).
- Masking/conceal options for security codes and PINs (`type="password"` or delayed bullet `•` mask).
- Native browser autofill support via `autocomplete="one-time-code"`.
- Full keyboard navigation (`ArrowLeft`/`ArrowRight`, `Backspace`, `Delete`, `Home`, `End`).
- Full WAI-ARIA 1.2 accessibility semantics (`role="group"`, `aria-label`, individual slot labelling).
- 4 futuristic visual variants: `"neon"` (cyberpunk glowing border with cyan/purple active slot aura), `"glass"` (translucent frosted background), `"bordered"` (clean slate border frame), and `"minimal"` (bottom-line underline slots).
- 3 size presets: `"sm"`, `"md"`, `"lg"`.
- 100% diff-invariant across `ir.description`; zero external npm packages.
