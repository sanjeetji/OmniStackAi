## 1. Objective

Provide a standalone, accessible, zero-dependency reusable File Upload / Dropzone component suite (`components/file-upload.tsx`) in all generated OmniStackAI Next.js web applications. The component must support:
1. `FileUpload` component:
   - `FileUploadStatus`: `"idle"` | `"dragging"` | `"uploading"` | `"success"` | `"error"`.
   - `FileUploadVariant`: `"default"` | `"compact"` | `"avatar"`.
   - `FileEntry`: `id`, `file`, `name`, `size`, `type`, `progress`, `status`, `error`, `previewUrl`.
   - Drag-and-drop zone with drag-over visual feedback (`onDragOver`, `onDragLeave`, `onDrop`).
   - Click-to-browse via accessible hidden `<input type="file">`.
   - Keyboard interaction: `Enter` / `Space` trigger file picker.
   - Validation: MIME types / extensions (`accept`), maximum file size (`maxSize`), maximum file count (`maxFiles`).
   - File preview list: thumbnail preview for images, formatted size (`formatBytes`), upload progress bar (`role="progressbar"`), remove button.
   - Avatar variant: circular dropzone with camera overlay icon for profile image uploads.
   - WAI-ARIA accessibility: `role="button"`, `tabIndex={0}`, `aria-label`, `aria-describedby`, live announcements (`aria-live="polite"`), `aria-disabled`.
2. Framework requirements:
   - Pure React 18, TypeScript, zero external npm dependencies.
   - Inline styles and CSS custom properties (`var(--color-primary, #2563eb)`, `var(--color-border, #e2e8f0)`, etc.).
   - 100% diff-invariant across changes to `ir.description`.
   - Registered in `NextjsWebAdapter.generate()`.
   - Exported in `omnistackai_agent_engine.codegen`.
