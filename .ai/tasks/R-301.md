## Objective
Enhance user experience and keyboard workflow across generated Next.js web application screens (`apps/web/app/<screen>/page.tsx`):
1. Collection Screen Search Clear Button:
   - In collection search form, wrap the search input in an accessible container with an interactive Clear (`×`) button rendered conditionally when `searchInput` is non-empty (`Boolean(searchInput)`).
   - Clicking Clear resets `searchInput` (`setSearchInput("")`), commits empty search (`setSearch("")`), and refocuses the search input (`searchInputRef.current?.focus()`).
   - Button emits `type="button"`, `aria-label="Clear search"`.
2. Subcollection Master-Detail Search Clear Button:
   - In subcollection search form (`_subcol_controls`), render an interactive Clear (`×`) button when controlled search query is non-empty.
   - Clicking Clear resets local state (`{search_setter}("")`) and commits empty search (`{s_var}.setSearch("")`).
   - Button emits `type="button"`, `aria-label="Clear <child_plural> search"`.
3. Form Screen First-Field AutoFocus:
   - In form screens (`_form_screen_page`), automatically emit `autoFocus` on the very first editable field (`idx == 0` among `editable_fields`), whether it is a text input, textarea, numeric input, parent relation select, or checkbox.
   - Subsequent fields (`idx > 0`) do not emit `autoFocus`.

## Invariance & Constraints

- Strict diff invariance across `ir.description`.
- Zero network or cloud model calls.
- Preserves all existing search debounce, keyboard navigation, and field error behaviors.
