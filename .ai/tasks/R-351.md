Emit a dedicated, accessible, desktop-grade, zero-dependency, and futuristic Collapsible / Disclosure compound component suite (`apps/web/components/collapsible.tsx`) via `NextjsWebAdapter.generate()`, providing compound subcomponents, smooth CSS grid expand/collapse transitions, full WAI-ARIA 1.2 disclosure pattern semantics, rotating indicator chevrons, 4 visual variants, and 3 size presets.

## Requirements
1. **File Generation**: `NextjsWebAdapter.generate()` emits `apps/web/components/collapsible.tsx` with `"use client"` directive.
2. **Export**: `omnistackai_agent_engine.codegen` exports `render_collapsible_component()`.
3. **Compound Architecture**:
   - `Collapsible` root component.
   - `Collapsible.Trigger` (`CollapsibleTrigger`).
   - `Collapsible.Content` (`CollapsibleContent`).
   - `useCollapsible()` context hook.
4. **Smooth Expansion**:
   - CSS grid row animation (`gridTemplateRows: open ? "1fr" : "0fr"`) with `overflow: "hidden"` container.
   - No hardcoded max-height bounds; animates accurately to arbitrary content dimensions without layout jumps.
5. **WAI-ARIA 1.2 Disclosure Semantics**:
   - Trigger: `<button type="button" aria-expanded={open} aria-controls={contentId} id={triggerId} aria-disabled={disabled}>`.
   - Content: `<div id={contentId} role="region" aria-labelledby={triggerId} hidden={!open && !isAnimating}>`.
   - Keyboard: `Enter` and `Space` activation on trigger.
6. **Variants & Sizing**:
   - 4 visual variants: `"neon"`, `"glass"`, `"bordered"`, `"minimal"`.
   - 3 size presets: `"sm"`, `"md"`, `"lg"`.
7. **Diff Invariance & Dependency Free**:
   - 100% diff-invariant across `ir.description`.
   - Pure React (zero external npm dependencies).
