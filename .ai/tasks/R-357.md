## Objective
Emit a standalone, accessible, zero-dependency, desktop-grade, and futuristic Announcement Banner & Callout compound component suite (`apps/web/components/banner.tsx`) in Next.js web applications generated by `NextjsWebAdapter`.

## Requirements
1. **WAI-ARIA Semantics**:
   - Container emits `role="status"` or `role="alert"` (for error/warning) and `aria-live="polite"` or `aria-live="assertive"`.
   - Close button emits `aria-label="Dismiss banner"`.
2. **Layout Positions**:
   - `"top"`: Sticky or fixed banner pinned to viewport top.
   - `"bottom"`: Sticky or fixed banner pinned to viewport bottom.
   - `"inline"`: Normal document flow block callout with rounded borders.
   - `"floating"`: Floating pill/card banner with elevated shadow and center alignment.
3. **Interactive Features**:
   - Dismissable with smooth collapse transition (`dismissible?: boolean`, `onDismiss?: () => void`).
   - Action CTA slot (`action?: React.ReactNode`).
   - Custom icon slot or built-in vector icons (info, check, alert, flame/neon).
4. **6 Futuristic Visual Variants**:
   - `"info"`, `"success"`, `"warning"`, `"error"`, `"neon"` (cyberpunk cyan glow), `"gradient"` (futuristic violet-indigo linear gradient).
5. **3 Size Scales**:
   - `"sm"`, `"md"`, `"lg"`.
6. **Compound Subcomponents & Standards**:
   - `Banner`, `BannerAction`, `BannerCloseButton`, `BannerIcon`, `AnnouncementBanner`, `Callout`.
   - Full React `forwardRef` and explicit `displayName`.
   - 100% diff-invariance across `ir.description`.
   - Zero external runtime npm dependencies (pure React).
