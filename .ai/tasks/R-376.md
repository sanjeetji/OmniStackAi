## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Media Player & Audio/Video Controller compound component suite (`components/media-player.tsx`) for Next.js web applications generated by OmniStackAI. The component supports:
- Dual media modes:
  1. `video`: High-definition video player with aspect ratio container, poster image, overlay controls, fullscreen, and Picture-in-Picture.
  2. `audio`: Compact audio player layout with cover art, track and artist info, visual playback progress, and controls.
- Full Custom Control Suite:
  - Play/Pause toggle with animated indicator.
  - Interactive Scrubber / Seek Bar with loaded buffer progress, played progress bar, and hover timestamp preview tooltip.
  - Volume slider with mute toggle and dynamic volume level icons.
  - Playback rate selector (`0.5x`, `0.75x`, `1x`, `1.25x`, `1.5x`, `2x`).
  - Skip forward/backward (10s intervals).
  - Fullscreen & Picture-in-Picture triggers.
  - Formatted time display (`MM:SS` or `HH:MM:SS`).
  - Closed captions / subtitle track support.
- Keyboard Navigation:
  - `Space` / `K` for Play/Pause.
  - `ArrowLeft` / `ArrowRight` to seek (±5s).
  - `ArrowUp` / `ArrowDown` to adjust volume (±10%).
  - `M` for Mute/Unmute.
  - `F` for Fullscreen.
  - `P` for Picture-in-Picture.
- WAI-ARIA media semantics (`role="region"`, `aria-label="Media Player"`, `role="slider"`, `aria-valuenow`).
- 4 futuristic visual styling variants: `default`, `card`, `glass`, `neon` (with glowing cyan borders and radiant scrubber glow).
- 3 size presets: `sm`, `md`, `lg`.
- React ref forwarding (`forwardRef`), explicit `displayName` across all exports.
- Compound and semantic alias exports: `MediaPlayer`, `VideoPlayer`, `AudioPlayer`, `MediaControls`, `MediaScrubber`, `VolumeSlider`, default export (`MediaPlayer`).
- Imperative handle (`MediaPlayerHandle`) with `play`, `pause`, `togglePlay`, `seek`, `setVolume`, `toggleMute`, `toggleFullscreen`, `togglePiP`, `getElement`.
- Zero external runtime npm dependencies (pure React 18+ and native HTML5 `<video>` / `<audio>`).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_media_player_component.py`.
