# R-241 — Authentication guards from the IR

## Requirement

Make the IR's per-endpoint `auth` flag real (Brief §9/§27/§55): every endpoint with `auth=true` enforces
an authentication guard that rejects a request with no bearer credential (HTTP 401) before the handler
runs. The IR `roles` are surfaced as a generated constant for future per-endpoint authorization. Token
verification (signature, expiry, roles) is a deliberate TODO in the generated code — not faked. Emitted
only when the IR declares at least one `auth=true` endpoint; applies to both DB and non-DB backends.
Deterministic and offline; nothing runs. Committed directly to `main`. New IDs continue after the
backlog's R-010..R-219 (this is R-241).

## Acceptance criteria

- Python: emits `app/auth.py` (a `require_auth` FastAPI dependency that 401s without an
  `Authorization: Bearer <token>` header); each `auth=true` route declares
  `dependencies=[Depends(require_auth)]`; `auth=false` routes are unchanged. Routers parse as valid
  Python.
- Go: emits `internal/handlers/auth.go` (a `RequireAuth(next)` middleware that 401s without a bearer
  token); `main.go` wraps exactly the `auth=true` endpoints with `handlers.RequireAuth(...)`;
  `auth=false` endpoints register directly.
- The IR roles are surfaced as a generated constant (Python `ROLES` tuple, Go `Roles` slice) of role
  names; generated code notes that per-endpoint role enforcement is future work.
- Nothing emitted when no endpoint requires auth; byte-stable; nothing runs.
- Offline tests cover guard emission + gating, per-route wrapping for auth vs public endpoints, and the
  roles constant.

## Design notes

- New `codegen/auth_guard.py`: `python_auth_file(ir)` and `go_auth_file(ir)` returning the guard file
  content (including the roles constant), plus a small `needs_auth(ir)` helper.
- `backend_python.py`: `_router_file` adds `Depends`/`require_auth` imports and
  `dependencies=[Depends(require_auth)]` on `auth=true` routes; `generate` emits `app/auth.py` when
  `needs_auth`.
- `backend_go.py`: `generate` emits `internal/handlers/auth.go` when `needs_auth`; `_main_file` wraps
  `auth=true` registrations with `handlers.RequireAuth(...)`.
- Two existing adapter-test assertions (decorator / registration substrings) updated to the guarded
  form. No secret; no network; nothing executed.
