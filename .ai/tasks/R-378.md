## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Image Cropper & Canvas Mask compound component suite (`components/image-cropper.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Interactive crop marquee bounding box with draggable center and 8 resize handles (corners and edges).
- Aspect ratio constraints: `"free"`, `"1:1"` (square), `"4:3"`, `"16:9"`, and `"circular"` (for avatars).
- Zoom scaling (0.5x to 3x) and rotation controls (90° steps and continuous slider -180° to +180°).
- Flip horizontal and vertical.
- High-DPI `<canvas>` transformation rendering and export (`toDataURL`, `toBlob`, `getCroppedCanvas`).
- Real-time crop preview thumbnail (`CropPreview`).
- WAI-ARIA 1.2 accessibility semantics (`role="region"`, `aria-label="Image Cropper"`, `aria-roledescription="image cropping canvas"`).
- Keyboard arrow key nudging (`ArrowLeft`, `ArrowRight`, `ArrowUp`, `ArrowDown`).
- 4 futuristic visual styling variants: `default`, `card`, `glass`, `neon` (with glowing cyan crop borders and luminous handles).
- 3 size presets: `sm`, `md`, `lg`.
- React ref forwarding (`forwardRef`), explicit `displayName` across all exports.
- Compound and semantic alias exports: `ImageCropper`, `AvatarCropper`, `CropCanvas`, `CropToolbar`, `CropPreview`, default export (`ImageCropper`).
- Imperative handle (`ImageCropperHandle`) with `crop`, `reset`, `rotate`, `zoom`, `flipH`, `flipV`, `toDataURL`, `getCropData`.
- Zero external runtime npm dependencies (pure React 18+ and native HTML5 `<canvas>` / pointer APIs).
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_image_cropper_component.py`.
