## Objective
Generate a zero-dependency, desktop-grade, futuristic, and accessible Keyboard Keycap and Shortcut Badge component (`components/kbd.tsx`) for the OmniStackAI Next.js application generator. The component provides:
1. Semantic `<kbd>` element rendering with accessible `aria-label` / `role="group"` / `aria-keyshortcuts`.
2. Automatic symbol mapping for modifier keys (`command`/`meta` -> `⌘`, `shift` -> `⇧`, `ctrl` -> `⌃`, `alt`/`option` -> `⌥`, `enter` -> `↵`, `backspace` -> `⌫`, `esc` -> `Esc`, arrows, etc.).
3. 5 visual variants: `default` (3D tactile elevated keycap with bottom border and shadow), `outline`, `subtle`, `ghost`, and `neon` (cyberpunk glowing cyan/indigo).
4. 4 size scales: `xs`, `sm`, `md` (default), and `lg`.
5. Support for key combination arrays (`keys`), custom separators (`separator`), and string shortcuts (`KbdShortcut`).
6. Composite container `KbdGroup` for chaining key combinations with uniform sizing/variants.
7. Ref forwarding for all components (`Kbd`, `KbdGroup`, `KbdShortcut`).
8. Snapshot diff invariance across `ir.description`.
