# R-413: Accessible Futuristic Reusable Copy-to-Clipboard Button Suite (`components/copy-button.tsx`)

## Status
DONE

## Objective
Add an accessible, zero-dependency, desktop-and-mobile-grade, futuristic Copy-to-Clipboard Button compound component suite (`components/copy-button.tsx`): copies a given `value` to the clipboard via `navigator.clipboard.writeText` with a `document.execCommand('copy')` textarea fallback, shows a transient "Copied" state (configurable `timeout`) with a swapped inline SVG icon (copy → check) and an `aria-live` announcement, disables when there is nothing to copy, and exposes `onCopy`/`onError` callbacks; WAI-ARIA (button with `aria-label`, visually-hidden `aria-live` status); 4 futuristic visual styling variants ("default", "card", "glass", "neon"); 3 size scales ("sm", "md", "lg"); React ref forwarding (`forwardRef`); `useImperativeHandle` (`CopyButtonHandle`: `copy`/`isCopied`/`reset`/`focus`); and explicit `displayName` across compound and semantic alias exports (`CopyButton`, `CopyToClipboard`, `ClipboardButton`, `CopyIconButton`, default export). Static module constant — never references `ir.name`/`ir.description`; ASCII-only source (inline SVG, no unicode glyphs).
