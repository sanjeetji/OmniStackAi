# Task Contract: R-319 — Generated Accessible Reusable Avatar Component (components/avatar.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Visual identity representations such as user profile icons, author attribution badges in blog posts, driver avatars in ridesharing, assignee pills, and comment authors are ubiquitous across enterprise web applications.

To provide this capability in generated applications, the platform needs a standalone, accessible, reusable compound Avatar component (`apps/web/components/avatar.tsx`). Like previously implemented UI primitives (`components/badge.tsx`, `components/tooltip.tsx`, `components/card.tsx`, `components/alert.tsx`, `components/skeleton.tsx`, `components/drawer.tsx`), the Avatar component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and strictly adhere to WAI-ARIA image and status accessibility specifications.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/avatar.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Subcomponents**:
   - `Avatar` (individual user avatar supporting image, initials, and SVG fallback with optional presence status indicator).
   - `AvatarGroup` (overlapping cluster of avatars with configurable `max` count and `+N` excess overflow badge).
3. **Shapes & Sizes**:
   - `AvatarShape = "circle" | "rounded" | "square"`.
   - `AvatarSize = "xs" | "sm" | "md" | "lg" | "xl"` with standardized pixel dimensions and proportional font sizes.
4. **Presence Status Indicators**:
   - `AvatarStatus = "online" | "offline" | "busy" | "away"`.
   - Corner dot with matching status colors (`#22c55e`, `#94a3b8`, `#ef4444`, `#f59e0b`) and accessible status label.
5. **Fallback Cascade & Deterministic Color Hashing**:
   - Level 1: Image URL (`src` with `onError` detection).
   - Level 2: Initials extracted from `name` (e.g. "Jane Doe" -> "JD"), with deterministic background color hash from a curated accessible palette.
   - Level 3: Generic accessible vector user silhouette SVG.
6. **WAI-ARIA & Accessibility Semantics**:
   - Emits `role="img"` and `aria-label={alt || name || "User avatar"}`.
   - Vector SVG icons emit `aria-hidden="true"`.
7. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
8. **Verification & Gates**:
