## Objective

Second task of the approved 7-task Phase D roadmap (plan record:
`/Users/sanjeet_kumar/.claude/plans/hi-fancy-shannon.md`; mirrored in
`R_&_D/OmniStackAI_Commercial_Platform_Kickoff_v1.md`). New control-plane routes proxying the
agent-engine's existing (R-468) edit/turns endpoints, mirroring `POST /jobs/build`'s exact
proxy+debit shape (R-472). Also fixes two real, verified gaps in the Python edit path found during
this roadmap's planning:

1. `_edit()` has no `usage_ledger` at all — confirmed by direct comparison with `_build()`.
   `_build()` creates a `UsageLedger()`, threads it through `resolve_generation_provider_from_env`,
   and adds a `"usage"` key to its response; `_edit()` calls `resolve_generation_provider_from_env()`
   with no such argument and its response has no `"usage"` key. Every edit today would debit 0
   credits regardless of real cost.
2. `_build()` never records a chat turn — only `_edit()` does (`session_store.record_turn` is
   called twice inside `_edit()`, never inside `_build()`). A future chat UI (R-477) that hydrates
   history from `GET /turns` after a page refresh would silently lose the very first message.

Both are fixed here by mirroring `_build()`'s own existing patterns exactly.

## Design

### Go (`services/control-plane/internal/jobs/`)

- New routes: `POST /jobs/build/{id}/edit`, `GET /jobs/build/{id}/turns`.
- `handleBuildEdit`: same shape as `handleBuild` — extend write deadline via `defaultBuildTimeout`
  (same slow-model-call reasoning), auth, read body verbatim, forward
  `POST {AgentEngineURL}/api/build/{id}/edit`, non-2xx proxied unchanged with zero debit, on 2xx
  extract `creditsForUsage(payload["usage"], ...)` and debit if >0, inject
  `credits_spent`/`credit_balance`. The shared "forward, decode, debit, inject" body is extracted
  out of `handleBuild` into a `proxyAndDebit` helper both handlers call, mirroring the
  `writeAuthError` extraction precedent R-474 already set once a second call site appeared.
- `handleBuildTurns`: pure `proxyGet`, identical shape to `handleBuildFiles` (auth only, no debit).
- A no-op edit (the delta call still happened even if it produced no file changes) still charges
  real credits — a dedicated test, since it's non-obvious and easy to regress.

### Python (`services/agent-engine/.../studio/live_serve.py`)

- `_edit()` gains `usage_ledger = UsageLedger()`, passed into
  `resolve_generation_provider_from_env(usage_ledger=usage_ledger)`, with `"usage":
  _usage_summary_to_dict(usage_ledger)` added to both response-dict branches (no-op-diff and
  committed-edit).
- `_build()` gains `session_store.record_turn(build_id, "user", prompt)` /
  `record_turn(build_id, "assistant", <short summary>)` right after `session_store.begin(...)`,
  single-IR builds only (same guard already there).
