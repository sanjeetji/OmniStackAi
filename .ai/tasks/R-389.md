## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic Audio Player & Frequency Equalizer compound component suite (`components/audio-player.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ hooks, HTML5 `<canvas>`, and native inline vector SVGs.
- Multi-track playback & playlist queue management: Track title, artist, duration, cover art thumbnail.
- Playback controls: Play, pause, stop, previous track, next track, shuffle, and repeat modes.
- Interactive seekable waveform / scrubber with duration counters (`MM:SS`).
- 5-band frequency equalizer (`AudioEqualizer`): 60Hz, 250Hz, 1kHz, 4kHz, 16kHz sliders (-12dB to +12dB) with presets ("Flat", "Bass Boost", "Vocal", "Electronic", "Rock").
- Volume slider with mute toggle.
- Playback speed control: 0.5x, 0.75x, 1x, 1.25x, 1.5x, 2x.
- Playlist queue slide-over drawer (`AudioPlaylist`).
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast slate dark player surface with clean cyan accents.
  - `"card"`: Bordered elevated card with soft drop-shadow.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)` overlays.
  - `"neon"`: Cyberpunk glowing neon theme with radiant equalizer bars and glowing audio waveform scrubber.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- WAI-ARIA 1.2 media semantics (`role="region"`, `aria-label="Audio Player"`, `aria-live="polite"`).
- React `forwardRef` and `useImperativeHandle` (`AudioPlayerHandle`): `play()`, `pause()`, `togglePlay()`, `nextTrack()`, `prevTrack()`, `seekTo()`, `setVolume()`, `setSpeed()`, `setEqualizerBand()`, `getCurrentTrack()`.
- Compound and semantic alias exports: `AudioPlayer`, `MusicPlayer`, `SoundPlayer`, `AudioEqualizer`, `AudioPlaylist`, and default export (`AudioPlayerComponent`).
- Explicit `displayName` across all compound exports.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_audio_player_component.py`.
