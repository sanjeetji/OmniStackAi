## Objective
Elevate the developer and user experience in generated Next.js web application dashboard overview pages (`apps/web/app/page.tsx` via `_overview_page` in `nextjs.py`):
1. **Interactive Entity Summary Cards**:
   - For listable entities (entities with `Op.LIST`), check if a matching collection screen exists (`_screen_intent(s) == "collection"` and `_match_entity(s, ir).name == entity.name`).
   - If a matching collection screen exists, render the summary card as an accessible interactive `<Link href="/{collection_screen.id}" ...>`:
     - `aria-label="View {escaped_plural} collection"`.
     - Uppercase entity tag, live total count (`{var}.loading ? "…" : {var}.error ? "—" : {var}.total`).
     - Subtitle displaying plural name and action affordance: `View all &rarr;`.
   - If no matching collection screen exists, render as a styled `<div>` card with live record count (preserving existing behavior).
2. **Dashboard Overview Header with Live Operational Status Badge & Metrics Chips**:
   - Wrap header in a responsive flex layout with application title and subtitle.
   - Render a live operational status badge: emerald pill (`#f0fdf4`, border `#bbf7d0`, text `#166534`) with a green status indicator dot (`#22c55e`) displaying "System Operational".
   - Render summary metric chips indicating total entity count (`{count} Entities`) and total screen count (`{count} Screens`).
3. **Screen Navigation Cards**:
   - Render screen cards with navigation indicator arrow (`&rarr;`) alongside screen title.
4. **Empty State Fallback**:
   - When neither entities nor screens are configured, render an accessible zero-state card welcoming the user and explaining that no entities or screens are configured.

## Invariance & Constraints
- 100% offline, stdlib-only Python codegen in `services/agent-engine`.
- Strict diff invariance across `ir.description`.
- Zero network or cloud model calls.
- Preserves all existing live hooks, screen nav cards, and quick actions.
