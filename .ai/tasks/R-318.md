# Task Contract: R-318 — Generated Accessible Reusable Drawer / Sheet Component (components/drawer.tsx)

## 1. Context & Background

The OmniStackAI Next.js Web Generator (`NextjsWebAdapter`) produces modern, accessible, customer-owned Next.js App Router applications. Complex web applications frequently require overlay sheet and drawer patterns for mobile navigation menus, filter sidebars, quick record inspection/edit sheets, and subcollection side panels without disrupting the primary route layout.

To provide this capability in generated applications, the platform needs a standalone, accessible, reusable compound Drawer / Sheet component (`apps/web/components/drawer.tsx`). Like previously implemented UI primitives (`components/confirm-dialog.tsx`, `components/tabs.tsx`, `components/card.tsx`, `components/alert.tsx`, `components/skeleton.tsx`), the Drawer component must be self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description` changes, and adhere to WAI-ARIA 1.2 modal dialog specifications.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/drawer.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Subcomponents**:
   - `Drawer` (root container managing visibility, backdrop, position slide-in transforms, escape keydown, backdrop click, and body scroll lock).
   - `DrawerHeader` (header section with title, description, and accessible close button).
   - `DrawerTitle` (accessible title supporting polymorphic heading tags `as` defaulting to `"h2"`).
   - `DrawerDescription` (subdued contextual description).
   - `DrawerContent` (scrollable middle content container).
   - `DrawerFooter` (bottom action bar with alignment presets `"left" | "right" | "between" | "center"`).
3. **Positions & Dimensions**:
   - `DrawerPosition = "left" | "right" | "top" | "bottom"` (defaults to `"right"`).
   - `DrawerSize = "sm" | "md" | "lg" | "xl" | "full"`.
   - Smooth CSS transform/transition animations for slide-in from respective edge.
4. **WAI-ARIA & Accessibility Semantics**:
   - `role="dialog"` and `aria-modal="true"`.
   - `aria-labelledby` linking title, `aria-describedby` linking description.
   - Accessible dismiss button (`aria-label="Close drawer"`).
   - Keyboard `Escape` dismiss handling when open.
   - Body scroll locking (`overflow: hidden`) during drawer visibility to prevent background scrolling.
5. **Diff Invariance & Purity**:
   - Independent of `ir.description` and `ir.name`.
   - 0 external dependencies (pure React/TypeScript/CSS).
