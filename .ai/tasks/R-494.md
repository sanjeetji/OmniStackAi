# R-494: Console — Studio tabs (Preview chrome, Files tree, Code viewer, Problems)

**Phase:** MVP
**Status:** COMPLETED
**Started:** 2026-09-19
**Completed:** 2026-09-19

## Objective

Fourth task of the Console UI overhaul (R-491..R-496). R-493 rebuilt the Studio's chat rail and
workspace shell; the four tabs inside the workspace — Preview / Files / Code / Problems — are
still the R-481 hand-rolled versions (a flat 200-item file list, a native `<select>` file picker,
a 560px iframe with two text buttons, a plain problems list). This task rebuilds them on the
vendored shadcn `Tabs` and Lucide: Files as a real collapsible tree; Code as tree + viewer with a
sticky header; Preview with real frame chrome (status pill, URL, open-in-new-tab, Desktop /
Tablet / Phone width presets, Restart / Stop); Problems grouped by file with parsed diagnostics
and a click-through into Code. **Every fetch, poll, effect and error path stays as it is** —
the preview's start/poll/restart/stop logic, the file read, the problems check — only the
presentation changes. It also closes a known R-477 degradation: after a `?build=` refresh the
Files/Code tabs were empty until the next edit, because only turns were rehydrated; the file
list is now fetched on hydration too.

## Design (verified against the real code and `scripts/test.sh`)

- **Contract constraints**: R-481 requires `studio-tabs.tsx`, `code-highlight.ts` and the four
  quoted labels `"Preview"` `"Files"` `"Code"` `"Problems"` inside `studio-tabs.tsx`; R-479
  requires `studio-preview.tsx` and a `StudioPreview` mention in `studio-chat.tsx`; R-475 pins
  `studio-icons.tsx`. With this task every Studio file imports Lucide directly, so the R-493
  shim is **deleted** and the R-475 assertion is edited to drop it — the deliberate,
  recorded retirement R-493 planned; the rest of the R-475 block (layout gate, tokens) stays.
- **Tabs** (`studio-tabs.tsx`): shadcn `Tabs variant="line"` — real Radix tabs (roving
  keyboard focus, `aria-selected`, `aria-controls`) — with a Lucide icon per trigger
  (`MonitorPlay`, `FolderTree`, `Code`, `Bug`) and live counts (files, problems) as small
  badges. Tab state stays local, as before; `selectedFile` stays lifted so Files → Code works.
- **Files tree** (new `file-tree.tsx`): `buildFileTree(paths)` turns the flat list into nested
  nodes (directories first, then files, alphabetical); a `FileTree` component renders it as
  nested lists with collapsible directories (`aria-expanded`, `Folder`/`FolderOpen`/`FileText`
  icons, depth indentation), the selected file highlighted, every row a real `<button>`. Top-level
  directories and every ancestor of the selected file start expanded. No arbitrary 200-item cap:
  a 173-file build renders whole.
- **Code**: a two-pane layout — the same `FileTree` in a narrow left pane (Code's own file
  switcher, per the R-481 founder decision that both tabs stay independently useful) and the
  viewer on the right with a sticky header (path in mono, language badge, line count, size),
  the untouched `tokenizeCodeLine` tokens on the existing `.code-tok-*` theme colors, a
  `tabular-nums` gutter, horizontal scroll for long lines, skeleton lines while loading, an
  alert on error, honest notes for binary/truncated files, and an empty state that says which
  pane to click.
- **Problems**: a header with the **Check for problems** `Button` (spinner while checking, since
  a real `tsc` runs), a result badge (destructive "N problems" / brand "No problems"), the "Not
  checked yet" empty state, a clean state with `CircleCheck`; results grouped per file in cards
  whose header (`FileText` + path + count) is a button that opens that file in Code; each
  diagnostic line is parsed from tsc's `L12:5 TS2339: message` form into line:col + code chips +
  message (unparseable lines render verbatim); `output_tail` behind a native `<details>` "Raw
  output". tsc only emits errors, so no fake "warning" severity is invented.
- **Preview** (`studio-preview.tsx`): identical state machine and effects (build-scoped start on
  `buildId`/`previewVersion`, 500ms elapsed ticker, 5s crash-detection poll, restart/stop,
  404 → disabled). New chrome: a toolbar with a status pill (Live / Starting / Stopped / Error /
  Unavailable), the URL as a truncated mono link, an **Open in new tab** icon button, three width
  presets (Desktop 100% / Tablet 768px / Phone 390px, `aria-pressed` segmented buttons) that
  size a centered frame container, and Restart / Stop `Button`s; the frame is
  `h-[calc(100dvh-18rem)] min-h-[480px]`; starting shows a skeleton frame with the real elapsed
  seconds; disabled shows the designed message with the exact `task agent-engine:studio:preview`
  command in `<code>`; error shows an alert with Restart.
- **Hydration fix** (`studio-chat.tsx`, one scoped addition): after turns come back for
  `?build=<id>`, `GET /api/jobs/build/{id}/files` is fetched and a files-only snapshot is set, so
  Files/Code work immediately after a refresh; `refreshFiles` moves to module scope
  (`fetchBuildFiles`) since it uses no component state — the SSE parser, edit and 404 paths are
  untouched. `StudioWorkspace` shows its "restored" note whenever the snapshot has no `name`.
- **CSS**: the legacy tab/file-list/file-viewer/code/problems/preview blocks are removed from
  `globals.css`; `.code-tok-*` theme colors stay (used by the viewer); `.spinner`, `.pill`,
  `.pill--accent` stay for the R-475 assertion (R-496 sweeps).
- **No new dependencies; no API/lib changes; no agent-engine/control-plane changes.**
