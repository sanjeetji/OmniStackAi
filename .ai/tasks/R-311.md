# Task R-311: Generated Collection Table Display Density Toggle in Next.js Web App

## Status: DONE

## Objective
Enhance generated Next.js collection screens (`_collection_screen_page`) with an interactive, accessible table display density toggle (`"compact"` | `"comfortable"` | `"spacious"`), giving users dynamic control over information density and scanning ergonomics.

## Requirements
1. **Density State & Calculation**:
   - Emits `density` state initialized to `"comfortable"`:
     `const [density, setDensity] = useState<"compact" | "comfortable" | "spacious">("comfortable");`
   - Maps `densityPadding`:
     - `"compact"`: `"6px 12px"`
     - `"spacious"`: `"16px 20px"`
     - `"comfortable"` (default): `"12px 16px"`
   - Maps `densityFontSize`:
     - `"compact"`: `13`
     - `"comfortable"` / `"spacious"`: `14`
2. **Toolbar Control Affordance**:
   - Renders an accessible segmented control in the collection screen toolbar:
     - Group container: `<div role="group" aria-label="Table display density" ...>`
     - Three buttons: `Compact`, `Comfortable`, `Spacious`
     - Each button carries `type="button"`, `aria-pressed={density === ...}`, `aria-label="{Density} density"`, and contextual active pill styling.
3. **Table & Row Presentation**:
   - Table emits `data-density={density}` attribute for test inspection and styling hooks.
   - Table `fontSize` dynamically reflects `densityFontSize`.
   - Table row data cells (`<td>`) apply `padding: densityPadding` across checkbox, data fields, and action cells.
   - Header Actions `<th>` preserves `'<th style={{ padding: "12px 16px", textAlign: "right", fontWeight: 600, color: "#475569" }}>Actions</th>'` for backwards compatibility with existing assertions.
4. **Diff Invariance & Safety**:
   - 100% diff-invariant across `ir.description` changes.
   - Pure codegen changes, 100% offline, 0 network, 0 model calls.
   - Strict test-first verification.
