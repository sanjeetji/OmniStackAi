## 1. Objective

Provide a standalone, accessible, zero-dependency Hierarchical Tree View component suite (`components/tree-view.tsx`) across all generated OmniStackAI Next.js web applications.

Key features:
1. `TreeNode` interface:
   - `id: string`: Unique node identifier
   - `label: string`: Node display label
   - `icon?: React.ReactNode`: Optional custom icon
   - `children?: TreeNode[]`: Nested child items
   - `disabled?: boolean`: Disabled state
   - `data?: unknown`: Arbitrary attached payload
2. `TreeView` component:
   - `TreeViewVariant`: `"default"` | `"bordered"` | `"ghost"` | `"lines"`
   - `nodes`: List of root tree nodes
   - Selection modes: single-select (`selectedId`, `onSelect`) and multi-select (`selectedIds`, `onMultiSelect`)
   - Expansion control: `expandedIds`, `onToggle`, `defaultExpanded` (boolean or list of IDs)
   - Search/filtering: `filter` prop with automated branch auto-expansion and matched label highlighting
   - Guide lines: connecting vertical and horizontal hierarchy tree lines
3. WAI-ARIA Tree View 1.2 compliance:
   - `role="tree"` on container with `aria-label` / `aria-multiselectable`
   - `role="treeitem"` on each node with `aria-expanded`, `aria-selected`, `aria-level`, `aria-setsize`, `aria-posinset`, `aria-disabled`
   - `role="group"` on child branch containers
4. Full Keyboard Navigation:
   - `ArrowDown`: Next visible node
   - `ArrowUp`: Previous visible node
   - `ArrowRight`: Expand collapsed node; or descend to first child if expanded
   - `ArrowLeft`: Collapse expanded node; or ascend to parent node if collapsed
   - `Home`: Jump to first node
   - `End`: Jump to last visible node
   - `Enter` / `Space`: Select active node
   - `*` (Asterisk): Expand all siblings at active level
5. Built-in vector icons:
   - FolderClosed, FolderOpen, FileText, ChevronRight, ChevronDown
6. Standard generator integration:
   - Export `render_tree_view_component` in `omnistackai_agent_engine.codegen`
   - Register `components/tree-view.tsx` in `NextjsWebAdapter.generate()`
   - 100% diff-invariant across `ir.description`, zero external npm dependencies
