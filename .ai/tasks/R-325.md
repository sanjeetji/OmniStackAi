# Task Contract: R-325 — Generated Theme Switcher / Mode Toggle Component (components/theme-toggle.tsx)

## 1. Context & Background

In Task R-324, the OmniStackAI Next.js Web Generator established `apps/web/styles/tokens.css` with semantic color palettes for Light mode (`:root`) and Dark mode (`[data-theme="dark"]`, `:root.dark`, `@media (prefers-color-scheme: dark)`).

To empower end users to switch themes dynamically with instant visual response and persistent user preferences across sessions, generated Next.js web applications need an accessible, reusable Theme Switcher component (`apps/web/components/theme-toggle.tsx`).

Following platform architectural standards, the component must be completely self-contained, 0 npm dependencies, 100% diff-invariant across `ir.description`, support Light / Dark / System modes, provide an inline FOUC-prevention script snippet, and adhere strictly to WAI-ARIA accessibility standards.

## 2. Objectives & Scope

1. **Standalone File**: Emit `apps/web/components/theme-toggle.tsx` via `NextjsWebAdapter.generate()`.
2. **Component Architecture & Exports**:
   - `ThemeMode`: Type alias `"light" | "dark" | "system"`.
   - `ThemeProvider`: Context provider managing current theme mode, resolved active theme, and localStorage sync.
   - `useTheme`: Custom hook exposing `{ theme, resolvedTheme, setTheme }`.
   - `ThemeToggle`: Compact, accessible toggle button with built-in SVG Sun and Moon icons, cycling or toggling modes.
   - `ThemeSelect`: Accessible segmented radio control or select for choosing between Light, Dark, and System modes.
   - `ThemeScript`: Inline script snippet to prevent Flash of Unstyled Content (FOUC) during initial SSR page load.
3. **WAI-ARIA Accessibility**:
   - `ThemeToggle`: `aria-label="Toggle theme (current: ...)"`, `title`, keyboard accessible.
   - `ThemeSelect`: `role="radiogroup"`, `aria-label="Select color theme"`, each option emitting `role="radio"`, `aria-checked`.
   - Vector SVG icons with `aria-hidden="true"`.
4. **Diff Invariance & Purity**:
   - Zero external npm packages (pure React 18, TypeScript, CSS custom properties).
   - 100% deterministic, diff-invariant string template.
5. **Verification & Gates**:
