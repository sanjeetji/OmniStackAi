## Objective

The generated collection list already renders a "Retry" button (calling `refetch()`) in its error banner.
The detail-screen main error state and both subcollection (master-detail) error states show only an
"Error: ..." text banner with no recovery. Bring them to parity: add a "Retry" button that calls the
relevant refetch, matching the collection banner's flex layout and dark-red styling. This completes the
error side of the generated app's data-fetch UX, mirroring the R-292/293 loading-skeleton completeness.
