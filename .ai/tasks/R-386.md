## Objective
Implement an enterprise-grade, accessible, desktop-and-mobile-grade, futuristic File Explorer & Storage Browser compound component suite (`components/file-explorer.tsx`) for Next.js web applications generated by OmniStackAI. The component must support:
- Zero external runtime npm dependencies: Pure React 18+ hooks and native inline vector SVGs.
- Hierarchical folder navigation with interactive breadcrumbs (`Home / Documents / Projects`).
- Dual view modes:
  - Responsive card grid mode with large file-type icons and preview cards (`"grid"`).
  - Tabular list view with sortable columns: Name, Type, Size, Last Modified (`"list"`).
- File selection: single-select and multi-select (`multiSelect`) with selection counter.
- Interactive search query filter input with clear button.
- Slide-over file inspector details panel (`FileDetailsPanel`) showing formatted file size (B, KB, MB, GB), last modified date, mime/extension, download, and delete triggers.
- Action toolbar: New folder, Upload, Download selected, Delete selected, View mode toggle.
- WAI-ARIA 1.2 semantics (`role="region"`, `aria-label="File Explorer"`, `role="grid"` / `role="list"`, `role="row"` / `role="listitem"`, `aria-selected`).
- 4 futuristic visual styling variants:
  - `"default"`: High-contrast crisp clean slate dark surface.
  - `"card"`: Bordered card surface with soft elevation.
  - `"glass"`: Translucent frosted glassmorphism with `backdropFilter: blur(20px)`.
  - `"neon"`: Cyberpunk glowing cyan/violet theme with radiant file halos and luminous borders.
- 3 size scales: `"sm"`, `"md"`, `"lg"`.
- Compound and semantic alias exports: `FileExplorer`, `FileManager`, `FileBrowser`, `DocumentManager`, `FileGrid`, `FileList`, `FileDetailsPanel`, and default export (`FileExplorerComponent`).
- React `forwardRef` and explicit `displayName` across compound exports.
- Imperative handle (`FileExplorerHandle`): `selectFile()`, `clearSelection()`, `navigateToFolder()`, `getCurrentFolderId()`, `getSelectedFiles()`.
- 100% diff-invariance across `ir.description`.
- 17 unit tests in `services/agent-engine/tests/test_file_explorer_component.py`.
