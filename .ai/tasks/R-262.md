# R-262: React Data-Fetching & Mutation Hooks Generator (apps/web/lib/hooks.ts)

**Phase**: BASIC/MVP
**Stage**: Founder Stage 0
**Status**: done

## Context and Goal
Generate strongly-typed, idiomatic React hooks (`apps/web/lib/hooks.ts`) in the generated Next.js web application:
- `useList<Entities>`: loading, error, data, total count, pagination math (`page`, `pageSize`, `totalPages`, `setPage`), sorting (`sort`, `order`, `setSort`), search (`q`, `setSearch`), refetch.
- `use<Entity>(id)`: detail fetching hook with loading, error, refetch.
- `useCreate<Entity>`, `useUpdate<Entity>`, `useDelete<Entity>`: mutation hooks with loading, error, and async execution.
- `useList<Entities>By<Rel>`: subcollection list hook scoped by parent relation.
- Emits `"use client"` directive at top.
- Pure codegen change; no new platform dep, no install/build/run/DB.
