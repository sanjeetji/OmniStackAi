## Objective
Generate a zero-dependency, desktop-grade, futuristic, and accessible Radio Group compound component suite (`components/radio-group.tsx`) for the OmniStackAI Next.js application generator. The component provides:
1. WAI-ARIA 1.2 Radio Group pattern compliance (`role="radiogroup"`, `role="radio"`, `aria-checked`, `aria-disabled`, `aria-required`, `aria-orientation`, roving `tabIndex`).
2. Full keyboard navigation with arrow keys (`ArrowDown`/`ArrowRight` selects next enabled item with wrap-around, `ArrowUp`/`ArrowLeft` selects previous enabled item with wrap-around, `Space` selects focused radio).
3. Layout orientations: `vertical` (default) and `horizontal` flex alignment.
4. 4 futuristic visual styling variants: `default` (sleek minimalist circles with animated indicator dot), `card` (selectable option tiles with title, description, and indicator), `pill` (segmented pill/toggle style), and `neon` (cyberpunk glowing cyan/indigo border and neon ambient glow).
5. 3 size scales: `sm`, `md` (default), and `lg`.
6. Controlled (`value`, `onValueChange`) and uncontrolled (`defaultValue`) state management with form submission integration (`name` attribute).
7. Compound subcomponents: `RadioGroup`, `RadioGroupItem` (aliased as `Radio`), and `useRadioGroup` context hook.
8. Full React ref forwarding for all interactive elements.
9. 100% diff-invariance across `ir.description`.
